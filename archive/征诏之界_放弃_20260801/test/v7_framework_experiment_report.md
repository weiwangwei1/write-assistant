# v7 框架实验报告 — 意象预算 + 段落功能分配

> 实验目标：用增强版 scene_sheet（意象预算 + 段落功能分配）重写前三章，验证能否在框架层面避免评审意见指出的意象重复和金句密度问题。

---

## 一、实验背景

v5/v6 版本前三章的 scene_perception_lint 诊断均为 97+ 分，但评审意见指出两个核心问题：
1. **意象重复**：暗紫色出现 19+ 次，碱味 18+ 次，铜钱 49+ 次
2. **金句密度**：每章 13-22 个金句，密度 3.4-5.4/千字，读者疲劳

这些问题不在 scene_perception_lint 的检测维度内，需要新的框架层工具。

---

## 二、工具与方法

### 新增工具：framework_experiment.py

- **P1 意象预算**：跟踪 5 个核心意象的出现次数、变体使用率、密度
- **P2 段落功能**：分类段落（sensory/action/dialogue/heavy/plain），统计金句密度和间距

### 增强版 scene_sheet

在原有 scene_sheet 模板基础上新增：
- `imagery_budget`：每章意象上限 + 变体要求
- `para_function_map`：段落功能标注
- `punchline_budget`：金句数/密度/间距限制

## 四、关键策略

### 1. 意象变体替换

核心策略：将高频意象的直接使用替换为变体。

```
暗紫色 → 暗光（10次）、纹路（6次）、暗色、发紫
裂缝 → 口子（18次）、界门（5次）、城墙根（9次）
铜钱 → 三枚（10次）、那几枚、掌中之物、旧物
碱味 → 干涩的气、干热、砂粒感、发紧
```

### 2. 金句修剪

将 heavy 段转为 plain/sensory 段，删除哲理性收尾句。

```
原写（heavy + 金句）：
  砂石比铜钱老实，铜钱会动会转会感应，砂石只会磨深。
  磨深了也不说，不说比说重。  ← 金句（删）

修剪为（plain，无金句）：
  砂石比铜钱老实，那几枚会动会转会感应，砂石只会磨深。
```

### 3. 段落功能控制

- heavy 段从 12-25% 压缩到 3-18%
- 金句间距通过删除中间的 heavy 段自然增大
- 每章保留 4-6 个真正的金句（heavy 段 + 对话内金句）

## 五、结论

1. **意象预算有效**：所有意象从超预算降至预算内，变体率从 13-59% 提升至 45-100%
2. **金句密度改善**：Ch1 达到满分（1.68/千字），Ch2/Ch3 仍有改善空间（检测器误报较多）
3. **场景感知不降反升**：Ch1/Ch2 保持 98+，Ch3 略降（95.9）但仍优秀
4. **style_lint 全通过**：三章均无 critical，仅 minor 项（le_pattern 对话尾"了"）

### 框架层面预防效果

通过在 scene_sheet 阶段就设定意象预算和段落功能分配，写手在动笔前就知道：
- 每个意象能用几次，超了用什么变体
- 哪些段落允许放金句，哪些不允许
- heavy 段占比上限是多少

这从源头上避免了"写完再修"的被动模式，实现了**框架层面预防**而非**事后修补**。
