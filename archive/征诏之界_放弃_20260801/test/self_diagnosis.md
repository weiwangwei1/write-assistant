# 自我诊断：v2 为什么"徒有其形"

## 核心问题：技术可见，手艺人不可见

烟雨江南的段落读起来像一个饱经风霜的人在给你讲故事——他有态度、有幽默、有厌恶、有怜悯，全都藏在叙述的口吻里。我的 v2 读起来像一台精密的摄像机在记录——角度对了、构图对了，但没有人在看。

## 逐条诊断

### 1. 句式单一：全是短句，没有呼吸

**我的 v2 典型段落**：
> 他把铜钱攥在手心。攥得很紧。
> 没有翻第二面。没有算。

短句。短句。短句。短句。这是 AI 写作最常见的节奏模式——用短句伪装力量感，实际上是因为不会写长句。短句只有在长句之后才有力。全是短句，等于没有重音。

**烟雨江南同场景**：
> 老汉斯取出块干干净净的手帕，慢慢擦着喷到自己脸上的口水，向黑人胸前一处碗口大的溃烂指了指，慢慢地道："你得了病！让你下矿井，会把我的壮骡子们都给传染上的，那时谁来给我干活？"

一个长句，四个动作（取手帕、擦口水、指伤口、说话），每个动作都带着人物性格。干干净净的手帕和碗口大的溃烂放在一起，对比自己完成了。然后下一句——

> 老汉斯身后，一个秃头壮汉再次扣动手中双管霰弹枪的扳机，又是一声巨响，数百粒铁砂轰进那黑人的胸口——

长句建立节奏，短句打断它。这才是呼吸。

### 2. 叙述者没有声音

**我的 v2**：叙述者是透明的。他只记录动作，不发表意见，不流露态度。结果就是——文字没有温度。读者感受不到"有人在给我讲这个故事"。

**烟雨江南**：叙述者有明确的态度——
> "跟周围那些穿得跟乞丐没什么两样的流民一比，老汉斯简直就是个国王，他也的确傲慢得象个国王。"

这一句里，叙述者在评价：老汉斯像个国王，而且他知道自己是。这不是角色心理，是叙述者的口吻——带着一点讽刺，一点承认。

> "看他说话的口气，就好象那个黑人仍站在桌前一样。"

死人已经倒了，叙述者说"看他说话的口气好像那人还站着"。这是黑色幽默，是态度。我的 v2 里完全没有这种东西。

### 3. 世界细节是"放进去的"，不是"长出来的"

**我的 v2**：
> 城墙的石缝里有一窝虫，白的，没眼……
> 城墙根下晾着半条被子，不知道是谁的……
> 这件事和程铖无关，和铜钱无关。

这三句话在结构上是孤立的——它们被"放"在叙事流里，像花瓶摆在架子上。最后一句"这件事和程铖无关"是作者在解释自己为什么写这段——这等于告诉读者"我在做世界建设"，手法就暴露了。

**烟雨江南**：世界细节从角色的观察或叙述者的评论中自然流出——
> "甚至在几公里外的镇上，这间不怎么透风漏雨的铁皮棚屋也可以算得上是豪宅了。"

世界信息（镇上条件更差）从一个比较中自然产生，不需要解释"这和主角无关"。

### 4. 感官细节重复且笼统

**我的 v2**："铁锈味"出现了三次。"暗紫色的光"出现了五六次。这是想象力不足的表现——同一个感官通道反复使用，因为没有找到新的切入点。

**烟雨江南**：每一个感官细节都是具体的、一次性的——
> "足以让大多数女人嫉妒得想在她脸上划上几刀"（美，通过他人的暴力反应来写）
> "刚刚给婴儿喂过奶"的湿衣襟（母性，通过一块水渍来写）
> "喀喀嚓嚓的咀嚼声音"（死亡，通过声音来写）

他不重复，因为每一个细节都是为那个特定的瞬间找到的唯一入口。

### 5. 对话没有角色辨识度

**我的 v2**：老周和程铖的对话都是短句、陈述句，交换信息。遮住名字分不清谁在说话。

**烟雨江南**：
> 老汉斯："都给我爬起来，兔崽子们！"（唠叨、粗鲁、有口头禅）
> 黑人："我能干活！我要吃的，我有三个孩子要养！"（急切、重复、不讲理）
> 老汉斯向死人说话："还有，黑鬼，你的口水很臭！"（冷漠到荒谬）

每个角色的词汇、节奏、语气都不同。对话不只是传递信息，是在展示"这个人是什么样的"。

### 6. 情感温度恒定

**我的 v2**：从头到尾一个温度——冷。战斗是冷的，死亡是冷的，发现铜钱是冷的。冷不是问题，问题是只有冷。

**烟雨江南**：温度在变——
- 序章写甲虫：好奇（温暖）
- 暴民追女人：厌恶（冰冷）
- 母亲塞婴儿：悲悯（滚烫）
- 老汉斯出场：讽刺（微温）
- 黑人被杀：冷酷（冰冷）
- 老汉斯对孩子：一丝不易察觉的柔软（微温）

温度的变化本身就是叙事。恒温等于没有情感。

### 7. "延迟"变成了"不给你"

**我的 v2**：程铖发现铜钱后"没有翻第二面，没有算"。这是对 P008（情绪先无用一拍）的机械执行——不是延迟，是拒绝给。

**烟雨江南的延迟**：情感不是被"扣住"的，是被"占用"的。帕瑟芬妮不是不哭，是先在宽慰别人——她的悲伤找到了一个出口（照顾别人），延迟是自然的，不是刻意的。

## v3 改进方向

| 问题 | v3 策略 |
|------|--------|
| 句式单一 | 长句和短句交替。长句嵌入多个动作和细节，短句做重音。每章至少3个≥40字的长句 |
| 叙述者无声 | 给叙述者一个口吻：老兵式的干涩、带黑色幽默、偶尔流露怜悯但不承认 |
| 世界细节被放置 | 让世界信息从角色动作或叙述者评论中自然流出，不单独成段 |
| 感官重复 | 每个感官细节只用一次，找到新的切入角度（触觉、温度、声音质感、光线折射方式） |
| 对话无辨识度 | 老周：句子碎、带口头禅、绕弯子；程铖：极短、精准、用行动回答问题 |
| 温度恒定 | 战斗段：冰冷+精准；铜钱发现段：微热+颤抖；老周断臂段：苦涩+温度 |
| 延迟变拒绝 | 情感不是被扣住，是被别的东西占住。程铖不是"不算"，是手被别的动作占着 |
