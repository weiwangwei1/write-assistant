# 《亵渎》期 vs 三本后期基线对比（2026-07-31）

> 背景：用户评价《征诏之界》质地接近《亵渎》期烟雨江南（粗粝/底层/冷/短），而非《永夜君王》期（华丽/宏大/从容）。用户提供《亵渎》全文后构建独立基线做量化验证。
> 基线：`fingerprint_dubo.json`（样本 218 万字符，25 分组，置信度 high，口径 v2.0）vs `fingerprint.json`（狩魔+罪恶+永夜三本，1015 万字符）。
> 结论：用户判断**全部得到数据支持**，且发现 2 个此前框架未覆盖的手法差异（省略号、触觉）。

## 四、核心画像（"粗粝/底层/冷/短"的量化定义）

《亵渎》期 = **更短的句子（-6%）+ 更密的对话（+39%）+ 更强的身体触觉（+58%）+ 更多的省略号（+106%，话留半截）+ 更少的书面转折（"却"-58%，硬并置）+ 更近的叙述人称（我/你+40%）**

## 五、对《征诏之界》的 4 个可执行校准点

1. **省略号（最大发现）**：我们的省略号使用 = 0/千字，亵渎 = 1.33/千字。"话不说尽、欲言又止"是亵渎期冷对话的重要收尾手法（lint 上限 ≤1.5/千字，可用到 1.0-1.3 区间）——此前框架完全没覆盖。
2. **触觉强化**：感官优先级从"视觉>听觉>触觉"调整为"视觉>听觉>触觉（可至视觉的 1/4-1/3）"。《征诏之界》的壳/烫伤/痂/铜钱天然有身体戏，触觉是底层质感的来源。
3. **对话密度收敛**：亵渎对话 23%，我们的 Ch4 检验稿 43% 超 lint 40% 上限——目标收敛到 25-30%（风格卡现有目标不变，但写手注意收敛）。
4. **转折方式**：部分书面转折（"却/而"）改为硬并置（"他走了。她没哭。"）——短句对撞是亵渎期冷感来源。注意：决策②"连词粘合"是总量约束（≥5/千字），硬并置是局部手法，两者并存不冲突。

## 六、不采纳项

- 破折号：亵渎 0.001/千字——维持现有 0 容忍，不变
- 比喻：0.750 vs 0.652 差异小，维持现有克制区间
- "了"收尾 +42%：亵渎的"了"收尾多于后期，但 lint 的 le_pattern 规则（AI 腔检测）优先，维持现有约束——亵渎的"了"收尾是自然口语，我们的 le_pattern 禁的是"连续了字短句"（AI 堆叠），性质不同
