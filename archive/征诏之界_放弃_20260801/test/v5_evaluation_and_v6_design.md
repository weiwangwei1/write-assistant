**15组高频词中只有4组是真正的意象，其余11组是误报。** 误报率 73%。

根因：滑动窗口提取的是"所有高频2字组合"，没有任何词性过滤层。人名"程铖"出现39次被报 critical，这是荒谬的——人名不需要"换感知通道"。

### 2.2 严重问题：T2 天花板效应

Ch2 和 Ch3 的 T2 都拿了 100 分。评分逻辑：

```
翻译=0 + 金句密度<3 + 世界自转≥10 → 100分
```

但叙述者介入不只有"翻译"和"金句"两种形式。缺失检测：
- **总结句**："就这样，一天过去了"——叙述者概括收束
- **评论句**："这便是征调者的命"——叙述者抒情评论
- **情绪直说**："他感到恐惧"——叙述者贴标签而非展示
- **旁白交代**："没有人知道他去了哪里"——叙述者全知视角插入

### 2.3 中等问题：T4 固定预算不区分场景

- Ch2 "那枚/那几枚"22次被判超限——但Ch2是铜钱核心场景，反复提及铜钱是叙事需要
- Ch2 "磨"7次被判超限——但磨刀是Ch2的核心动作线

根因：固定预算(4次/6次)不考虑章节主题。一章围绕铜钱展开，"那枚"高频是合理的。

### 2.4 中等问题：T3 变体分组噪声

- "口子"变体出现"子深"——共享"子"字但不相关
- "位面"变体"位置""背面"——共享"位"字但不相关

根因：共享任一核心字就判为变体，过于粗暴。

## 三、根因分析

### 3.1 架构层面

v5.0 修了 v4.0 的 5 个症状，但**根病未治**：所有检测都基于关键词匹配/正则模式，没有语义理解能力。

```
v4.0 根病：用正则做 NLP
  → v5.0 修了 5 个症状
    → 但暴露了新的症状（人名误报、天花板、预算僵化）
      → 继续修？还是换思路？
```

### 3.2 T3 的定位错误

T3 把"高频词的感知通道覆盖率"当作质量指标。但这个逻辑有两个漏洞：

1. **不是所有高频词都是意象**：人名、场景词、术语高频是正常的
2. **通道覆盖率不是质量标准**："城墙"出现在视觉通道是合理的，不需要让它"走听觉通道"

真正应该检测的是：**关键意象词是否被多维度感知**。"裂缝"第一次写视觉（暗紫色），第二次可以写听觉（嗡嗡声），第三次写触觉（边缘硌手）——这才是"换感知不换词"。但"程铖"不需要换感知通道。

### 3.3 T2 的检测维度不足

T2 只检测"翻译"和"金句"两种叙述者介入形式，遗漏了至少 4 种常见介入形式。导致只要不翻译、金句不密集就满分。

### 3.4 评分体系的结构性缺陷

```
综合分 = T1×0.30 + T2×0.25 + T3×0.25 + T4×0.20 - critical×5
```

问题：
- T2 天花板(100) × 0.25 = 25 分白送
- T3 误报critical × 5 = 惩罚失真
- 加权平均掩盖短板效应（一个维度30分但另一个100分，综合分还能看）

## 四、v6.0 框架重设计

### 4.1 设计理念

**核心转变：从"扣分制"到"信号制"**

v5.0 的逻辑是"检测问题→扣分→评分"。问题是检测不准就扣错分。

v6.0 改为"提取信号→标记→让写手判断"。工具不做最终评分判定，而是输出结构化信号供写手参考。

**三条原则：**
1. **不报假问题**：宁可不报，不可误报。误报比漏报危害更大——写手会按误报去改，反而改坏
2. **人名/场景词不进意象分析**：通过角色卡和场景设定预过滤
3. **评分取消天花板**：T2 不设满分，只要文本中有叙述者介入信号就不可能满分

### 4.2 三维架构（4维→3维）

```
perception_texture.py v6.0
│
├── T1 场景具身度      [段落级]  段落是角色在感知还是作者在交代
│   ├── 信息交付段检测（陈述句式+无身体参与）
│   ├── 空间锚点检测（保留 D3 双层锚点）
│   └── 开篇焦距检测（保留 D5）
│
├── T2 叙述者介入度    [段落级]  作者在多大程度上"抢过话筒"
│   ├── 动作后翻译（保留 D2）
│   ├── 情绪直说检测（新增：他感到X → 应改为行为展示）
│   ├── 总结/评论句检测（新增：就这样/这便是/没有人知道）
│   └── 金句密度（保留 v5.0 语义过滤版，降权为参考项）
│
└── T3 意象多样性      [词级]    关键意象词是否被多维度感知
    ├── [管道] 高频词发现（保留滑动窗口）
    ├── [过滤] 意象词筛选（新增：排除人名/场景词/术语）
    ├── 通道覆盖检测（保留，只对意象词执行）
    └── 感官萦绕检测（保留 D4）
```

**砍掉 T4 节律控制的原因：**
- 动作预算和指代预算的固定阈值不合理
- 真正需要检测的"动作簇聚"和"指代模糊"可以合并到 T2（叙述者偷懒的信号）
- 减少一个维度，减少评分拉锯

### 4.3 T1 场景具身度（精简版）

**检测目标**：每段话是角色在感知，还是作者在交代？

**变化**：
- 删除：感官动词计数、身体部位计数、梯度评分（v5.0 的信号计数虽然改善了区分度，但本质仍然是表面计数）
- 保留：信息交付段检测、空间锚点检测、开篇焦距检测
- 新增：陈述句密度检测

**信息交付段判定**（精简版）：
```
段落同时满足以下条件 → 信息交付段：
  1. 含≥2个陈述句式（是/有/叫/规定/编制 + 句号）
  2. 无身体动作词（手/眼/脚/肩/背等）
  3. 无感官动词（看/听/摸/闻等）
  4. 不在对话中
```

**评分**：
```
T1 = 100 - 信息交付段数×10 - 空间失锚数×5 - 焦距扣分
```

不再做"embodied/partial/weak/plain"四分类——分类本身不可靠，直接检测"问题段"更准确。

### 4.4 T2 叙述者介入度（扩展版）

**新增检测项：**

#### 4.4.1 情绪直说检测
```python
# 检测模式：主语+感到/觉得/知道+情绪词
EMOTION_DIRECT_PATTERNS = [
    r"(?:他|她|程铖|老周|沈缺)(?:感到|觉得|知道|明白)(?:恐惧|害怕|不安|愤怒|悲伤|孤独|疲惫|绝望)",
    r"(?:恐惧|害怕|不安|愤怒|悲伤|孤独|疲惫|绝望)(?:涌上|袭来|爬上|漫过)(?:心头|全身|胸口)",
]
# 诊断：情绪应该通过行为展示，不应由叙述者直接告知
```

#### 4.4.2 总结/评论句检测
```python
# 检测模式：叙述者收束/评论/全知
NARRATOR_SUMMARY_PATTERNS = [
    r"就这样[，,]",
    r"这便是",
    r"没有人知道",
    r"谁也不知道",
    r"后来的事",
    r"很多年以后",
    r"这是他第[一二三四五六七八九十]+次",
]
# 诊断：叙述者跳出场景做总结/评论/全知交代
```

#### 4.4.3 金句密度（降权为参考项）
- 保留 v5.0 的语义过滤器
- 不再作为扣分项，只标记为 info 级别信号
- 密度>4/千字才报 warning

**评分**：
```
T2 = 100 - 翻译数×10 - 情绪直说数×8 - 总结评论数×8 - 金句超限×5
```

不再有世界自转加分——世界自转是正面信号，但不应该通过加分来"补贴"扣分。正面信号不加分，只扣分。

### 4.5 T3 意象多样性（重构版）

**核心变化：增加意象词筛选层**

```python
# 意象词筛选管道
def filter_imagery_words(groups, character_names, scene_words):
    """
    从高频词组中筛选真正的意象词
    
    排除：
    1. 人名（从角色卡读取）
    2. 场景固有词（城墙/城/墙/门/街道等）
    3. 世界观术语（大徵/征诏令/征调者/功勋等）
    4. 身体部位（手/眼/脚/肩/背等）
    5. 称谓词（师父/老头/将军等）
    6. 功能词（的/了/是/在等，v5.0已过滤但不够）
    """
```

**意象词白名单思路**（而非黑名单）：

v5.0 用黑名单（排除功能词），但排除不了人名。v6.0 改为白名单思路——只有满足以下条件的词才进入意象分析：

1. **是具象名词**（可被感官感知的实体或现象）
2. **非人名**（不在角色卡名单中）
3. **非场景固有词**（不在场景词表中）
4. **非世界观术语**（不在术语表中）
5. **非身体部位**（不在身体词表中）
6. **非称谓词**（不在称谓表中）

```python
# 预排除词表
CHARACTER_NAMES = ["程铖", "老周", "沈缺", "沈老头", "苏眠", "赵三", "程母"]
```

**变体分组改进**：
- 共享核心字 → 共享2字中的至少1字 + 语义相关
- 或直接取消变体分组，只分析词本身

**通道检测改进**：
- 从"整句扫描"改为"意象词前后20字窗口"
- 减少句子中其他词对通道判定的干扰

**评分**：
```
T3 = 所有意象词的平均通道覆盖率 × 100 - 感官一次性数×5
```

### 4.6 评分体系

**取消综合评分，改为维度评级：**

```
每个维度独立评级：
  A (≥85)  优秀
  B (70-84) 良好
  C (55-69) 中等
  D (<55)  需改进

最终评级 = 最低维度评级
  （木桶效应：一篇文章的感知织体取决于最弱的维度）
```

**取消 critical 加权扣分**——critical 只影响自身维度的分数，不再额外扣综合分。避免 T3 误报 critical 拖垮综合分。

**取消世界自转加分**——正面信号不加分，只扣问题分。
