## 烟雨江南风格蒸馏方案总结

### 一、方案架构

用**对话内上下文学习**替代传统微调管线，四个资产文件构成完整闭环：

| 传统管线 | 对话内替代 | 资产文件 |
|---------|-----------|---------|
| SFT 微调 | 系统提示词 + Few-shot样本加载 | `烟雨江南_系统提示词.txt` + `烟雨江南_Few-shot样本.json` |

| 世界观知识库 | 原文机制提取表 | `烟雨江南_战斗机制参考表.md` |

### 二、四份核心资产

**1. 系统提示词**（`烟雨江南_系统提示词.txt`）

风格参数的量化提取，分六层：
- 语言风格：均句长29字、段落74字、感叹号3/千字
- 叙事技法：第三人称限知、短句快推长句慢铺
- 内容偏好：暗黑奇幻/废土、冷硬基调
- 结构模式：场景切入→冲突发展→悬念收束
- 读者互动：压抑后爆发、章末留钩子
- **战斗描写核心原则**（本轮新增5条）：动作不停、机制嵌入观察、保留氛围铺垫、砍掉解释性段落、砍掉游戏面板

**2. Few-shot样本**（`烟雨江南_Few-shot样本.json`）

25段原文按5类场景分类：描写、整章、战斗、对话、心理。生成时按场景类型选取2-3段作为风格锚点。

**3. 战斗机制参考表**（`烟雨江南_战斗机制参考表.md`）

从三部原文系统提取的世界观骨架：
- 狩魔手记：能力域+阶位制（格斗域/灵能域/感知域/类法术域，逐阶提升）
- 罪恶之城：等级+构装制（1-18级+圣域+传奇，魔纹构装提升整级实力）
- 永夜君王：原力+战兵制（原力潮汐修炼，1-9级+战将）
- 生物兵器体系：初阶/中阶/高阶/掠食型/超级生命体
- 战斗描写模式：节奏控制表、力量体系嵌入方式、全景视角规则、结尾断点四种模式

**4. 对话内训练流程**（`烟雨江南_对话内训练流程.md`）

使用流程：风格加载 → 生成 → 风格自检 → 对比修正 → 迭代。含4个Prompt模板（场景生成/整章生成/续写/对比修正）和六条叙事法则。

### 三、六条叙事法则

从五轮迭代中提炼，是蒸馏的核心经验产出：

| 法则 | 一句话 |
|------|--------|
| 直接进入事件 | 不设环境定场句，从动作或状态开始 |
| 信息缺口 | 不解释来源/背景，信任读者 |
| 物象代替形容词 | 用"房屋无声崩解"代替"破坏力很强" |
| 事实性判断 | "生命脆弱"而非"这很残酷" |
| 硬切全景→个体 | 无过渡词，直接切换 |
| 解释服务人物 | 解释是塑造人物的，不是帮读者理解的 |

### 四、五条战斗描写原则（本轮新增）

| 原则 | 要点 |
|------|------|
| 动作不停 | 战斗中动作接动作，不插入规则解释 |
| 机制嵌入观察 | "甲壳接缝泛着暗光"而非"甲壳厚度3厘米" |
| 保留氛围铺垫 | 对手评估/环境渲染一两句带过，不展开 |
| 砍掉解释性段落 | "只有三次进化的才评估猎物"——删，动作本身已说明 |
| 砍掉游戏面板 | 能量百分比/护盾次数——不写，用行为暗示 |

### 六、使用方式

```
1. 加载系统提示词（含风格参数+叙事法则+战斗原则）
2. 按场景类型从Few-shot样本中选2-3段原文
3. 从战斗机制参考表中选取世界观体系
4. 生成
5. 自检：句长/段落/标点/引语词/网络用语/环境/情感
6. 与原文同类场景对比，定位偏差
7. 重写偏差段落
```
