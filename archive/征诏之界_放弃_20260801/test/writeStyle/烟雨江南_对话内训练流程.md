# 烟雨江南风格蒸馏 - 对话内训练流程

## 核心原理

将传统蒸馏管线映射为对话内操作:

| 传统管线 | 对话内替代 | 实现方式 |
|---------|-----------|---------|
| SFT 微调 | 上下文学习 | 加载系统提示词 + Few-shot样本 |
| DPO 对齐 | 对比修正 | 生成后与原文对比,定位偏差,重写 |
| RAG 检索 | 原文检索 | 从三部作品中检索相似场景作为参考 |
| 结构控制器 | 生成后自检 | 检查句长/段落/标点是否符合风格参数 |

## 使用流程

### Step 1: 风格加载(每次对话开始时执行)

将以下内容作为对话的前置上下文:

**A. 系统提示词**(见 `烟雨江南_系统提示词.txt`)

**B. Few-shot 样本**(按场景类型选择)

根据你要写的场景,从 `烟雨江南_Few-shot样本.json` 中选2-3段最相关的原文:
- 写战斗 → 选"战斗"场景样本
- 写环境 → 选"描写"场景样本
- 写整章 → 选"full_chapter"样本
- 写对话 → 选"对话"场景样本

**C. 风格约束清单**(生成时自检用)

| 检查项 | 目标值 | 不合格处理 |
|--------|--------|-----------|
| 平均句长 | 25-32字 | 过长则拆句,过短则合并 |
| 段落长度 | 57-94字 | 过长则分段 |
| 感叹号 | ≤3/千字 | 超标则减少 |
| 引语词 | 道>说>笑 | 避免用"说道""喊着" |
| 网络用语 | 0个 | 替换为文学性表达 |
| 环境描写 | 每场景≥1处 | 补充光影/色彩/温度 |
| 情感表达 | 克制 | 用行为暗示,不直接说"他很悲伤" |

### Step 2: 生成(用户给指令,AI按风格生成)

用户指令格式建议:

```
[场景类型] [题材/设定] [字数要求] [特殊要求]

示例1: 战斗场景 | 主角在废墟中遭遇伏击,敌人数量不明 | 2000字
示例2: 整章 | 标题:暗潮涌动 | 主角到达新城市,感受到潜在威胁 | 3500字
示例3: 对话场景 | 主角与反派谈判,双方互相试探 | 1500字
```

### Step 3: 风格自检(生成后自动执行)

生成文本后,执行以下检查:

**A. 统计检查**
- 句长: 抽样10句,计算平均长度,目标25-32字
- 段落: 统计段落数和平均长度,目标57-94字
- 标点: 感叹号≤3/千字,省略号≤1/千字
- 引语词: 检查是否使用了"道/说/笑"而非"说道/喊着"

**B. 风格检查**
- 是否有网络用语? → 有则替换
- 环境描写是否服务氛围? → 不是则删减或重写
- 对话是否推动剧情? → 不推动则删减
- 情感是否克制? → 过度煽情则改为行为暗示
- 是否有"烟雨江南味"? → 核心判断:冷硬中有诗意,残酷中有美感

**C. 不合格项修正**
- 定位偏差段落
- 重写该段落
- 重新自检

### Step 4: 对比修正(DPO替代)

将生成文本与原文中类似场景的段落对比:

1. 从原文中找一段**同类型场景**的段落
2. 逐维度对比:
   - 句式节奏: 原文怎么断句? 生成文本怎么断句?
   - 描写密度: 原文环境描写占多少? 生成文本占多少?
   - 对话风格: 原文对话怎么写? 生成文本怎么写?
   - 情感处理: 原文怎么处理角色情绪? 生成文本怎么处理?
3. 找到偏差最大的1-2个维度
4. 针对性重写

### Step 5: 迭代

重复 Step 2-4,每轮聚焦一个偏差维度:
- 第1轮: 句式节奏
- 第2轮: 描写密度
- 第3轮: 对话风格
- 第4轮: 情感处理
- 第5轮: 整体神韵

## 风格锚点(从原文提取的标志性特征)

### 语言锚点
- "道"是首选引语词,极少用"说"
- 破折号用于补充说明或转折
- 短句+换段制造紧迫感
- 长句用于环境铺陈,常有多个从句

### 叙事锚点
- 战斗时节奏骤然加快,短句连发
- 环境描写常以光影变化为核心
- 角色心理通过行为暗示,极少直接描写内心
- 残酷场景用冷静笔触写,反差感强

### 情感锚点
- 悲伤不写"泪流满面",写"他站了很久,然后转身离开"
- 愤怒不写"怒不可遏",写"他平静地收起刀,走了过去"
- 温情不写"心中一暖",写一个微小的动作或沉默

### 世界观锚点
- 力量体系清晰,有等级划分
- 世界残酷,弱者没有话语权
- 主角冷静理性,不冲动
- 设定通过事件自然展开,不直接说明

## 对话内使用的Prompt模板

### 模板A: 场景生成

```
你现在加载了烟雨江南的写作风格。以下是风格参考:

[系统提示词内容]

以下是烟雨江南的原文样本,请仔细体会其风格:
[2-3段Few-shot原文]

现在请用烟雨江南的风格写一段[场景类型]场景:
[用户的场景描述]

要求:
- 严格遵循上述风格参数
- 写完后自检:句长、段落、标点、引语词是否符合
- 不要使用网络用语
- 情感表达克制,用行为暗示
```

### 模板B: 整章生成

```
你现在加载了烟雨江南的写作风格。

[系统提示词内容]

[1-2段整章Few-shot原文]

现在请用烟雨江南的风格写一章:
标题: [章节标题]
大纲: [章节大纲]
字数: [目标字数]

结构要求:
- 场景切入 → 冲突发展 → 转折/悬念收束
- 章末留钩子
- 平均句长25-32字,段落57-94字

写完后自检风格参数,不合格处自行修正。
```

### 模板C: 续写

```
你现在加载了烟雨江南的写作风格。

[系统提示词内容]

[1段同类型Few-shot原文]

请用烟雨江南的风格续写以下文本:
[前文内容]

要求保持与前文一致的风格节奏,自然衔接。
```

### 模板D: 对比修正

```
以下是烟雨江南的原文段落(同类型场景):
[原文段落]

以下是AI生成的段落:
[生成段落]

请对比两者的风格差异,从以下维度分析:
1. 句式节奏(断句方式、长短句交替)
2. 描写密度(环境描写占比)
3. 对话风格(引语词、对话节奏)
4. 情感处理(直接/间接)
5. 整体神韵(冷硬感、诗意感)

找出偏差最大的1-2个维度,然后重写生成段落。
```

## 快速启动(3步)

1. 复制 `烟雨江南_系统提示词.txt` 内容
2. 从 `烟雨江南_Few-shot样本.json` 中选2-3段原文
3. 发送指令: "用烟雨江南的风格写一段[场景]"
