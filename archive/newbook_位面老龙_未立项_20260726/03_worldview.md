- **大虞国暗桩**：特产"陈酿"时光含量奇高——因为大虞建在纪元废墟之上（卷一伏笔，卷五回收）。

### 位面体系

- **分级**：微尘 → 小千 → 中千 → 大千 → 主位面。（伏笔：主位面不止一个——卷五炸弹）
- **通道规则**：位面壁垒对强者有排斥（位面意识的自我保护，强者进入会撑爆通道）——低级位面只许低修为进入，主角低修为反而是"富矿微尘位面"的独占优势（前60章核心爽点引擎之一）。
- **位面本源**：最珍贵战利品，时光含量=一个纪元的份量，老龙为之疯狂（剧情发动机+势力争夺核心）。

## 三、力量体系（双轨制，复杂度硬控）

### 轨道一：修行境界（通用框架，读者零门槛）

炼体 → 聚炁 → 灵海 → 神府 → 法相 → 洞天 → 圣人（七境九重）

- 前30章只涉及炼体/聚炁。
- **低武原则**：天花板圣人，但圣人无法正面对抗大势力联军（构装+军阵+圣地底蕴可围杀圣人）——个体强但不碾压组织，保证势力博弈有意义、战力不崩盘。

### 轨道二：构装体系（核心差异化）

**一句话定义**：将灵炁回路（构纹）刻入器物或血肉，形成可战斗的功能单元——这个世界的"军火"。

- **构装师五等**：学徒 → 构装师 → 大构装师 → 宗师 → 圣构装师。社会地位=战略资源，一位宗师可让三级势力坐上二级谈判桌。
- **构装九阶**：一阶~九阶（下中上品）+ 传说构装。
- **四类型**：武装（刻兵器）/ 体装（刻血肉，有排异风险，数量受神府强度限制）/ 领域（刻阵地）/ 载具（浮空舟、战傀）。
- **主角金手指·活构装**：老龙传承的上一纪元技术——构装可吞噬材料**成长进化**（常规构装刻完定型）。
  - **加点公式**：每次进化=材料路线选择（攻/防/诡，选择有成本）；
  - **洗点机制**：重构构装，代价=降一阶（高昂的后悔药）；
  - **防膨胀限制**：活构装成长受主角境界钳制（喂养过度会反噬），且材料越来越稀有——前10章只对"小有帮忙"。

### 轨道三：献祭系统（金手指执行层）

- **规则**：向老龙献祭任何物品 → 老龙按"时光含量"（物品承载的岁月/故事/因果）估值 → 返还赐予。
- **估值公式**（skeptic FIX-3，全书规则最大升级）：**估值 = 物品时光含量 × 与献祭者的因果深度**。
  - 买来的古董与主角无因果，含量打骨折——从规则层面封死"扫货刷金"漏洞；
  - 自己用十年的破刻刀反而值钱——"用得越久的东西越值钱"，每次献祭都带情感成本，爽感与情感绑定；
  - 父母的勘测日志=最深因果=规则层面的价值顶点——Ch50情感高潮不是作者偏心，是公式使然。
- **边界规则**（outline-editor recommended_fix）：天机楼"观气术"只能看"时光含量"表象，看不到"因果深度"（因果是献祭者与老龙之间的私密账本）——故宁璎估得出古董价，估不出主角旧物的价；"唯独估不出主角的价"由此获得规则依据，情感钩子与规则统一。
- **赐予类型**：材料 / 功法 / 构纹图谱 / 位面坐标 / 老龙的"指点"（三纪元的知识才是最值钱的）/ 偶尔的龙血淬体。
- **三条限制（防战力膨胀）**：
  1. 估值看时光含量**也看老龙心情**——不是稳定兑换商店，保留随机爽感与喜剧空间；
  2. 老龙初醒极度虚弱，赐予上限低，随献祭总量恢复逐步解锁（金手指与主角同步成长）；
  3. 同一物品不可重复献祭；**活物献祭会激怒老龙**（原则性伏笔，卷五回收：抗税联盟正是反对"以位面为祭"）。
- **四象限定位**：象限B（简单执行+深度收益）——献祭动作一句话可懂，收益深度靠随机性+知识+位面坐标（引出副本线）。

### 战斗方式

1. **构装对战=机制对抗**（非数值碾压）：构纹有克制关系（破甲克铜皮、破幻克隐身），越阶战斗靠构装搭配与临场拆解——读者能看懂"为什么赢"。
2. **军阵与围杀**：高境者也会死于构装军阵，战争戏=构装工事+后勤+位面通道争夺。
3. **献祭临场翻盘**：主角可把战场缴获**当场献祭**换取针对性赐予——但老龙心情不可控，翻盘有喜剧风险（要刀给锅，锅恰好是神器）。
4. **体装排异**：体装构装的排异反应=战斗中的定时炸弹（莫长老的废手=警示牌）。

## 四、社会模式

- **职业贵族制**：构装师/丹师/阵师为贵族职业，构装师居首（位面征战时代，构装=军火，构装师=军工复合体）。
- **位面征税制**：势力掌握位面通道，向下摊派"出征份额"——底层杂役的月例被层层克扣（第1章冲突源）。
- **阶层跃迁三通道**：宗门大比 / 构装师认证 / 位面战功——主角三管齐下，每通道对应一类打脸场景。
- **矛盾五来源分布**：利益（本源争夺）+ 尊严（杂役翻身）+ 观念（抗税vs纳税，卷四后）+ 立场（宗门阵营）+ 环境（位面崩塌威胁）。卷一以利益+尊严为主，观念矛盾卷四接棒——矛盾类型随卷次升级，不重复。

## 五、主题

**等价交换的终极答案**：所有命运赠送的礼物都标好了价格，但总有人默默替你付账——老龙替万界付了三纪元，终局换万界替它付一次。明基调热血向：世界很老，账单很重，但主角始终向上走，老龙始终在插科打诨。

**不悲观三保险**（预筛承诺6）：
1. 主角处境整体向上，压抑场景3章内必释放；
2. 每章≥1个幽默/爽感释放点（老龙喜剧锚点+主角吐槽）；
3. 悲壮只给配角往事与暗线（史诗感来源），不压主角当下处境。
