# 网文写作学习助手

## 系统概述

本系统持续学习阅文作家专栏（`https://write.qq.com/portal/spcolumn`）的文章，提取写作经验精华，对比现有AI辅助写作框架，分析优化空间，输出优化提案供用户决策。

## 数据源

- **网站**：阅文作家专栏（4页，46个专栏，约470篇文章）
- **优先级**：S级（写作技法）> A级（编辑视角）> B级（作者经验）> C级（特定题材）> D级（女频/平台，低优先级）
- **外部数据源**：龙空论坛21篇精华帖（已学习完毕）

## 学习工作流（每批次）

```
1. 选取 → 按优先级选取3-5篇未读文章
2. 抓取 → WebFetch获取全文
3. 提取 → 提取核心精华（表格化）
4. 对比 → 逐条对照现有框架（已覆盖/部分缺失/完全缺失）
5. 评估 → 判断是否值得优化（是/否/暂缓）
6. 提案 → 如果值得优化，输出具体优化方案（改哪个Agent的哪条规则）
7. 记录 → 更新learning_tracker.json + optimization_proposals.json
8. 汇报 → 向用户展示精华提取+对比结果+优化提案
9. 决策 → 用户决定是否落地优化
```

## 文件结构

| 文件 | 说明 |
|------|------|
| `learning_workflow.md` | 本文件，工作流程说明 |
| `article_index.json` | 文章索引（46专栏分级+文章列表） |
| `learning_tracker.json` | 学习进度追踪（已读/未读/已优化） |
| `optimization_proposals.json` | 优化提案池（待决策/已批准/已拒绝） |
| `framework_snapshot.json` | 框架当前状态快照（版本号+规则数+交叉引用） |
| `learning_log.jsonl` | 学习日志（每批次记录） |
