# 主角人味实验 · 探索 6：框架层 + 角色层改动评估

> 实验区文档 · 2026-08-04 · 不参与 lint / 不设配额
> 目的：评估探索 1-5 产出的方法论需要落到框架层（character-designer / chapter-writer）和角色层（顾衡角色卡）的哪些改动，给出优先级和执行方案。

## 一、总览：探索 1-5 产出了什么

| 探索 | 产出 | 成熟度 |
|------|------|--------|
| 探索 1 | 五道工序（生活层/反差层/幽默层/行动层/节奏层） | ✅ 已验证（江城反推） |
| 探索 2 | 四层多维结构模型（L1-L4）+ 顾衡示范卡 + 动作化出口 | ✅ 已验证（示范卡填满） |
| 探索 3 | 送客宴三场景改写验证 | ✅ 已验证（人味从 C→B） |
| 探索 4 | L5 关系生态 + 6 对互动对 + 5 个互动模板 + 物件叙事网络 | ✅ 已验证（9 角色审计） |
| 探索 5 | 6 条性格 DNA + 跨设定验证 + 最小动作清单 | ✅ 已验证（3 设定全通过） |

**核心方法论**：设定是衣服，性格是身体。先立身体（6 条 DNA），再穿衣服（小说设定），最后设计谁撞出谁的火花（L5 生态）。

## 二、框架层缺口诊断

### 2.1 character-designer v1.5 缺口

| 现有结构 | 探索产出 | 缺口 | 严重度 |
|----------|---------|------|--------|
| `personality_extreme`（性格极致，绑设定） | 探索 5：6 条 DNA（不绑设定） | **缺 `personality_dna` 层**——当前角色卡直接从设定开始，没有"剥离设定的纯性格"层 | 🔴 高 |
| `personal_habits` / `weaknesses` / `daily_life` | 探索 2：L1 生存底座 + 动作化出口 | △ 已有字段，但缺"动作化出口"铁律——当前习惯是"描述"不是"可写进正文的动作" | 🟡 中 |
| `show_events` / `scene_sides` / `show_variants` | 探索 2：L3 对外接口 + 探索 4：L5 互动模板 | **缺 L5 关系生态层**——没有互动模板/镜子角色/物件碰撞的设计 | 🔴 高 |
| `identity_contrast` / `appearance_contrast` | 探索 2：L2 性格内核 + L4 动态引擎 | △ 已有反差设计，但缺"恐惧/执念的动作出口"和"成长弧线的行为位移标记" | 🟡 中 |
| 工作流：读大纲→设计角色卡→设计关系网→写文件 | 探索 5：先立 DNA→再穿设定→再设计生态 | **缺"DNA 优先"步骤**——当前流程没有"先剥离设定立性格"的环节 | 🔴 高 |
| 主角 4 型模板（谨慎/莽夫/扮猪/幕后） | 探索 5：6 条 DNA 是跨类型的通用性格 | △ 4 型模板和 DNA 不冲突，但 DNA 应该在 4 型之前——先确认 DNA，再选类型 | 🟢 低 |

### 2.2 chapter-writer v3.2.2 缺口

| 现有结构 | 探索产出 | 缺口 | 严重度 |
|----------|---------|------|--------|
| H3 `character_internal`（内在矛盾+精算失效场景） | 探索 2-3：每章兑现≥1 个动作化出口 | △ H3 已有"精算失效"要求，但没要求"每章兑现 DNA 动作出口" | 🟡 中 |
| 5.6 角色（每章≥1 个与剧情无关的个人细节） | 探索 1：五道工序 + 探索 4：互动模板 | **缺"人味互动"倾向**——没有"每章至少用 1 个互动模板产出碰撞人味"的要求 | 🔴 高 |

### 2.3 流程层缺口

| 现有流程 | 探索产出 | 缺口 | 严重度 |
|----------|---------|------|--------|
| 大纲 → 角色设计 → 章节写作 | 探索 5：先立 DNA → 再穿设定 → 再写剧情 | **缺"DNA 优先"流程**——角色设计阶段没有"先剥离设定立性格"的强制步骤 | 🔴 高 |

| 无 | 探索 4：白霜提前到 Ch2 | **需调整大纲**——白霜出场从 Ch51 改到 Ch2 | 🟡 中 |

## 三、框架层改动方案

### 3.1 character-designer v1.6 改动清单

#### 改动 1：新增 `personality_dna` 字段（🔴 高优先）

**位置**：角色卡格式中，`personality` 字段之前

**字段结构**：
```json
"personality_dna": [
  {
    "trait": "看透强迫症",
    "definition": "看人看事非要看到底，看不到就慌——不是能力，是性格驱动",
    "setting_free": true,
    "action_outlets": [
      "进任何空间先数人/物件/出口",
      "和人说话先看手再看眼",
      "看准后手指敲两下（满足标记）"
    ]
  }
]
```

**规则**：
- 主角必须有 ≥6 条 DNA 特质
- 每条 DNA 必须有 `definition`（不依赖设定的定义）+ `action_outlets`（≥3 个不依赖设定的动作）
- `setting_free: true` 表示这条特质经验证不依赖小说设定
- DNA 在角色卡中排在最前面——写手首先看到的是"这个人"，其次才是"他的设定"

**与现有字段的关系**：
- `personality_dna` 是"身体"（先立）
- `personality` / `identity_contrast` / `personality_extreme` 是"衣服"（后穿）
- `personality_extreme.core_trait` 必须能追溯到某条 DNA 特质

#### 改动 2：新增 `interaction_ecology` 字段（🔴 高优先）

**位置**：关系网格式中，每对关系新增字段

**字段结构**：
```json
{
  "character_a": "顾衡",
  "character_b": "白霜",
  "relationship_type": "盟友",
  "collision_type": "冷热对冲",
  "interaction_template": "白霜接顾衡的冷话茬→顾衡回一句更冷的→白霜被噎住→张爷打圆场",
  "object_collision": "顾衡的破碗 × 白霜的银耳铛——穷体面对照",
  "human_flavor_output": "节奏喘息 + 幽默控场 + 生活底色",
  "description": "...",
  "evolution": [...]
}
```

**规则**：
- 每对关键关系必须设计 ≥1 个 `interaction_template`（碰撞场景模板）
- 每对关系标注 `collision_type`（碰撞类型）+ `human_flavor_output`（产出什么人味）
- 有"情感物件"的角色对，标注 `object_collision`（物件碰撞）

#### 改动 3：新增 `object_ecology` 字段（🟡 中优先）

**位置**：角色卡中，`personal_habits` 之后

**字段结构**：
```json
"object_ecology": {
  "signature_object": "磕了口的粗瓷碗",
  "object_meaning": "穷讲究 / 掌控感的安全物 / 慌时扣下",
  "collision_partners": [
    {"character": "局头", "object": "摔断把的旧瓷盖", "collision": "碎物对峙——两个碎物同时暴露情绪"},
    {"character": "张爷", "object": "布满裂口的老手", "collision": "张爷把糕放在破碗里——破碗终于装了回好的"}
  ]
}
```

**规则**：
- 主要角色必须有 ≥1 个"情感物件"（不值钱但有情感承载的东西）
- 物件必须标注"与谁碰撞时点亮"
- 物件叙事法则：两个"碎物/旧物"在同一场景出现时，必须有 ≥1 次对照

#### 改动 4：工作流新增"DNA 优先"步骤（🔴 高优先）

**当前工作流**：
```
读交接卡 → 读配置 → 设计角色卡 → 设计关系网 → 写文件 → 通知总编
```

**改为**：
```
读交接卡 → 读配置 → 
① 立 DNA（剥离设定，6 条特质 + 动作出口）→
② 穿设定（DNA → identity_contrast / personality_extreme）→
③ 补 L1-L4（生存底座 / 性格内核 / 对外接口 / 动态引擎，每层≥1 动作出口）→
④ 设计 L5 生态（互动模板 + 物件碰撞）→
⑤ 写文件 → 通知总编
```

**关键变化**：第①步"立 DNA"在大纲设定之前完成——角色师先回答"这个人是什么性格"，再回答"这个性格在本书设定里怎么体现"。

#### 改动 5：角色卡新增"动作化出口"铁律（🟡 中优先）

**规则**：角色卡中每个维度的描述，必须附带 ≥1 个 `action_outlet`（可写进正文的动作）。禁止只写形容词不写动作。

**示例**：
- ❌ `"personality": "外冷内热"` → 没有动作出口
- ✅ `"personality": "外冷内热", "action_outlets": ["嘴说不管但身体已经动了", "帮完说不是帮你是你运气好"]` → 有动作出口

### 3.2 chapter-writer v3.3 改动清单

#### 改动 1：H3 新增"DNA 动作出口兑现"（🟡 中优先）

**当前 H3**：要求 `character_internal`（内在矛盾 + 精算失效场景）

**新增**：`character_internal` 中新增 `dna_outlets_used` 字段，标注本章兑现了哪些 DNA 特质的动作出口。

**规则**：
- 每章正文必须兑现 ≥3 条 DNA 特质的动作出口
- 兑现的动作用原文引用（如"他进屋先数了人——三个，不对，少一个"）
- 缺则 detail-reviewer 标记 `dna_insufficient`

#### 改动 2：倾向库新增"人味互动"（🔴 高优先）

**位置**：5.6 角色之后，新增 5.6b

**内容**：
```
### 5.6b 人味互动（探索 4 产出）
- 每章至少使用 1 个"互动模板"产出碰撞人味
- 五个可调用模板：
  ① 斗嘴喘息：紧张局中插入冷热对冲的幽默
  ② 物件对照：两个情感物件同框，不写旁白
  ③ 生活流交叉：剧情间隙插入与剧情无关的日常
  ④ 镜像失态：两个"端着"的人同时露怯
  ⑤ 穷体面对照：两个穷人比"穷讲究"建立认同
- 模板调用标注在 beat_sheet 的 `interaction_template` 字段
```

#### 改动 3：新增"黄金三章人味阈值"（🔴 高优先）

**位置**：H 系列新增 H11（或作为 H3 的子规则）

**内容**：
```
H11: 黄金三章（Ch1-3）人味阈值
前 3 章正文必须出现：
① ≥1 个"掉价的私密细节"（主角在做与剧情无关的事）
② ≥1 个"荒诞反差画面"（具体共置画面，非形容词）
③ ≥1 次"黑色幽默控场"（幽默服务控场/解构/推进关系）
④ ≥1 次"动作代替独白"（用可观察的动作表达情绪）
缺任一项，detail-reviewer 标记 human_flavor_insufficient
```

#### 改动 4：5.7 幽默倾向强化（🟡 中优先）

**当前 5.7**：闷骚式搞笑、语境错位、自我吐槽

**新增约束**：
```
- 幽默不是段子，是角色在紧张局面里解构恐惧、确立掌控、规避暴露的手段
- 每次幽默必须同时服务"缓解紧张" + "展示性格" + "推进关系"至少一个
- 主角底色如果是"掌控者"，幽默就应是"腹黑式冷幽默"，不是"搞笑卖萌"
- 禁止"旁白替爽"：禁止通过角色台词直接告诉读者该觉得爽
```

## 四、角色层改动方案（顾衡）

  ]

### 4.3 给顾衡补 L1-L4 动作化出口

把探索 2 示范卡的"↓ 动作化出口"逐条写入角色卡的对应字段。

### 4.4 给顾衡角色卡新增"非设定动作清单"

```json
"setting_free_actions": [
  "进任何空间先数人/物件/出口",
  "局势最紧时说最轻松的话",
  "看穿后只说半句让对方自己悟",
  "嘴说不管但身体已经动了",
  "遇到看不透的人移开视线",
  "随身带不值钱但保养好的东西"
]
```

这些动作不依赖"读心""断账"任何设定，写手在任何场景都能调用。

### 4.5 调整白霜出场时间

- **当前**：白霜 Ch51 出场
- **改为**：白霜 Ch2 出场（送客宴的第二批客）
- **影响**：需要调整大纲 Ch2-3 的结构，给白霜加"送客宴在席客"的身份
- **恩人暗线**：白霜的"寻恩人"暗线可以延后揭示（Ch51 才开始怀疑顾衡），但她的"人味催化剂"功能必须 Ch2 到位

## 六、执行建议

1. 升级 character-designer → v1.6：新增 `personality_dna` / `interaction_ecology` / `object_ecology` 字段 + "DNA 优先"工作流
2. 升级 chapter-writer → v3.3：新增 H11（黄金三章人味阈值）+ 5.6b（人味互动）+ 5.7 幽默强化 + H3 DNA 兑现

3. 调整白霜出场时间（Ch51→Ch2）

### 第三步：黄金三章重写

1. 用新角色卡 + 新框架重写 Ch1-3
2. 每章校验：H11 人味阈值 + DNA 动作出口兑现 + 互动模板使用

3. 验证通过后，框架升级正式生效

## 七、风险评估

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| character-designer 字段过多导致角色卡臃肿 | 中 | 中 | DNA 层控制 ≤6 条；动作出口每条 ≤3 个；互动模板每对关系 ≤1 个 |
| chapter-writer H11 成为新的"凑阈值"负担 | 中 | 中 | H11 是"有无"校验不是"计数"校验——只查 4 项是否出现，不查出现几次 |
| 白霜提前到 Ch2 打乱大纲结构 | 高 | 中 | 白霜在送客宴只做"人味催化剂"，不推进主线；恩人暗线延后 |
| DNA 与现有 personality_extreme 重复 | 低 | 低 | DNA 是"不依赖设定的纯性格"，personality_extreme 是"设定下的极致化"——前者是身体，后者是衣服 |
| 框架升级后旧角色卡不兼容 | 中 | 低 | 新增字段为 optional；旧角色卡可后续补填；不影响已有章节 |
