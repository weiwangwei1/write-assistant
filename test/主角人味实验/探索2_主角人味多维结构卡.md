# 主角人味实验 · 探索 2：先立主角的多维结构，再设计剧情

> 实验区文档 · 2026-08-04 · 不参与 lint / 不设配额
> 目的：承接探索 1（诊断 + 五道工序），把"事后补人味"升级为"**源头立人**"——在剧情设计之前，先给主角立一个**多维结构**。本文件给出可复用的四层模型、每个维度的"动作化出口"、用江城验证，并给顾衡落地一张示范多维结构卡。

---

## 一、为什么"先立角色，再写剧情"

用户反馈：技术指标可以，但真人看一眼 AI 写的，角色立不住，节奏太平。

根因不是"写得不够用力"，而是**写作顺序错了**：
- 现在：先定剧情（谁欠谁、怎么斗法）→ 再往剧情里塞角色 → 角色沦为"推动剧情的工具"
- 反例：江城（《噩梦惊袭》）的存在感，**不依赖某条剧情**。你抽掉他身处的那场梦，他一个人敷面膜、藏录音笔、怼人，依然立得住。

结论：**一个立得住的主角，先于剧情而存在。** 剧情只是把他放进去，让他的多维结构"被撞出火星"。

四层模型的作用：不是再写一张"更厚的角色卡"，而是给主角一个**可以不依赖任何剧情就成立的"人"**，然后让剧情去承托、去放大、去引爆它。

---

## 二、人味多维结构：四层模型

每一层都回答一个问题，每一层都由**若干个维度**组成。关键铁律：**每个维度必须落到一个"可写进正文的动作/画面/句子"，禁止用形容词收尾。**

| 层 | 回答的问题 | 维度 |
|----|-----------|------|
| **L1 生存底座** | 这个人怎么过日子？ | 谋生 / 住处 / 私密习惯 |
| **L2 性格内核** | 这个人是什么底色？ | 欲望 / 恐惧 / 底线 / 执念 |
| **L3 对外接口** | 这个人怎么跟世界打交道？ | 语言指纹 / 关系行为 / 行动倾向 / 反差并置 |
| **L4 动态引擎** | 这个人会怎么变？ | 成长弧线 / 冲突引爆 |

### L1 生存底座——"下班后的样子"

- **谋生**：靠什么吃饭？收入几何？生活成本是什么？（江城的"接诊生意""为发愁""谨记陌生电话，怕漏单"）
- **住处**：住哪儿、怎么住？住处里有什么物件？（江城的出租屋、睡地板、沙发缝里藏的录音笔）
- **私密习惯**：睡前 / 独处时做什么？不为人知的掉价小癖好？（江城敷面膜、省脑细胞）

**动作化出口**：正文必须出现至少一次"主角在做一件与剧情无关、甚至有点掉价的事"。

### L2 性格内核——"什么驱动他"

- **欲望**：他真正想要什么（不是目标，是底层渴望）？（江城：掌控、知情、不被人摆布）
- **恐惧**：他怕什么？什么会让他失态？（江城：真相被掩盖、自己失控）
- **底线**：什么他绝不碰 / 什么会让他翻脸？（江城：不圣母，但也不越界害人）
- **执念**：什么他放不下、过不去？（江城：那个失踪的女患者）

**动作化出口**：欲望/恐惧/底线/执念各=一个具体动作（见"行动外化"）。禁止"他很渴望掌控"这种结论句。

### L3 对外接口——"怎么跟世界交手"

- **语言指纹**：口头禅、说话节奏、腹黑程度、越紧张越说什么？（江城："准确来说是失踪""我叫郝帅，男模"）
- **关系行为**：对熟人 / 陌生人 / 敌人 / 弱者，态度如何判若几人？（江城：跟胖子贱兮兮、对警察有分寸、对来袭者冷静）
- **行动倾向**：主动出击还是藏拙？交易式还是付出式？（江城：主动替人侦查，报"代价是一件大衣"）
- **反差并置**：那个"荒诞画面"是什么？（江城：格子睡裤 + 卡通拖鞋 + 雨里平静走 30 米）

**动作化出口**：反差必须靠"一个具体共置画面"建立，读者"看见"而非"被告知"。

### L4 动态引擎——"他会怎么变"

- **成长弧线**：他缺什么？会往哪个方向长？（江城：从"看破"到"放下防备"）
- **冲突引爆**：他的哪个弱点 / 软肋会被剧情精准踩中？（江城的软肋：那个患者 / 他不愿承认的在乎）

**动作化出口**：成长不是"变强"，是"某个维度被剧情反复碾压后，态度与行为发生可见位移"。

## 三、江城验证：每个维度都能在原文里找到"动作证据"

| 维度 | 江城 | 原文动作证据 |
|------|------|-------------|
| 谋生 | 心理医生接诊 | "为了节省脑细胞应对明天可能上门的生意" |
| 私密习惯 | 敷面膜 / 藏录音笔 | 睡前敷面膜；警察走后从沙发缝取录音笔 |
| 欲望 | 掌控、知情 | 藏录音笔、记下所有细节、纠正"是失踪不是死亡" |
| 恐惧 | 被真相蒙蔽 | 对"失踪"二字高度敏感，反复抠字眼 |
| 底线 | 不圣母 | "不能！"然后裹紧大衣，拒绝借大衣 |
| 语言指纹 | 黑色幽默 + 抠字眼 | "那你可要小心了，脖子粗也能掰断""我叫郝帅，男模" |
| 反问并置 | 荒诞外表 × 冷静内核 | 睡裤 + 拖鞋 + 雨里走 30 米 + 面对 4 人极度平静 |
| 行动倾向 | 主动出击 + 交易式 | "我替他过来侦查，代价是一件大衣，还有一把雨伞" |

**结论**：江城的"人味"不是天赋，是这四层全部被"动作化"填充到了满分。每个维度都有可被读者"看见"的画面。

## 四、给顾衡落地：一张示范多维结构卡

> 基于《请客》现有角色卡（市井债务解局人 / 读心 / 掌控者），用四层模型重建。**黑色字 = 立结构，灰色字（↓） = 这次必须写进正文的动作出口。**

### L1 生存底座

- **谋生**：靠"替人断账"收酬，但酬劳只收"对方欠别人的账"——不轻易收钱，所以常年穷。茶馆有个角落，赊账的账本快写满了。
  - ↓ 正文出口：进门先看账本，跟掌柜说"今儿这壶茶，还是记我账上"——他穷，但记账记得心安理得。
- **住处**：城南一间半塌的旧屋，下雨漏雨，拿瓦盆接。
  - ↓ 正文出口：接雨声他能听出"谁在撒谎"的节奏——能力与生活勾连，不刻意炫技。
- **私密习惯**：睡前把白天见过的人"重新演一遍"，像过电影；对着一张旧字条发呆。
  - ↓ 正文出口：独处时他把每个人"重演"一遍，最后总停在那个他读不了的人身上。

### L2 性格内核

- **欲望**：不是钱，是"把人心算准"的掌控感。每次看穿，像赌徒翻牌一样满足。
  - ↓ 正文出口：看穿一个人后，他手指会不自觉地敲两下桌面（满足的生理标记）。
- **恐惧**：被反将一军——有人反过来看穿他。
  - ↓ 正文出口：那个"他读不了的人"出现时，他第一次移开视线、拒绝读。
- **底线**：读心但不使诈。他的"干净"，是他唯一自恃的东西。
  - ↓ 正文出口：别人求他骗人，他宁可少收酬也拒绝；一旦有人拿他的"干净"做文章，他翻脸。
- **执念**：那页旧字条上记着的人，他记不清却放不下。
  - ↓ 正文出口：字条读过一百遍，纸角都磨圆了，他就是不敢真正去查。

### L3 对外接口

- **语言指纹**：爱用"账"打比方。越紧张越冷幽默。
  - ↓ 正文出口：口头禅"你心里这本账，记串了"；死局里他反而说最轻松的玩笑。
- **关系行为**：对弱者嘴硬心软但绝不圣母；对故人故意冷淡；对敌人当面拆穿。
  - ↓ 正文出口：给穷人断账收最低价，嘴上却说"就你这点破事，也值当跑一趟"。
- **行动倾向**：主动出击，先数人、再下判断、一句话点破，绝不被动等。
  - ↓ 正文出口：进屋先数人，数完才开口——"五个人，缺一个，你等的那位，不来了。"
- **反差并置**：一身落拓旧衫，捏着个打了磕口的粗瓷碗，越是大局越捏着破碗。
  - ↓ 正文出口：那破碗是心理安全物，谈崩时他转碗，谈成时他把碗放下。

### L4 动态引擎

- **成长弧线**：从"享受看穿"到"学会把自己放进去"——缺的不是能力，是把自己的心交出来。
  - ↓ 正文出口：中后期他第一次"主动读错"一个人，只为护住对方，这是全书的第一个弧光折点。
- **冲突引爆**：那页旧字条上的人，是他唯一的"读不了"，也是全书的软肋；被看穿"他其实在乎"时，他彻底失态。

## 五、这张卡怎么用（流程）

1. **先立卡**：新主角开写前，四层全填满，每层至少一个"↓ 动作化出口"。
2. **再写剧情**：剧情只负责"承托 + 放大 + 引爆"这张卡，不负责定义角色。
3. **每章校验**：写手每章必须至少兑现 1 个"↓ 动作化出口"（生活流 / 反差画面 / 幽默 / 动作外化 / 节奏喘息），缺则退回。
4. **人味阈值**：前 3 章必须出现——①1 个"掉价的私密细节"②1 个"荒诞反差画面"③1 次"黑色幽默控场"④至少 1 次"动作代替独白"。

- 本轮 = 立模型 + 立样板（顾衡示范卡）。
- 下一轮建议：**用这张卡做一次"人味改写"对照实验**——挑顾衡第 1 章《送客宴》，把示范卡里的"↓ 动作化出口"逐条写进重写稿，与原版并排，验证"人味是否真的立得住"。
- 验证通过后：把四层模型 + 动作化出口沉淀进 `character-designer`（角色卡模板）与 `chapter-writer`（倾向库），让"先立主角、再写剧情"成为流程默认。
