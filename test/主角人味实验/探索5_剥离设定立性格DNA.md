# 主角人味实验 · 探索 5：剥离设定，先立性格 DNA

> 实验区文档 · 2026-08-04 · 不参与 lint / 不设配额
> 目的：用户要求"主角的性格跳出小说的框架，先立住主角的特点"。把顾衡从《请客》的设定（读心 / 断账 / 公道先生 / 市井闲人 / 心理学出身）中**完全剥离**，只看"这个人"的性格本身。确认这些特点能否脱离任何小说设定独立成立——放到都市、古代、科幻里，他还是他。

---

## 一、为什么要"剥离设定"

江城立得住的真正原因：**你把"心理医生进梦界"全抽掉，他依然是一个活人。**

| 江城的性格特点 | 是否依赖"梦界"设定 |
|-------------|-----------------|
| 强迫症式留底（藏录音笔） | ✗ 任何故事里他都会这么做 |
| 越紧张越抠字眼（"是失踪不是死亡"） | ✗ 任何故事里他都会这么说 |
| 用幽默解构恐惧（孤儿梗） | ✗ 任何故事里他都会这么干 |
| 荒诞外表下的极致冷静（睡裤+拖鞋+雨里平静） | ✗ 任何故事里他都会这么出场 |
| 不圣母但边界清晰（"不能！"裹紧大衣） | ✗ 任何故事里他都会这么选 |

**结论**：江城的性格 DNA 不依赖任何设定。设定只是"把他放进去"的容器，不是"定义他"的模具。

顾衡当前的问题：他的性格描述全部绑在设定上——"读心""断账""公道先生""心理学出身"。**抽掉这些，他还有什么？** 如果答案是"没了"，说明角色还没立住。

## 二、剥离练习：从角色卡里提取"纯性格"

把顾衡角色卡里的每一句性格描述，剥离设定后看剩下什么。

| 角色卡原文 | 设定层（剥离掉） | 剩下的纯性格 |
|----------|----------------|------------|
| "对'人心'有近乎偏执的掌控洁癖" | "人心"→设定词 | **对"看透"有偏执满足感**——看人看事非要看到底，看到底才踏实 |
| "从不玩弄人心，却非要看穿、算准、捏在手里" | "人心""看穿"→设定词 | **看透但不用来害人**——有洁癖式底线 |
| "享受把一盘乱局里每个人的心思读得清清楚楚" | "读""心思"→设定词 | **享受"全局尽在掌握"的快感**——不是权力欲，是"我全看明白了"的满足 |
| "冷面之下逗趣，越死局越爱吐槽" | "死局"→设定词 | **越紧张越精确、越冷**——压力越大反而越准 |
| "嘴硬心软" | 无设定 | **嘴上说不管，手最快去护** |
| "对'看走眼/漏读'有执念性别扭" | "读"→设定词 | **受不了"没看准"**——看错一次记很久 |
| "掌控欲太强：一旦脱离预料，会短暂失态" | 无设定 | **失控即失态**——唯一的"像普通人"的时候 |
| "走到哪儿都先数一遍在场的人" | 无设定 | **环境强迫症**——进任何空间先盘点 |
| "睡前会把一天见过的人重翻一遍" | 无设定 | **复盘强迫症**——睡前必须过一遍 |
| "年轻时被大火追过，怕火" | 无设定 | **有一个具体的恐惧**——不怕死，怕一种具体的东西 |

剥离后的 10 条纯性格，**没有一条依赖"读心""断账""公道先生"**。这些是顾衡的"人"——设定只是把他放进去的容器。

## 三、顾衡的性格 DNA：六条核心特质

从 10 条纯性格里归并、提炼，得到 **6 条核心性格特质**。每条特质包含：定义 / 不依赖什么设定 / 跨设定验证 / 动作化出口。

---

### 特质 1：看透强迫症——"看不到底就慌"

**定义**：他看人看事非要看到最底层。看到底才踏实，看不到就焦虑、反复琢磨、睡不着。这不是能力，是**性格驱动**——他受不了"没看明白"。

**不依赖什么**：不需要"读心能力"。一个普通人也可以有这种性格——看人先看手、听人说话先找漏洞、进房间先数人。这是"强迫症式洞察欲"，不是超能力。

**跨设定验证**：
- 都市版：他是记者，看人先看微表情，采访前把受访者的所有公开信息翻三遍
- 古代版：他是仵作，验尸先验指甲缝，非要把死因看到底
- 科幻版：他是舰长，见任何外星种族先分析行为模式，不弄明白不开战
- **三种设定下，"看透强迫症"都成立。**

**动作化出口**：
- 进任何空间先数人、数物件、数出口（环境盘点）
- 和人说话时先看手、再看眼、听呼吸（信息采集）
- "没看明白"时会反复追问同一个问题，换三种问法
- 看准后手指不自觉敲两下（满足的生理标记）

---

### 特质 2：越压越冷——"紧张时反而更精确"

**定义**：压力越大、局面越危险，他反而越冷静、越精确、越冷幽默。这不是"掌控者的定力"，是**性格底色**——他的神经系统就是这么长的，越紧张越收敛。

**不依赖什么**：不需要"掌控欲"的设定。一个普通人也可以这样——deadline 前反而效率最高、吵架时反而条理最清。

**跨设定验证**：
- 都市版：被老板当面质问，他反而笑了一下，逐条反驳
- 古代版：被刀架脖子上，他反而指出对方握刀的姿势不对
- 科幻版：飞船警报响起，他反而慢下来，先检查数据
- **三种设定下，"越压越冷"都成立。**

**动作化出口**：
- 局势最紧时，他说最轻松的话（冷幽默控场）
- 别人慌时他反而慢下来（动作节奏反向）
- 紧张时语速变慢、声音变低（不是变大）

---

### 特质 3：看透不用来害人——"洁癖式底线"

**定义**：他能看穿任何人，但绝不拿看穿的东西去害人。这是他的**自尊底线**——"我看透你是我的本事，我不拿它伤你是我的规矩"。一旦有人拿他的"干净"做文章，他翻脸。

**不依赖什么**：不需要"读心""公道先生"设定。一个普通人也可以——看穿同事的谎言但不揭穿、知道朋友的秘密但不传播。

**跨设定验证**：
- 都市版：他是律师，看穿证人说谎但不利用，宁可换个角度赢
- 古代版：他是谋士，看穿主公的心思但不操控，只给建议
- 科幻版：他是心理医生，看穿患者的伪装但不揭穿，等对方自己说
- **三种设定下，"看透不害人"都成立。**

**动作化出口**：
- 看穿后不点破，只说半句，让对方自己悟
- 有人求他"帮我骗人"，他拒绝（宁可少赚钱）
- 有人拿他的"干净"做文章，他当场翻脸（唯一会翻脸的事）

---

### 特质 4：嘴硬手软——"嘴上说不管，手最快去护"

**定义**：他嘴上最冷、最嫌弃、最说"各人管各人"，但手最快去帮。他自己不承认这是善良，他说这是"看不下去"。这不是"嘴硬心软"的标签，是**行为和语言的反差模式**。

**不依赖什么**：不需要任何设定。任何故事里都可以有这种人。

**跨设定验证**：
- 都市版：嘴上说"不关我事"，转头替同事把锅扛了
- 古代版：嘴上说"各人命各人担"，半夜替受伤的人敷药
- 科幻版：嘴上说"按规定办"，私底下帮违规者改了记录
- **三种设定下，"嘴硬手软"都成立。**

**动作化出口**：
- 嘴上说"不管" → 身体已经动了（语言和动作的反差）
- 帮完之后说"不是我帮你，是你自己运气好"（不认账）
- 被人点破"你其实心软"，他变脸（最怕被人看穿善良）

---

### 特质 5：失控即失态——"唯一的破绽"

**定义**：他所有性格的基础是"我能看透、我能掌控"。一旦遇到"看不透"或"失控"的局面，他会短暂失态——不是崩溃，是**像普通人一样慌一下**。这一下是读者觉得"他是人"的瞬间。

**不依赖什么**：不需要"掌控欲"设定。任何"能力强的人"遇到自己能力无效的时候都会这样。

**跨设定验证**：
- 都市版：他看穿所有人，但看不清自己为什么在意某个人 → 失态
- 古代版：他算准所有事，但算不准自己什么时候会心软 → 失态
- 科幻版：他分析所有数据，但分析不了自己的恐惧 → 失态
- **三种设定下，"失控即失态"都成立。**

**动作化出口**：
- 遇到"看不透"的人 → 移开视线、拒绝看（第一次逃避）
- 局面脱离预料 → 手指停住、摸向随身的安全物（破碗/钢笔/钥匙）
- 失态后迅速恢复，但恢复得太快反而暴露他慌过

---

### 特质 6：穷体面——"穷但不寒酸"

**定义**：他穷，但穷得有体面标准。旧衫要洗白、破碗要揣好、赊账要记清。不是"穷且益坚"的鸡汤，是**一种不肯让自己太难看的倔强**——他已经没什么了，仅剩的那点体面不能丢。

**不依赖什么**：不需要"市井闲人"设定。任何故事里的穷人都可能有这种性格。

**跨设定验证**：
- 都市版：月薪三千，但衬衫永远熨平、皮鞋永远擦亮
- 古代版：穷书生，长衫洗得发白但绝不破到露肉
- 科幻版：底层船员，工服旧但叠得整齐、工具磨亮
- **三种设定下，"穷体面"都成立。**

**动作化出口**：
- 随身带一个"不值钱但保养得很好"的东西（破碗/旧笔/磨亮的打火机）
- 赊账记在一个固定的本子上，一笔不差（穷但认账）
- 别人请客他不去，说"吃人嘴软"——其实是怕还不起

## 五、性格 DNA 与小说设定的关系

**设定是衣服，性格是身体。** 先有身体，再穿衣服。

```
性格 DNA（身体）
├── 看透强迫症 ← 设定给它穿上"读心能力"的外衣
├── 越压越冷   ← 设定给它穿上"死局控局"的场景
├── 看透不害人 ← 设定给它穿上"公道先生"的身份
├── 嘴硬手软   ← 设定给它穿上"替人断账"的行为
├── 失控即失态 ← 设定给它穿上"读不清孟守拙"的剧情
└── 穷体面     ← 设定给它穿上"市井闲人旧长衫"的外表
```

**写作顺序应该是：**
1. 先确认性格 DNA（6 条特质 + 动作化出口）→ 这一步不碰任何设定
2. 再把设定"穿"上去 → 每条特质找到它在《请客》世界里的具体表现
3. 写正文时，先写"人"的反应，再写"设定"的反应——读者先认同"这个人"，再接受"他的能力"

## 六、6 条特质的"最小动作清单"

每条特质给 3 个**不依赖任何设定**的动作，写正文时直接用——不管他在什么故事里，这些动作都成立。

### 特质 1：看透强迫症
1. 进任何空间先数人/物件/出口
2. 和人说话先看手再看眼
3. 看准后手指敲两下（满足标记）

### 特质 2：越压越冷
1. 局势最紧时说最轻松的话
2. 别人慌时他反而慢下来
3. 紧张时语速变低变慢

### 特质 3：看透不害人
1. 看穿后只说半句，让对方自己悟
2. 有人求他害人，他拒绝
3. 被人拿"干净"做文章，当场翻脸

### 特质 4：嘴硬手软
1. 嘴说"不管"但身体已经动了
2. 帮完说"不是帮你，是你运气好"
3. 被点破心软，变脸

### 特质 5：失控即失态
1. 遇到看不透的人 → 移开视线
2. 局面失控 → 手摸向随身安全物
3. 失态后恢复太快，反而暴露慌过

### 特质 6：穷体面
1. 随身带一个不值钱但保养好的东西
2. 赊账记清，一笔不差
3. 别人请客不去，说"吃人嘴软"

## 七、与江城的对照

| 特质 | 顾衡 | 江城 | 共通点 |
|------|------|------|-------|
| 看透强迫症 | 数人、看手、复盘 | 藏录音笔、抠字眼 | 都有"必须留底/看透"的强迫 |
| 越压越冷 | 越紧张越冷幽默 | 越危险越说玩笑 | 都用"冷"对抗压力 |
| 看透不害人 | 看穿但不使诈 | 看穿但不越界 | 都有"不利用"的洁癖 |
| 嘴硬手软 | 嘴说不管手去护 | 嘴上拒绝实际帮忙 | 都是语言冷行为热 |
| 失控即失态 | 看不透时移开视线 | 被反问时愣住 | 都有"精算失效"瞬间 |
| 穷体面 | 破碗揣好旧衫洗白 | 睡裤+卡通拖鞋 | 都有"穷但不狼狈"的倔强 |

**结论**：顾衡和江城的性格 DNA 高度同构——都是"看透强迫症 + 越压越冷 + 不害人 + 嘴硬手软 + 失控失态 + 穷体面"的组合。区别只在设定外壳不同。**这说明 6 条特质是"人味主角"的通用 DNA，不是顾衡独有的。**

## 八、下一步建议

1. **用性格 DNA 重写角色卡**：把 6 条特质 + 动作化出口作为角色卡的"第一层"，设定（读心/断账/公道先生）降为"第二层"。写手每章先校验"6 条特质有没有兑现"，再校验设定层。
2. **正文校验标准**：每章正文必须出现 ≥3 条特质的动作化出口，且不依赖设定词（不出现"读心""断账"也能看出来是顾衡）。
3. **跨设定测试**：如果将来开新项目，可以直接把这 6 条 DNA 套到新主角身上——换设定不换性格，减少从零设计角色的时间。
