# test/ — "灵魂"探索工作区

> 目标：回答一个问题——**指纹全对之后，还差什么？**
>
> 基准：烟雨江南三本（罪恶之城 / 狩魔手记 / 永夜君王，原作全本在 `.trae/skills/writer-styles/yanyujiangnan/reference/原作/`）
>
> 现状：我们的章节能通过 style_lint 全部机械指标（句长/了着/连词/破折号/比喻数），叙事引擎四条原则已注入 style_card，但对照原作仍然"差了点什么"。这个工作区研究的就是那"一点"。

## 核心假设

**灵魂不是一个可以加的规则，但"缺灵魂"有可识别的模式。**

机械指纹回答"像不像"，本工作区回答"动不动人"。两者正交：指纹全对而全然不动人是可能的（现状），动人而指纹违规也是可能的（原作常如此——它的短句、它的破折号都在"违规"边缘）。

## 方法：同场景对照实验

每个实验四步：

1. **取样**：从原作中找一段"有灵魂"的段落（读者会被击中、会记住、会截图分享的那种），存入 `samples/`
2. **精读**：拆解作者到底在做什么——不是统计指标，而是：信息放在哪？情感什么时候到？视角给谁？什么东西被刻意没写？
3. **对照**：拿我们同场景类型的段落并排，做差距分析
4. **提取**：产出 1-2 条原则，进 `principles.md`（原则级，不做成 lint 配额——灵魂不能配额化）

## 目录

```
test/
├── README.md           ← 本文件
├── samples/            ← 原作选段（带出处、选它的理由）
├── experiments/        ← 同场景对照实验（每实验一文件）
│   └── exp001-世界重量-狩魔手记序章.md

```

## 产出边界

- 原则进 `principles.md`，标注证据来源；累积 5-8 条后评估哪些进 style_card（以"原则+自检问题"形式，与叙事引擎四条同级）
- **不做的事**：不加 lint 规则、不加审核层、不加配额——这个工作区只产出"写手动笔前的注意力方向"
- 每次实验一个文件，控制在一屏内；原则是浓缩的，示范是引用的，不堆字数
