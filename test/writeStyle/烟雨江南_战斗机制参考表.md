# 烟雨江南 - 战斗机制参考表

> 从三部原文中系统提取，作为每次生成战斗场景时的"世界观骨架"。
> 不用临场编造体系，直接从此表中选取并组合。

## 一、能力等级体系

### A. 狩魔手记 — 能力域+阶位制

| 能力域 | 说明 | 典型能力 |
|--------|------|---------|
| 格斗域 | 近战/防御强化 | 防御强化、格斗专精 |
| 灵能域 | 武器操控 | 冷兵器操控、狙击专精、复杂武器系统指挥 |
| 感知域 | 感知强化 | 视觉强化、微光视觉、远程感知 |
| 类法术域 | 能量操控 | 火焰、能量束 |
| 辅能力域 | 非战斗专精 | 枪械改造、医疗 |

**阶位规则**：
- 每个能力从一阶起步，逐阶提升
- 阶位越高，能力越强，但进化点消耗越大
- 一个人可同时拥有多个域的能力（如：感知域三阶 + 神秘学二阶）
- 低阶能力者给高阶能力者提供的进化点递减
- **关键规则**：五倍的一阶能力者可以压倒一个三阶（数量优势有意义，但有上限）

### B. 罪恶之城 — 等级+构装制

| 等级段 | 对应力量 | 说明 |
|--------|---------|------|
| 1-5级 | 普通职业者 | 初入门槛 |
| 6-10级 | 中坚力量 | 可独当一面 |
| 11-14级 | 高阶战士/法师 | 精英 |
| 15-17级 | 接近圣域 | 一方强者 |
| 18级+ | 圣域强者 | 生命延长，区域级力量 |
| 传奇 | 超越圣域 | 可改变战局 |
| 半神→真神 | 神级 | 点燃神火，凝聚神职 |

**构装规则**：
- 魔纹构装 = 纹在身上的微型魔法阵，提供属性加成或强力技能
- 每人可承载1-4个构装（天资决定上限）
- 构装师极稀少，构装极珍贵
- 构装骑士 = 高阶战士+魔法重甲+全身构装 = 战争终极武力
- **关键规则**：构装可以让使用者"提升整级实力"——这是改变战局的底牌

### C. 永夜君王 — 原力+战兵制

| 等级 | 名称 | 说明 |
|------|------|------|
| 1级 | 一级战兵 | 刚觉醒原力 |
| 2级 | 二级战兵 | 觉醒一个原力相关能力 |
| 3-4级 | 中级战兵 | 家族天赋者最低水平 |
| 5-8级 | 高级战兵 | 精英 |
| 9级+ | 战将 | 天赋惊人，各方争抢 |

**原力规则**：
- 原力分黎明/黑暗两面
- 通过原力潮汐冲击修炼，每次冲击点燃一个节点
- 生死之间才能激发真正潜力（核心理念）
- 黑暗种族依附黑暗原力而存在

## 二、生物兵器体系（狩魔手记专用）

| 分类 | 说明 | 战斗特征 |
|------|------|---------|
| 初阶 | 基础型，结构简单 | 战斗评价：微弱~弱 |
| 中阶 | 复杂化，涉及生化聚能武器 | 战斗评价：中~强 |
| 高阶 | 高度专业化 | 战斗评价：强~极强 |
| 掠食型 | 特殊型，战斗评价远超同阶 | 至少高出两级 |
| 超级生命体 | 顶端存在 | 几乎无敌，需星舰级武器对抗 |

**生物兵器描写要素**（从原文提取）：
1. **外部结构**：甲壳/骨刃/口器/节肢 — 用"短而弯曲，厚实粗重，分成几段"这种精确描述
2. **内部机制**：能量循环/储能结晶/分泌器官 — 用"暗红色的光是能量循环的标志"这种暗示
3. **行为特征**：评估猎物/测试速度/调整策略 — 体现智慧等级
4. **进化标志**：心率变化/甲壳颜色/能量光芒 — 可观测的信号
5. **战斗评价**：用"在体系中评价为微弱"这种相对评价，不用绝对数值

## 三、战斗描写模式（跨作品通用）

### 节奏控制

| 阶段 | 句式 | 段落 | 典型手法 |
|------|------|------|---------|
| 对峙/铺垫 | 中长句 | 大段落 | 环境描写+感知描写+对手评估 |
| 交锋/快推 | 短句连发 | 单句段落 | 动作+结果，一句一段 |
| 转折/高潮 | 短句+感叹 | 极短段落 | "两秒。" "三只。" |
| 余波/收束 | 中句 | 中段落 | 行为暗示+感官细节 |

### 力量体系嵌入方式

**原文手法**（不是罗列数据，而是嵌入观察）：

| 错误（说明书式） | 正确（观察式） |
|-----------------|---------------|
| "甲壳厚度3厘米" | "甲壳接缝处泛着暗红色的光" |
| "骨刃速度每秒40次" | "刀锋以快得不可思议的频率颤动" |
| "能量值剩余43%" | "护盾还能承受两次同样的攻击" |
| "等级：六阶" | "已经达到六阶的她从坑中直接跃出" |

**核心原则**：数据通过角色的观察和判断间接呈现，不直接陈述。

### 全景视角使用规则

- 每场战斗最多用1次
- 不是"从高空俯瞰"这个固定句式，而是自然切换
- 全景段落要包含：宏观后果（火海/废墟/烟柱）+ 个体渺小感的对比
- 全景后直接硬切回个体，无过渡词

### 结尾断点模式

| 模式 | 示例 | 适用场景 |
|------|------|---------|
| 事实陈述 | "城市内接近十万的人口已有一半失去了生命" | 大规模毁灭后 |
| 行为暗示 | "她未再看一眼，消失在苍茫的北国" | 角色离开/转折 |
| 感官细节 | "刀柄上传来冰凉的触感" | 战斗即将开始 |
| 视角切换 | "掠食型超级生命已被完全锁定" | 暗示更大威胁 |

## 四、使用指南

### 写战斗场景时的选取流程

1. **选世界观**：废土科幻→狩魔手记体系 | 奇幻→罪恶之城体系 | 蒸汽朋克→永夜君王体系
2. **定主角等级**：从对应体系中选取一个等级（如六阶能力者/12级战士/三级战兵）
3. **定对手**：从体系中选取对应等级的对手（生物兵器/魔鬼/黑暗种族）
4. **定力量差距**：对手比主角高1-2级，制造压迫感
5. **选描写要素**：从"生物兵器描写要素"中选取3-4项
6. **按节奏控制表安排段落**：对峙→交锋→转折→收束
7. **嵌入力量体系**：用观察式而非说明书式
8. **选结尾断点**：从四种模式中选取最合适的
