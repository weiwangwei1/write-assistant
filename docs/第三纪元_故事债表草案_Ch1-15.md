## 一、本表口径（模型定义）

- **债** = 在读者/角色心里挂下的、必须在未来被兑付的义务。四类：
  ①**契约债**（钱货、字据、机制代价）②**关系债**（承诺、托付、恩仇）③**认知债**（答案被欠着）④**情绪债**（尊严、被记上、被剩下）
- **挂账** = 债第一次出现在读者眼前，且留下**钉子物**（读者记得住的具体物）
- **清算** = 部分清算 / 全清 / 长线；**汇聚高潮 = 同一节点 ≥2 条债同时到期并清算**，单线清算只算"转折"
- **新债铁律**：每笔清算必须长出新债（否则高潮之后没有推进力）

## 四、模型跑出来的 4 个缺口

1. **Ch1 口径要改**：从"B 级爽点章"改记为"**挂账章**"——它的任务是把 D1-D5 五笔账埋稳，不宣称高潮。
2. **Ch4-8 连续五章无汇聚**（正是 outline 自标的"弃书风险段"）：建议 Ch6 做成双债（D6 代价＋获宝期待）、Ch8 做成双债（D7 认知＋D14 世界），避免平推。
3. **Ch1→Ch14 之间只有一次汇聚，间隔 13 章**：建议在 Ch11 加一次小汇聚（D12 记脸＋D9 痕迹＋机制债叠加），把账节点密度提到"3-4 章一次"。
4. **"清算后长出新债"未显式登记**：现散落在各章 `transition_hook` 里、口径不一 → 债表要求逐笔写明新债。

## 五、验证结论

- **模型可用**，且价值超预期：
  ① 给"高潮"一个**可判读判据**（≥2 条债同期清算）——Ch1 的争议（1 条债桌面、0 清算）一次说清；
  ② 自动暴露"平推章"（Ch4-8）与"汇聚稀疏"（13 章一遇）；
  ③ 顺带把"钉子物"变成规划必填项——汇聚那天读者能不能看懂，取决于挂账时钉子是否扎住。
- **待补的一条**：债的**挂账强度**（钉子物是否显眼、是否被过度复用）属人工判断，建议留在单章层由 detail-reviewer 看，不进债表。
- **不建议**把债表做成脚本规则：跨章结构脚本抓不了，硬做只会变成不可判读的规则（违背"不可判读不进规则"原则）。

## 七、黄金三章重排草案（A1 产出 · 债为第一维度）

> 约束：方案 v2（Ch1=位面任务最险一刻，已由 v9.2 落定）＋专名预算 0（不新造专名）＋正文不出现"老龙"＋机制术语不点破
> 原则：**事件是债的载体**——先定三章各清哪几笔、挂哪几笔，再回填 beat

### 7.1 债弧总览

| 章 | 债操作 | 账节点判定 |
|---|---|---|
| Ch1（已定稿 v9.2） | **挂 5 笔，清 0 笔**：D1 字据·铺子 / D2 不开口求人 / D3 城下为什么值钱 / D4 被记上那一眼 / D5 断绳被剩下 | ❌ 挂账章＋转折（不计高潮） |
| Ch2（重排） | **清 2 笔**：D1 部分清算（认罚，铺子抵掉）＋D2 部分清算（不求人——用手艺把"抵店"谈成"以工抵店"，前铺抵出、后作坊留下）；**半揭** D3（城下＝第二纪元古构装残骸） | ✅ 小汇聚（B 级） |
| Ch3（重排） | **清 2 笔 + 挂 2 笔**：D3 升级并兑出（残骸核心＝前纪元遗物通道，四阶级）；D5 部分清算（断绳不响应——"最轻的东西，就是不被收"）；挂 D6（献祭代价，量化起）；D4 一次轻回响（灰自己摊平——被看着） | ✅ **第一次真汇聚（S 级）** |

### 7.2 分章账节点（回填 beat 的口径）

**Ch2 · 交割（B 级小汇聚｜"专业碾压"）**
- 到期：字据到期，柜上收铺。他不求人，递上的是**手艺**：当场把柜上压仓的坏件修好/把抵店的价谈到"留后作坊"——**用算与本事顶掉屈辱**（D1+D2 同期清算＝B 级汇聚）
- 半揭：柜上随口一句"料是好料，可惜不是我要的那路"，或他翻出城里那批"城下出来的东西"的收购记录 → **城下＝第二纪元古构装残骸**（D3 半揭）
- 章末钩子：他把镐插进后作坊的地里——方向朝着城下（期待感型）
- 旧大纲迁移：旧 Ch1"乱局/三冷动作/破城"**不重演**，改为**以回城所见承载结果**（油槽烧黑的墙、巷口仍横着的木板、民兵守住的缺口）——前史只给结果不给过程；旧 Ch2"造物亮出"并入本章的"以工抵店"

**Ch3 · 献祭（S 级第一次真汇聚｜机制首秀）**
- 绝境：夜袭（兽潮残部/头领级）打到城防缺口，现有手段不够，全员要死（旧 Ch3 情境沿用）
- 机制首秀：三级献祭对照（浅祭·老兵铜符／命祭·生辰木牌／**前纪元遗物**·他手里的芯子）——四条规则同章释放（与既有设定一致）
- 同期清算：D3 兑出（芯子烧完无光只有灰＝四阶级，一击灭纹兽）；D5 断绳缠在芯子上一并丢进去——**没烧**（规则①无附着不响应），他捡回来收好 → D5 部分清算＋长线化
- 挂账：D6 代价（指甲缝渗血/耳后冷汗，Ch6 量化为使力时长变短）
- D4 轻回响（异象型，一句，不解释）：烧完的灰里，有一小撮自己聚拢又摊平，像有人顺手抹了一下
- 章末钩子：残骸缺了关键一环 → 位面里有替代物（再进位面的动机，衔接 Ch4）

### 7.3 需要你裁定的三点

1. **旧 Ch1"破城乱局＋三冷动作"的处理**：按上表改为"以回城所见呈现结果"（不重演过程）——若你希望保留"守城夜"的正面戏，它会与"Ch1 已在位面"冲突（除非放到序言或后续闪回，但会拖慢开篇）。
2. **"以工抵店"是否收**：它把 D1+D2 两笔债并成一清，是 Ch2 汇聚成立的关键；代价是"铺子没被夺走"的惨感被削弱（改为"前铺抵出、后作坊留下"）。
3. **D5 断绳的清算方式**：上表用"不响应"（残酷确认，规则自洽）；另一选项是"被收下"（会打开一条新线，但需新增设定解释，且削弱"断绳被剩下"的余味）。
