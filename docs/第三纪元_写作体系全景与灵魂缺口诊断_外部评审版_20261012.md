## 一、项目速览

| 项目 | 内容 |
|---|---|
| 书名 | 《第三纪元》（暂定名） |
| 笔名 | 铁锈生 |
| 目标平台 | 番茄小说 |
| 题材 | 位面入侵 · 献祭流 · 智斗 |
| 规模 | 300 章 / 6 卷 |
| 单章篇幅 | 2400–2600 字（初稿写长、宁删勿补） |
| 当前进度 | 黄金三章（Ch1-3）闭环完成，Ch4 未开写 |
| 质量目标 | 技术分 9.5 / 追读指数 8.5（自定标准） |

**一句话故事**：第三纪元的世界正在崩塌。一个掌控全局的天才构装师顾衡，守一座必破的边境城——因为城下埋着第二纪元的古构装残骸，那是他造物的关键拼图，最后也成了他献祭救城的代价。

**核心循环**：看全局 → 知道缺什么 → 去位面抢资源 → 构装师造出来 → 更强 → 看更大的全局。

**主角设定（设计层）**：
- 顾衡，25 岁，构装师。天赋型主角——"全局掌控"是脑力与性格，不是金手指。
- 三条写作铁律：**无创伤驱动**（过去是"空白"不是"伤口"，不自怜不追忆）；**代价从不示人**（疼和伤都"动作很快地掩掉"）；**不解释**（被问身份一律不答，用实物或行动回应）。
- 远期悬念：他"算不清自己"（齿轮上多出来的一道刻痕是谁留的）——身世线（"另一个自己"恐惧）要到卷 3-5 才展开，黄金三章不碰。

**已有三章**：Ch1《开价》2587 字（位面里向"一只眼睛"全押换命）→ Ch2《交割》2593 字（铺子抵债、以工抵店、开始挖城下残骸）→ Ch3《献祭》2448 字（头兽夜袭，三级献祭对照，献出残骸核心一击灭兽，代价挂账）。三章全文见附录 A。

## 二、体系全景（这套系统是什么）

这不是"用一个 AI 写小说"，而是一套**多智能体协作生产系统**：18 个专业化 AI 角色（Skill），各自有角色定义、输入输出契约、工作规则；彼此**不共享记忆**，全部通过磁盘上的 JSON"交接卡"传递信息。

### 2.1 角色分工（18 个 Skill）

| 环节 | 角色 | 职责 |
|---|---|---|
| 入口 | 总编 chief-editor | 全局编排、任务分发、门禁校验、进度管理 |
| 前置 | 选题筛子 topic-screener / 书名审核 title-reviewer / 质疑者 skeptic | 选题 6 维预筛；书名简介；大纲批判性质疑 |
| 骨架 | 大纲师 plot-architect / 大纲编辑 outline-editor / 设定审核 setting-reviewer / 角色师 character-designer / 命名专家 keyword-expert | 分章 beat、爽点分布、悬念窗口；大纲与角色卡验收；世界观评审；人物关系网与成长弧线；术语命名巡检 |
| 生产 | 写手 chapter-writer | 章节正文生成（核心角色） |
| 审核 | 细节控 detail-reviewer → 去 AI 化 de-ai-processor → 审稿员 quality-reviewer（8 维分+6 读者画像）→ 平台适配 fanqie-adapter → 终审 final-reviewer | 五道关卡 |
| 维护 | 记忆管家 memory-manager / 长线守护 longline-guardian / 人工检查点 human-checkpoint | 分级记忆入库；每 10 章与卷末全局审查；人工介入点 |

### 2.2 三类"代码"

1. **提示词工程**（系统核心逻辑）：`.trae/skills/*/SKILL.md`——每个角色的完整行为规则；
2. **可执行门禁脚本**：`style_lint.py`（文风硬约束校验）、`style_fingerprint.py`（文体指纹比对）、`fix_auditor.py`（修复差异证据）、`emotion_curve.py`（卷级情感曲线）；
3. **状态/数据文件**：大纲、角色卡、设定圣经、伏笔追踪、交接卡等 JSON。

### 2.3 记忆与交接

- **记忆分级**：L0 会话指针 → L1 章节摘要 → L2 卷摘要 → L3 大纲/债务表 → L4 设定圣经/角色卡 → L5 长线评审。
- **交接卡**：写手交 `chapter_draft_{N}.json`（含 beat 表、跨章事实、角色内在线、风格意图），审核方回流 `detail_review_{N}.json`、`quality_review_{N}.json` 等。**正文不内嵌，全部引用文件。**
- **证据链**：任何门禁修复都必须先存快照（pre_lint）再改，改完由 fix_auditor 出"只产证据不判定"的差异卡，供审核员判定是否"为过门禁而伤害文学性"。

### 2.4 实际运行态（与设计态的差别，如实说明）

设计里有"无人值守自动运行器"（auto-runner），但**当前未启用**。真实循环是：
**作者（人）→ IDE 里的 AI 总编/写手/审核子代理 → 脚本门禁 → 文件交接**。
人负责：方向决策、通读验收、争议裁量；AI 负责：执行、自检、出证据。
一部书目前的实际吞吐约"每章 1 轮初稿 + 1-2 轮整改"。

## 三、写作流程（单章完整旅程）

以已完成的 Ch3 为例，单章流水线如下——

| 步骤 | 做什么 | 为什么这么做 |
|---|---|---|
| ① 素材核读 | 读会话指针、章节大纲 beat、角色卡、设定圣经、债务表 | 所有事实以文件为准，防止跨章漂移 |
| ② beat 设计 | 3-6 个 beat，逐个标注 weight（major/minor）与爽点类型（S/A/B/C/reveal/na） | 控制单章密度：黄金三章 beat≤4（major≤3） |
| ③ 写初稿 | 注入风格卡 + 24 技法 + 硬约束 H1-H11 | 初稿写长，宁删勿补 |
| ④ 文风门禁 | `style_lint.py`：L0 阻断项必须清零，L1/L2 为顾问/参考项 | 反 AI 味的硬底线（详见第五节） |
| ⑤ 交接卡 | 填 beat 表、跨章事实、角色内在、人味四项自检 | 让审核员能逐条对账 |
| ⑥ 细节控审核 | `detail-reviewer` 11 层逐句/逐伏笔审读，出问题清单（critical/major/minor） | 微观打磨先于宏观评分 |
| ⑦ 整改轮 | 逐项修改 → 重跑门禁 → fix_auditor 出证据 → 二轮复评至"polished" | 修复必须留证，防过度矫正 |
| ⑧ 后续（设计态） | 去 AI 化 → 8 维评审 → 平台适配 → 终审 → 记忆入库 | 本轮黄金三章尚未走完 ⑧，停在"细节控 polished" |

**Ch3 实测样本**：初稿 2456 字 → lint 修复 2 轮 → 细节控一轮给出 1 major + 10 minor → 作者裁定"推荐集 9 项"整改 → 二轮复评 polished（2448 字）。整个闭环产生 JSON 卡 5 份 + 快照 1 份 + 指纹/证据卡各 1 份。
**合规成本观察**：单章 2448 字，围绕它的过程文档约是正文的 2 倍体量——这是一个值得评审者注意的"注意力天平"问题（见第八节 D6）。

## 四、关键指令与红线（写手/审核侧摘要）

### 4.1 写手硬约束（H1-H11，机器可校验）

| 编号 | 内容 | 校验方式 |
|---|---|---|
| H1 | 篇幅 2400-2600，宁删勿补 | 脚本字数 |
| H2 | lint 前置门禁（挂风格包运行） | 脚本 |
| H3 | 角色确定性追踪：对未确证的信息禁用确定语气 | 交接卡字段 |
| H4 | 单章密度：beat≤4/5、新命名概念≤2、新出场角色≤1、伏笔动作≤3 | 交接卡计数 |
| H5 | 爽点标级：前 2 章无 S/A 时本章必须有 ≥1 个 | 交接卡 |
| H6 | 悬念预算：活跃悬念窗口 ≤3，超限禁新开 | 交接卡+大纲 |
| H7 | 章首/章尾跨章去重（感官通道、意象族、章尾类型） | lint 跨章模式 |
| H8 | 时间线/设定词与设定圣经逐条比对 | lint+审核复核 |
| H9 | 对话占比 35-60%（顾问指标，场景判断优先） | lint |
| H10 | 分段排版，单段≤200 字 | 脚本 |
| H11 | 黄金三章人味阈值：掉价私密细节/荒诞反差/冷幽默控场/动作代独白，四项"有无"校验 | 交接卡 |

### 4.2 写手技法库（5 组共 24 条，A-E 按决策场景分组）

A 章际衔接（如：悬念钝化逐层加码、感官线索呼应与迁移）／B 场景节奏（场景三合一、切镜头、情绪缓冲带、非对称对抗、反差法、大场面段落次序）／C 角色反应（群像主动准备、沉默的处理、极短暂反应、高光代价、动作上发条、同一刺激差异化反应）／D 描写信息（不替读者做功课：禁止作者归纳/明喻显性度管控）／E 机制结构（双重赌注、机制失败对照、认知反差；禁"道德选择题"）。
**另有一条心态规则**：吐槽点与设定信息"展示而非告诉"，每章"感动点保留"。

### 4.3 细节控审核 11 层（审核侧）

逐句违和与断裂 / 句式呼吸与"怕与欲是否可见" / 展示-解释冗余（含 v1.23 新增"氛围克制"：恐怖阴森等标签词不得直说）/ 文笔质感 / 角色确定性匹配 / 跨章事实核验 / 暗线节奏守门（伏笔不跳级、不透支）/ **过度矫正实证**（读 fix_audit 证据卡逐条判定）/ L1 顾问项逐条回应 / 重复模式（意象繁殖/句式模板/节奏单调）/ 叙事技法 18 项对照 + 黄金三章开篇量化。

### 4.4 风格基线（风格包 tiancantudou，摘自尊宝级蒸馏）

- **叙事引擎**：潜力暗示 → 阻碍出现 → 突破预期 → 格局升级（每 3-4 章一个循环）。
- **核心气质**（一句话）：用绵密的画面把读者按进场景里，情节从画面中长出来。
- **关键语言约束**：句长 40.34 字、逗句比 4.48、破折号近乎为零（硬约束）、"着"字只用于进行态画面、连词起段为签名手法。
- **六种情境决策**：开篇环境先于人物 / 信息靠叙述铺陈 / 情感靠环境映射+内心独白 / 出场靠旁人反应+速写 / 战斗靠长句+可视化 / 章末意境钩或悬念钩。
- **三条节奏管控（v2.1，来自上一次黄金三章外部评审）**：转折词单章≤3；主角"沉默模式"单章≤2、三章累计≤4；三短句重锤全书仅 1 次。
- **⚠️ 关键裂缝（如实上报）**：实文风格与上述基线已**实质脱钩**。三章实测：句均长 16-17 字（基线 40）、长句占比 3%（基线 47%）、逗句比 1.6（基线 4.48）——指纹校验 4-5 个维度超阈。作者 2026-09-20 裁决：指纹降为**参考指标不阻断**，"风格以定稿口味为准"（句号为主、长短交错靠段落层级）。**即：名义上挂"天蚕土豆"风格包，实际上写的是另一种更冷、更碎的文体。**这一点请评审者重点判断（见第八节 Q5）。

### 4.5 门禁分层机制（防"为过审而伤文"）

- **L0 阻断**：反 AI 红线（如"不是A是B"滥用、喻体堆叠、禁词）——必须清零；
- **L1 顾问**：风格倾向（篇幅/对话占比/碎段率）——报告但不阻断，由审核员逐条回应；
- **L2 参考**：签名手法频率（"了/着"千字率、破折号）——参考指标；
- **修复留证**：每次修复先存快照、后出差异证据卡——**审核员要判定"这是修文还是毁文"**（这条机制是三次真实事故换来的：删了最好的比喻换平叙、把直接对话改成摘要、为降频率删掉语法必需的虚词）。

## 五、黄金三章：设计意图 vs 实文差距

三章全文见附录 A；以下是我们自己读出的"体感差距"（诚实版）：

**Ch1《开价》**——意图：立人（敢还价、会算、不肯求人）+ 机制首秀（位面交易）。
体感：机制奇观成立（灰雾里睁开的"一只眼睛"报价），"他饿"一段是三章中最有人味的笔墨。但读完，读者记住的是"这个人很能算"，**记不住他这个人有什么温度**。全章唯一的情绪泄漏是结尾"断绳被剩下的滋味有点苦，还有一点他没料到的酸"——只有一句，马上收回去。

**Ch2《交割》**——意图：专业碾压爽点 + 七年铺子失去的隐痛 + 转向城下。
体感：修弩、把"抵店"谈成"以工抵店"写得漂亮（手艺可视化）。但"失去"的处理被主动压掉：幌子摘下、门框绳印还在，他只"看一眼，拍了拍衣摆"就回身。**作者太刻意地让主角不疼，读者也就没有地方可以疼。**全章情绪峰值反而在配角（伙计"弦咬着牙，铮的一声，脆得满院子听得见"）。

**Ch3《献祭》**——意图：S 级第一次真汇聚（三级献祭对照 + 越阶灭兽）+ 代价挂账 + 悬念开窗。
体感：三章中结构最强（浅祭/反例/命祭/越阶四级台阶清晰），灰柱一击、章末矛杆凝霜收得很稳。但**本章最动人的台词属于配角**：老周头"跟了四十年，够了"、被拍飞后"低头看自己的手"。主角顾衡全程零波动（唯一反应是"捏饼的手停了一下，极短暂，又嚼了起来"）。**读者会共情配角，主角却在旁观自己引发的献祭。**这是"灵魂不够"最具体的形状。

**共同画像**：结构、伏笔、节奏、人设"账目"全部对得上（这是体系的功劳）；三章情感色温全冷；三章钩子全是"事"的钩（野心/事件/事件），没有"人"的钩；主角在纸面上**没有一个人**（没有亲人、朋友、同伴、对手的正脸）。

## 六、「灵魂缺口」诊断（五维 + 一条结构性观察）

### D1 角色深度：主角被封在壳里

- 三个设计原则（无创伤驱动/代价不示人/不解释）单独看都是高级选择，**叠加后导致**：过去空白、伤口不外露、情绪不外化——主角在纸上只剩"计算"与"手艺"。
- 自检题：读者读完 Ch1-3——"他想要什么"答得出（不求人、造物、挖城下）；"他疼过什么、怕过什么"答不出。
- 三章内主角与所有人**零关系积累**（先生是交易对手、头目是第一次搭话、老周头是单方面见证）。体系里设计了一个"锚点角色"（守军头目——用凡人的方式把非人化的顾衡拽回地面），但交集直到 Ch3 末尾才发生第一次。

### D2 情感规划：只有数字，没有链条

- 现有工具：每章标注 emotional_intensity（6/6/9）与爽点类型，有卷级情感曲线脚本（够用）。
- 缺的是：**情感逻辑链**——谁对谁的情感、因为什么变化、在哪一章变化。当前三章情感曲线 = 冷、冷、冷。
- 框架内**没有任何机制**要求"情感发生变化"。情绪只是被"标级"，从未被"编排"。

### D3 读者钩子：全是事钩，没有情钩

- Ch1"这辈子不用再求人"（野心钩）→ Ch2"镐朝着城下的方向"（事件钩）→ Ch3"缺的那一环，位面里有"（事件钩）。
- 缺：让读者**在意人物命运**的钩（"她会等到他吗"型）、**关系**的钩（"这两个人之间会怎样"型）。钩子工程做得很精细，但只挂在情节轴上。

### D4 对话潜台词：主角只会说"答案"

- 顾衡所有台词都是"早已想好的结果句"：'饿了'、'没有'、'要'、'料在位面'。每一句都精准，**没有一句说错、吞吐、改口、欲言又止**。
- 配角侧反而有两层：老周头"跟了四十年，够了"（表面答疯不疯 + 潜台词告别）。主角侧零案例。
- 有趣的是：我们**库存里已经有一套对话潜台词原则**（见 D6 库存盘点），只是从未被激活进流程。

### D5 叙事声音：单一声道

- 全篇一种声音：冷、短、硬。统一是优点也是上限——没有第二文本声音（书信/传闻/传说/旁人视角的独立段落），也没有"世界自己的时刻"（不服务情节、只让世界显得活着的段落——我们的库存原则 P001/P011 正是治这个的）。
- 三章中唯一接近"第二声音"的是 Ch3 墙根溃败的群像（扒甲/磕头/喊死），只闪了一下。

### D6 结构性观察：过度工程化的天平

### A1. 第一章《开价》（2587 字）

口子塌了，他反而松了口气。

身后的退路塌成一堵死石，灰尘贴着地皮漫开。进出的路他早看好过，真到了无路可退这天他就不退，这话说得比字据还硬。

他奔的那块料就在前头，压在壳兽窝边的石堆底下。城里的柜上等这东西开工，字据三天前立定，后天日落交不出货，铺子抵给人家，门面那两块幌子，就得连夜换人挂。铺子是他七年攒起来的，从一副担子攒到两间门面，抵出去容易，再攒回来未必有第二个七年。死，他想得很淡。而真正让他夜里睡不着的，是回头去开那个口，求人宽限几天，那种话一出口，往后见谁都矮半头，他这辈子没求过人，宁可拿命来填。

身前二十步，壳兽蹲着低头换爪，壳背一拱一伏，壳缝里透出很轻的哨音。壳纹转得慢，慢，说明它不饿。

他饿。

饿是从前天夜里起来的：最后半块干粮前天晌午就啃完，昨天靠嚼草根顶着，胃里那点空变成一只手，攥着往里拧。昨夜他趴在石棱后头，看壳兽嘴里嚼着东西，听见那嚼声，喉咙滚了一下。他骂了自己半宿：馋一头野兽嘴里的东西，跟拿刀往脖子上比划没分别。这会儿饿又找上来，肚子又叫，在灰里滚出去老远。他按住肚子，等那声音散干净。什么都能忍，可是饿不听话，从不看场合。

他没有动：这地方声音招东西，快也招东西。喘得肺里发疼，肋下那道口子火辣辣地抽，是塌方才添的，气浪扫过来时他正扶着口子的边，石棱贴着肋下刮过去，石头塌起来不认人。抬起手，那只手在抖，另一只手覆上去，按住，压平，等手心实在了才松开。呼吸也得管着，一息，两息，三息，数到数不动，就从头再数。

接着，他做了件怪事：不找路，也不后退。贴着死石蹲下来，把兜里的东西一件一件摸出来，摆在脚边。

一块灰黑的残片，巴掌大小，说不出是石头还是铁，攥在手里多久都焐不热，是锈关城下挖出来的头一块；一块料，拳头大，刚到手，还带着体温，沉甸甸的，是柜上最认的成色。他在袖口上擦掉浮土，摆正，像柜上伙计摆货。

又摸了半天，摸出一截断绳，摆在最边上。绳子是路上捡的，不值钱，他还是摆了上去。万一呢。

三样东西并排摆好，摊开，离他半步远。摆错了的东西，它不看，规矩冷得没道理可讲。他在三样东西后头坐下来，像守摊。

规矩只有一条：没有退路的人，才排得上号。他不做亏本的事，不过这一趟进来，是算过的，从进城那天起攒了三个月，攒的不是钱，是这一步。头一回在城北的死巷，第二回在城外的破窑，他留过半步退路，它都没露面。后来他想通了，有退路的人，排不上号。

三天前进口子，他记住的头一条是少出声：裂隙在身后收拢，灰天压得极低，没有风，连石头都是凉的。他试过：喊一声，远处有东西应；走快些，影子跟上来；点起火，光却是给别的东西看的。两天两夜，他摸清了壳兽的脾气：换爪是它睡前的最后一下，换完爪半个时辰不动。料就埋在它窝边石堆下，压着两层石头，底下是软土。

他要等的，正是它换爪：料到手那一刻，指尖是热的，他很久没摸过这么正的东西，掂了掂才往怀里塞。就在那一下壳兽醒了，他退，它跟，他绕，它等，一路退到口子这边，身后一声闷响，退路塌得比他想的早半天。

灰里还是静的，他坐着，不动，把这半天慢慢挨过去。口子塌，怪不到他头上，可是眼下这里只有他一个人，怨谁都没处去。

灰雾里有了动静：这一回没有风，头顶那片灰慢慢睁开一只眼睛，竖着的，又窄又长。没有脸，没有身子，只有那一道眼睛悬在他头顶。

灰雾整片降了半尺，压到肩上。他没有抬头，连喘气都放到最浅，心跳压到肋骨底下。

壳兽的纹瞬间停住，伏下来，头贴地，一动不动。眼睛不看它，看他摆的那三样东西。

一个数落进他脑子里。不响，不痛，就那么落进来。它报了价。他听得懂。

没急着接话，跟它打交道，先开口的那个，先输。他哑着嗓子，把三天里的第一句话挤出来，道：“贵。”

眼睛没动，那个数也没动，灰里静得人头皮发紧。壳兽的壳纹又转起来，慢，却比刚才快了半分，背后死石里有什么极轻地响了一下。

他蹲着，把那个数掂了几个来回：正好卡在他兜底上，一分不多，一分不少，它比他自己还清楚他的家底。

壳兽贴着地，尾巴绷得笔直，它想退，又不敢动。他把料往前推了一寸，又推了一寸，推料的时候手很稳，指头底下压着的，是那两间门面。眼睛看货比行商毒，旧的新不了，新的旧不了，哪样重哪样轻，分得清清楚楚。

不够。不用它开口，他自己知道不够。他咽了口唾沫，把残片推出去。这是最后一样能押上的东西，推的时候，指节白了一下。就一下。

手收回来，平放在膝上，坐直。那截断绳还在最边上，眼睛从头到尾没看它一眼。静，很久的静。头顶那道眼睛里没有怒气，没有催促，只有他自己的两样东西，被一样一样看过去，看得极慢，最后，眼睛合上一半。

成交。

掌心是空的。料和残片一样没剩，连体温都没留，石头上剩两块印子，凉得很快。身后那堵死石深处，咔地裂开一道暗响。断绳还躺在原地，被剩下的滋味有点苦，还有一点他没料到的酸。他把那截绳子捡起来，起身就走。壳兽没看他，从头到尾一次也没看，它朝着灰雾里那道眼睛的方向低低伏了一下，掉头走回石棱后头。灰雾慢慢升回去，天还是灰的。

他扶着石壁站起来，膝盖发软，站住，等抖完，才迈第一步。塌石堆里裂开的那道缝还在，很窄，风从缝里灌进来，带着灰味，他侧身钻进去，肩膀蹭着石棱。

走了一段，他摸着黑把兜底翻了一遍：料没了，残片没了，肋下添一道伤，只剩半块干粮渣，他捏着那点渣放进嘴里，嚼得很仔细，把手指上的碎屑也抿干净，才接着走。

快出缝的时候，他忽然收住脚：眼睛合上之前，看了他一眼。那一眼不轻，不重，不长，不短，像柜上的先生验完货，顺手把这一笔也记上。他背后慢慢起了层凉意，做买卖的规矩他懂，白看的人情，早晚要还。

缝到了头，外面还是灰天。灰天底下是一片石滩，石滩尽头才是那道回程的裂隙。他在石滩上坐下来重缠肋下的布。再往前走，他没回头，可是塌石、缝口、石滩，这条路他记着。

他摸了摸里兜。空的。

空就空。

锈关城下压着的那些东西，一样都还没动。回去之后，字据认罚，铺子抵掉，换一副镐、三个月的干粮，再挖。这一次他才看明白：城里柜上收的是料，那只看货的眼睛收的，是城下出来的东西。残片一推出去，它看得比看料的时候更慢，更细。料哄得住柜上，哄不住它。

他把下回的数目粗粗估了估：下回只会比这回更贵。

贵不怕。铺子抵了，就当把这七年押上去。求人的话，他一句都不想学着说。城下的东西挖出来，他就能再站到那儿一次，站在它眼皮底下，谈一笔大的。

谈成了，他这辈子不用再求任何人。

这一笔，才是他真正要算的那一笔。

### A2. 第二章《交割》（2593 字）

日头偏西时，他翻过最后一道梁，望见锈关。风从梁上过去，卷着土，城的轮廓在土里浮出来，比走的时候矮了一截。

城还在。东边那段墙塌下去一截，豁口拿乱石堵着，石头垒得急，缝里还插着断矛的木杆。墙根焦黑一片，烟痕爬上半面砖，从烧穿的墙脚拖到拐角；油槽敞着口，槽里早烧空。

进城之前，他先路过一条窄巷。巷口那摞木板还横在路当中，平平摊着，把半条巷子卡住，没人搬。板子被踩脱了边，土里嵌着黑壳的碎渣。

西段那个口子也堵上，碎石掺着黄土堆成一道歪坡，坡面全是脚窝，新的压着旧的。缺口后头蹲着个民兵，矛横在膝上，人在打盹，睫毛上落着薄薄一层灰。石头垒得难看，可是堵得严实。

那些痕迹，是他进裂隙那几天的事。兽潮来过一趟，城没塌干净，人也没死绝，留下的人补的补、堵的堵，而城外那些塌过的地方还空着。他逆着搬石头的人流进城，不快不慢，没人多看他一眼。

他拐进自己那条巷子。铺子在最里头，两间门面，两块幌子还挂着，风一掀一掀，边角起毛。

后作坊落了一层灰。案上没人动过，工具都在老位置。他放下背上的东西，坐了一会儿，摸出一枚旧齿轮，不知从什么上拆下来的，搁在指间慢慢转，指腹沿着齿纹走一遍，翻过去，再走一遍。

转完，他把齿轮搁回案角，锉刀挨着它摆正。明天日落，前铺归别人。

期限这天，日头还压在城西墙头，柜上的人来了。一个先生，两个伙计，后头跟着一辆板车。他把锉刀别回腰上，去开门。

伙计进门先把梯子靠上墙，摘幌子。木钩从铁环里脱出来，磕在墙上，响了两下。先生站在门槛外，把字据抖开，看一眼，又卷回去。

“顾老板，”先生道，“今天到期。料呢？”

“没有。”

先生等着他往下说。他没往下说。先生把字据压在柜台上：“字据在这，交不出货，铺子抵。按行里的规矩，你今天要是有话，可以讲。”

先生等的是一句求人的话。那句话，他到最后也没有说。他在看那堆货。伙计已经动手往车上搬。墙角堆着一堆坏的，伙计搬货绕着走，先搬好的，坏的留到后头，像是要当废料拉走。

他蹲下去，从那堆里抽出一把弩看了看。有枚铜销子滚到脚边，他顺手捡起揣进兜里。

他问：“这堆坏的，你们估了多少？”

先生拨了两下算盘。“坏的算不成钱。三两件拆个销子，剩下的回炉。”

“回炉，是拿钱填炉子。”他把弩搁在膝上，挨个翻，“第一件销子弯，第二件牙口咬偏，第三件没坏，是装倒的。三十几件里，救得动的有二十几件。”

“修好了卖给谁？”先生笑了笑，“这城刚破过，谁买旧货。”

“破过城的城，先紧的不是粮，是家什。”他从腰间抽出锉刀，“墙要补，补墙要锄头要门轴，守夜的兵手里的弩，也得修得好好的。”

说话间，他手上已经拆开那把弩。弯销子退出来，牙口拿锉刀校两道，装回去，扣死，试两下。咬合声一声接着一声，密得匀。伙计的手停在半空，先生手里的算盘也停住，人从案子那头绕过来，站在旁边看。

他扣上最后一下，把弩递过去。“修好了。值多少，你自己看。”

先生接过去，翻两遍，递给伙计。伙计扣一下，弦咬着牙，铮的一声，脆得满院子听得见。

“前铺，抵给你们。”他把锉刀别回腰间，站起来，“后作坊，我留着。”

“后作坊几间黑屋子，值不了几个钱。”先生说，“你要，拿去。”

他点头，补一条：“那堆坏的，我修。修好的归你们，逐件作价，抵到账清。”

先生低头拨了一遍珠子。“够是够。”他抬头，“你图什么？”

“家伙什多，摆得开。”

他顿了一下。“还有一样。修不动的，归我。”

“废料你也要？”

“要。”

先生看他一会儿，却像是不想看懂这个人，冲伙计抬下巴。伙计铺开纸，先生提笔，一条一条写。写到最末，先生翻出柜上的老账，把他名下那一行勾掉。字据对折，递回他手里。

伙计把摘下的幌子卷起，码上车。他站在门框边。框上两道旧印子，幌子绳磨的，还不深。他看一眼，拍了拍衣摆，回身进后作坊。

坏的这一堆没有上车。按新写的条款，它们先归堆到后作坊，等他修。伙计将它们一趟一趟往里搬，搬到最后一筐，指着墙角那几件问：“这些也算？”

先生进来，低头看。那几件东西跟别的坏件不一样，没有锈色，黑得发沉，像是谁拆散一整件东西，把零件丢在这儿。先生拿手背碰一下，很快缩回来。凉，比院子里的石头还凉，一点温都不存。

“料是好料。”他撇嘴，“不是我要的那路。”

伙计问那是什么，先生答不上来，只说早些年柜上收过差不多的，压在库里三十年，没人用得动，后来当了压舱料。

伙计把它们当铁疙瘩丢进筐里，哐当几声。他眼皮动一下。

人走之后，他闩上门，把那几件黑东西挨个摆到案上。案角搁着那枚旧齿轮，旁边是锉刀。他把锉刀往旁边一推，修这些，用不上它。

他翻出一本磨角的册子，翻到记黑件的那几页。城下，黑件一，八文。城下，黑件三，二十文。收自井台翻土的，收自掘墙基的，收自城根下挖菜的半大孩子。每条后头都跟着他自己添的小字，写得实在：打不动，吊不进炉，还不存温。

他把册子合上，拿起案上最长的一件。半截东西，说不准是牙还是爪，榫口断在根上。他把它凑到油灯底下。断口上的纹没有断，还在慢慢往前走，一小步，一小步。

料是死的。什么样的好料，炉火都咬得进去。但这一件路数不一样，纹是打里头长出来的，断都断不死它。本纪元的火，本纪元的铁，一样都管不了它。

他认得这个路数。城下挖出的头一块残片，在他手里揣过三个月，也是这么个凉法，断口上也是这样的纹，慢慢地走。旧世的活，死掉的纪元留下的东西。他手里这几件，是第二个纪元的构装，碎在城里，等人来捡。

柜上认料。肯为这种东西出价的主儿，这里没有。不过他知道，有东西肯出价。残片推过去的时候，那双眼睛看得比看料时慢，比看料时细。那一眼的账，他没忘。

他把黑东西拢到一处，拿旧布盖上。灯花爆一声，油剩下不多，他没添。

城下的土里，这种东西不止这几件。以前他只能等，等翻井台的、掘墙基的把东西带上来。城破过一回，土层松动，底下那层离人近了一截。再往下，就得他自己动手。

后半夜，他清出案面，把坏件分成两摞：能救的，拆料的。墙角黑影里蹲着那具半人高的东西，半边身子钉着甲片，半边露出骨架，螺旋纹从关节里起头，一圈压着一圈往里拧。这是他自己造的构装，还差一样，才能填上心口。

他抹掉甲片上落的灰，从墙根抄起那副镐。镐是老镐，柄上缠过布，布磨破，露出底下的木纹，握上还是顺手。

他在墙根挑了个地方，那儿的土没铺砖，夯过的，敲上去发闷。镐头吃进土里半寸，柄立住，微微朝着后墙偏。

后墙那边，是城心。城心底下，压着死掉的纪元散下来的东西，等人去挖。

镐把上还留着他的手印，朝的是城下的方向。

### A3. 第三章《献祭》（2448 字）

“西墙！裂口又开了！”

夜里的第一声喊，是从墙头上滚下来的。

交割之后，城里的灯连着四夜没敢灭。连日补的口子还没干透，新土一按一个坑。第五夜，西墙外头又有了动静。先是一层闷响，从地皮底下顶上来，接着是裂兽的动静：挤、退，像被什么东西从后头推开。那道补过的口子，新垒的石头被顶得簌簌往下掉。

它们在让路。

墙头上的人先看清了那个东西：比壳兽还高一头，比两个人摞起来还高，壳黑得不反光，火把的光打上去就没了。壳面上是螺旋纹，一圈拧着一圈，收口往里收，拧得比壳兽的纹严实。

有人认出了壳面那圈纹，可是那两个字卡在嗓子里，喊出来只剩半截：“纹兽……头兽！”

弓手先放的箭，叮的一声弹开，连道白印都没留。

它抬了一次爪。城墙根下三排拒马桩齐齐断开，桩后头蹲着的人也断开，断口平得像是铡刀切过的。城墙根下乱作一团：有人扒死人的甲往身上套，套到一半踩进泥里；有人扔了矛喊“我不活了”，跪在碎砖上磕头，磕出闷响，没人去扶。

顾衡蹲在城墙内侧的角落里，背靠砖墙，手里捏着一块干饼，一口一口嚼。硬得硌牙，他嚼得很慢，眼皮都没抬。脚下的砖在抖，他嚼饼的节奏没变。裂兽只在西段聚，东段没动静；来的是残部，可残部里带了一头顶用的。

守军头目把矛往地上一顿，扭过头来：“你到底什么人？”

他没答。头目的手在矛杆上收紧，指节发白；他捏饼的手也紧了一下，碎渣掉在膝盖上。两个人谁都没看谁，手都在用力。

旁边有人哭出了声。他看了那人一眼，低头又咬一口饼，含混嘟囔：“饿着死的更快。”

墙那头，东段的老兵瘸着腿挤过来，怀里摸出一块铜符。铜符边角磨得发亮，正中刻着一个字，摩挲了几十年，看不清了。有人认得那块铜符：跟了他四十年，出操带着，睡觉枕着。

“老周头你疯了！”

老兵没理，过了一会儿才说：“跟了四十年，够了。”

他掌心一紧，铜符碎开。暗铜色的光钻进矛头，铁面上浮起一层铜纹。老兵提矛冲上去。那条瘸了半辈子的腿，这几步蹬得又直又稳。一矛扎进头兽的壳面，裂开一条缝，渗黑汁。而后，螺旋纹转了一下，那条缝合得严丝合缝，像是从没裂开过。

头兽抬爪，把老兵拍飞出去，没吭一声。矛杆断成两截，落点离顾衡不到五步。铜纹从矛面褪干净，连个印子都没留。老周头撑了一把，没撑起来，靠着墙根坐下，低头看自己的手。风把碎铜翻得轻响，没人顾得上看他。

有人学样，攥碎一块玉佩按上矛头。没有光，矛头还是矛头。碎玉渣子攥了满手，那人举着手站在风里，腿一软，跪在自己的碎渣上。手一直没放下来，像举着一件看不见的东西。玉佩值钱，上头却没有命，没有情，攒不下四十年。这世界不认。

再有一个年轻兵从队列里冲出来，手里攥着生辰木牌。木牌碎了，青白色的光，比暗铜色亮。一矛扎进壳面，裂得比老兵那一下深，青纹撑着，螺旋纹合不上。头兽尾巴扫过来，把他拍在墙上，贴着往下滑。倒下之前，他收了一次招，膝盖打软，撑了一下，才站稳。

那个收招的动作，老得离谱。

两鬓白了一片。二十出头的人。

顾衡捏着干饼的手停了一下，极短暂，又嚼了起来。

能伤，杀不死。代价，已经付清。

城墙上静了一瞬，乱都乱不动。所有人都在看那个蹲在角落嚼饼的人。

顾衡把最后一口饼塞进嘴里，拍了拍手上的渣，坐直，把兜里那枚旧齿轮摸出来，指尖在齿上走了一圈，翻过面，又走一圈，收回兜里，站起来。

头目喊：“你干什么，前面的人要死光了！”

他没理。出角落，拐弯，往城北走。

头目又喊：“城北是死路！”

但他没回头，往死路里走。头目在原地站了一息，抬脚跟上，隔着十几步，不远不近。

作坊里，他掀开墙角的一块板，取出两样东西：这几天挖出来的那截芯子，从城北地底那截大东西身上取的，攥在手里，凉得贴着骨头；还有一件他自己造的，巴掌大，铜骨架，里头嵌着四条槽，槽壁的纹是螺旋的，收口往里收，跟头兽壳上那圈一个走法。四条槽，一条都没填过。

回到裂口边，他蹲下。头目凑过来问：“这是什么？”

他把断绳抽出来，缠在芯子上。绳是路上捡的，不值钱，他缠得很仔细。缠完，一并按进第一条槽。

入槽，一声轻响。槽壁没有亮。没有暗铜色，没有青白色，一点颜色都没有。芯子烧成灰。灰是干的、细的，从槽壁渗出来，顺着铜骨架往他手上爬。爬到手腕的时候，指甲缝里渗出血，血让灰吞了，连个印子都没留。

没有光。只有灰。

绳子从灰里滑出来，落在地上，一点没焦。他没看它。

耳后渗出一层汗，他动得很快，像是不想让谁看见。手往下一按，引导器贴住地面。

地，震了一下。

城北方向涌起一层灰，顺着砖缝走，沿着街面走，一路涌到裂口正下方，顺着夯土芯子往上窜。灰柱冲天，将夜色劈成两半，穿过砖石，穿过头兽的壳，从壳里穿出来。整条裂口亮得雪白。而后，灰猛地收回去，收得一丝不剩。

壳裂。光灭。兽倒。

一击。

按着引导器的那只手松开，指节僵着发白，凉气像顺着铜骨架钻进了骨头里，半晌才回暖。他把手缩进袖子里，攥了两下，没让人看见。

兽潮退了，不是被打退的，是头兽一倒，群兽没了方向，互相踩着往后涌，踩出一地碎壳和黑汁。墙头上的兵先回过神，喊声从这头传到那头。

头兽的壳面上，螺旋纹彻底没了，变回一层黑。伤口里没有血，只有灰。

地上，那截断绳还躺着。他弯腰把它捡起来，收好。

灰堆里，有一小撮灰自己聚拢，又摊平，像有人顺手抹了一下。

城墙下安静下来。守军头目看着裂口边的引导器，问：“你守这座城，就为了这东西？”

他指腹蹭着槽壁翻看。第一条槽空了，灰从槽底漏进风里。三条空槽在火把光里亮着，槽壁的纹还泛着微光。一条槽就灭了头兽，三条一起填满，是什么光景？

“剩下的三个呢？”

“料在位面。”

头目愣一下：“一个人去？那里头，进得去出不来。”

他把引导器收进怀里，拍了拍膝盖上的土：“还有三个槽没填。”

他站起来，往城墙内侧走。火光在他身后把影子拉得细长。

头目站在原地，攥着自己那杆断了半截的矛。矛杆上凝着一层薄霜，灰白色，和芯子烧出来的灰一个颜色。他拿拇指蹭了一下，没化；又蹭了一下，霜厚了一层。他把手收回来，揣进怀里，没再看那杆矛。

风从城外吹回来，掠过裂口，往城里去，风里有一丝活人的炊烟味，很淡。

城北地底那截大东西，从今晚起缺了一环。

缺的那一环，位面里有。
