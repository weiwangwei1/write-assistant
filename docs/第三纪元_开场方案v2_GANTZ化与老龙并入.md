## 一、核心决策（全部经用户确认）

1. **完整 GANTZ 化**：Ch1 = 位面任务"最险一刻"进行中；锈关前史延后揭示；黄金三章重排。
2. **老龙 = 献祭对接者体系顶层**（"献祭能得到反馈的最终最大的角色"）：
   - 人人可献祭，但反馈来自**对接对象**，分等级：低能级神灵/恶魔（民间常见渠道，代价小、反馈弱、常坑）→ **老龙**（顶层，需资格）
   - 资格 = 付得起 + 被接单；**新增核心机制：绝境 = 接单门槛（"没有退路的人，才排得上号"）**——GANTZ"死亡→黑球"的同构件；用户已拍板收下（不加例外口子）
   - 卷1 处理：低能存在**仅作传闻**；老龙**部分显现**（一只眼/轮廓/声音/契印级）；**冷化气质**（末世收账人，非喜剧小龙）；**来源不定义**（不归跨纪元种族、不归位面在地者——两条既有硬禁令不碰）
3. **献祭四条规则：加法不改法**——对接者 = 规则背后真相层（第 3 条"不等价惩罚"的暗示答案）；老龙 = 顾衡的隐藏渠道。卷1 不点破。
4. **形态 = "任务—结算"双子结构**：任务由顾衡自主发起（保掌控者人设，不设"任务机构"）；结算（鉴价/兑换/代价）由老龙承担（GANTZ 黑球的活体版，但只做鉴价与信息，**不代打、不全知、不剧透**）。
5. 参照系：罪恶之城老龙（远古存在/契约交易/条件苛刻，见 `zuiezhicheng-analysis/zuiezhicheng-analysis.html` 第 6 节）+ 未立项《献祭万界》资产（`archive/newbook_位面老龙_未立项_20260726/`，可复用）。
6. 与旧账本的关系：**城下残骸、守城动机、"冷动作兑现"结构全部保留**，仅"出现顺序"后置；"城下埋着什么"的挂账由 Ch1 的献祭物（城下挖出的头一块残片）自然承接。

## 五、评审回执与 v9 修订方向（2026-09-20 增补）

**外部评审（对 Ch1 v7）四诊**：①句式同质化（全篇一个节奏，AI 式工整）——与指纹校验 FAIL（句均长 12.77 vs 基线 40.34、长句占比 1.2%）互为印证；②主角像执行程序（冷=无血肉；有"手抖"无"怕"，无欲无惧）；③"算账"词根复读 10+ 次（母题滥用，lint 也只查整片段不查词根）；④钩子全是空头支票（"城下那笔账"对第 1 章读者＝关我屁事，缺具体欲望/危机）。结论：**只有风格空壳，没有故事核心驱动力**。

**v9 修订方向（✅ 已执行，2026-09-20）**：
1. **句式呼吸重构**：长短交错、流动长句承载推理与氛围，短句只留重音——即"风格路线 A（向基线靠）"的实操
2. **血肉三补**：①一个具体的怕（私人的）→ 落地"宁可拿命来填，也不填这句话"；②一个读者秒懂的欲与失（这趟要什么、空手回去会失去什么）→ 落地字据＋七年铺子；③一个非算账的人味瞬间（用户选定＝**「饿」**）→ 4 处贯穿：他饿／馋壳兽嚼食／肚子叫／末尾细嚼干粮渣
3. **算账减频**：12 次 → 4 次（保留：开场"算过"、报价、"记上"、结尾"那一笔"）
4. **钩子具体化**：开头给 immediate stakes（字据后天日落交不出货→铺子抵给人家）；结尾"城下"改为"具体＋关己"（城下挖东西 →"站在它眼皮底下谈一笔大的"→"这辈子不用再求人"）
