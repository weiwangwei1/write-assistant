## 一、处理惯例（沿用 v4.2 / v4.3 吸收外部方法论的做法）

1. 先逐条比对「我们是否已有更强机制」——已有的不重复建设；
2. 判据缺失、不可判读的条目一律不采；
3. 与既有实测矛盾的条目**记录拒绝理由**，防后续重复引入；
4. 只取可判读、可退稿的条目；落地一律「合并进既有条款 / 既有产物」，不净增规则。

## 三、不采 / 拒绝条目与理由（防复引）

### 3.1 第 11 条「增加颗粒度」——拒绝（⚠️ 高复发型建议，重点留档）

原主张：打散长句（每句 ≤15 字）；删除「虽然 / 但是 / 因为 / 所以」等逻辑词；加入五感。

拒绝理由（三条证据）：
1. 「每句 ≤15 字」＝短句连打，正是 Ch1 v7 被外部评审＋读者判「一个节奏到底，一眼AI」的病根（四诊之一）；框架已用 v9 呼吸感重构两轮修订纠正。
2. 与签名风格约束直接冲突：挂载风格包基线**句均长 40.34 字、逗句比 4.48**；且 lint 有**连词下限（3.0/千字）**——「删逻辑词」会让句句短促、更显 AI。
3. 正确解已固化：**长度变化靠段落层级排布 ＋ 短句只留重音（一章 5-8 处）**（chapter-writer 5.1 呼吸感可操作版）；本条实质危害在「短句化＋删逻辑词」两点，「加五感」不构成增量（属既有倾向库常规要求）。

结论：**拒绝，不修改框架**；落档以阻断后续重复引入。

### 3.2 第 10 条「情绪爆发对白」——不采

- 「末句必须是金句」不可判读、强迫产金句必生硬；「短句为主」与「短句只留重音」口径冲突。
- 已有覆盖：「从压抑到爆发」的节奏本身＝爽点闭环「压抑→打压→蓄力→爆发」；台词峰值由章末钩子与签名台词机制管理。

### 3.3 第 12 条「万能黄金提示词」——不采

- 通用八件套＝初始化流程＋章节循环＋交接卡契约的子集；「情绪张力＋伏笔＋反转」已被爽点 / 伏笔 / 债体系**更精确**覆盖。无增量。

## 四、候选采纳点（2026-10-10 用户拍板：全部推进）

> 原则：均为「合并进既有条款 / 产物」，**零净增规则**；每项落地前先定向核读对应 SKILL 现状。

### 候选 A｜情感节奏曲线（plot-architect 轻量产物）
- 目标：卷级「情感节奏曲线」视图——波峰 / 波谷 / 断顿窗口（连续 N 章无强情绪点）标注；是**规划产物**，不是评分、不是新规则。
- 核读项：plot-architect 现状是否有逐章情绪强度字段；与 skeptic「爽点断顿窗口」检查去重（引用而非重复建设）。
- 验收：outline 可直接读出断顿预警；与悬念窗口机制不互相重复。

### 候选 B｜角色卡维度审计
- 以外部 7 维为对照清单，对 character-designer 卡模板做核实审计（预期无缺口或仅个别边缘维度）。
- 产出：维度对照表＋缺口清单（可为空），结论回填本文档附录。

### 候选 C｜氛围直白词加固（最小改动）
- detail-reviewer 第 5 层「情绪克制检测」旁新增「氛围类直白形容词」判据（恐怖 / 阴森 / 诡异 / 瘆人 / 毛骨悚然 / 令人窒息），处置口径：改为光影 / 声音 / 细节间接营造。
- 同步：chapter-writer 倾向库对应条目加备注（不加硬约束）。
- 版本：detail-reviewer v1.22 → v1.23；chapter-writer 视改动范围定（备注级可不动版本）。
- 验收：校准时对现有章节做误报率抽查。
- **已落地（2026-10-10）**：detail-reviewer v1.23 第5层「氛围克制检测」＋第11层 D1 第三细则；chapter-writer v4.5 5.9 D1 第三抓手（含第九节变更史 v4.4 缺条补录）；校准抽查结论：当前定稿（Ch1 v9.2 / Ch2）与归档正文对词表零命中，无误报。同步落档：master_instruction「v4.3变更摘要」、AGENTS 第九节版本引用。
