# 试写 · 黄金三章（第二版 · 修人味）

- **书名**：《天不算我》
- **备选书名**：《天不收》《册外》
- **文风包**：maibao（卖报小郎君，轻快爽文 / 段子手叙事）
- **内核**：秩序是被人为操控的骗局（天道＝一个被人写死的"席位"，反抗者终将被制度招安成新的天道）
- **本稿性质**：节奏＋人味试写稿。未经 lint / 评审流程，只看①开篇是否抓人 ②行文是否有人味、有趣。

## 第二版改了什么（对照第一版被否的两条）

**① 行文没人味、不有趣** → 按 maibao 签名手法重写，H11 四项逐条落地：

| H11 项 | 第一版（缺） | 第二版（落地） |
|---|---|---|
| 掉价私密细节 | 无 | 蹲墙根数铜板数三遍／按袋底歪针脚的补丁／拍裤子越拍越灰／抱着匣子睡 |
| 荒诞反差画面 | 无 | 天雷劈塌邻家屋脊、他蹲着数钱眼皮不抬；穷到叮当，却在雷底下慢条斯理讨价 |
| 冷幽默控场 | 无 | "是门响，不是修的人响"／"厚道的是棺材铺"／燎了人还说"是雷劈歪了" |
| 动作代替独白 | 无 | 顶雷时往右挪半步（不解释），事后焦黑燎到欠债人裤脚 |
| 内心吐槽（签名） | 无 | "对天讨没意见，对张掌柜有意见"／跑路时心里把韩砚骂了个遍／心里道一句可惜（没燎着裤脚，少收八两） |

## 书名

主选 **《天不算我》**。
- 三层意思压一起：天没把我"算"进去（册上无名）／天不"算"我的账（天罚落不到）／天不要我这条命。
- 市井口语，能看见画面，不卖机制、不作贱、有余味。

备选：《天不收》（更冷更狠）／《册外》（更文、更暗示"不在册"）。

## 简介

> 大衍朝的人，抬头三尺都信一句话：天有眼。
>
> 天眼见功过，天雷罚罪孽。谁作了恶，一道白光下来，躲进庙里也没用。
>
> 陆三不信。不是他胆大，是他没空。他欠着三个月房租，妹子小满等着抓药，城南这间破院，明天就得姓赵。
>
> 所以他干了城里最后一门不体面的营生：替人顶雷。
>
> 谁家老爷犯了事、要挨天讨，出得起价，他就往那一站，把雷接下。
>
> 这些年，他挨过刀，挨过棍，饿急了还挨过狗。
>
> 只有一样东西没挨过。天雷。
>
> 满城作恶的人排着队被劈，那道雷绕着他走，一回也没落下来。
>
> 他琢磨了半辈子，也没琢磨明白为什么。
>
> 直到那天，他在雷底下站定，那道雷在他头顶上拐了个弯。

**简介自查**：只给一个能看见的钩子（天雷绕着他走、最后拐了个弯），全篇不解释"天道是什么""他为什么不被管""册上为什么没他"。

## 三章节奏骨架

| | 第一章《顶雷》 | 第二章《册外》 | 第三章《上一个》 |
|---|---|---|---|
| 章首 | 掉价＋荒诞（数铜板／邻家挨雷）＋300 字内立赌注 | 对话即追逃 | 生活流（抓药）后再入局 |
| 推进 | 下单讨价→顶雷现场做局逼债 | 借屠户挡雷→反将官差 | 找雷婆→撞见"天上有人改笔" |
| 爽点 | 挪半步燎债主、当众打脸 | 借天讨反制官差（A 级） | 看穿"雷能被人改" |
| 章末钩子 | "册上没有你" | "已归天。字面意思。" | "这一行早写好了，等你往上走" |
| 钩子方向 | 身份悬念 | 前人失踪的反转 | 逼近主线（制度入口） |
