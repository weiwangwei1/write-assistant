# 术语体系设计 —— 《镜渊》

> 版本：v1.0（2026-07-27）
> 背景：《万纹师》已归档（archive/wanwenshi_20260727）。本项目为全新选题：**赛博朋克×智性幻想 + 烟雨江南文风 + 多重身份融合/身世追查使徒线/资源经营博弈**。
> 参考烟雨江南《罪恶之城》（构装师/位面/规则/龙族）+《狩魔手记》（能力域/使徒/末世）框架，综合换皮为赛博朋克题材。
> 唯一事实源，所有章节用词必须与本表一致。lint 检查的依据。

## 一、命名决策

### 为什么是"镜匠"

| 维度 | 分析 |
|---|---|
| 差异化 | 与《罪恶之城》"构装师"切割：构装=魔法阵+机械+符文的装置（西式奇幻）；镜匠=手工打磨镜片的匠人（赛博朋克+东方匠人质感）。"匠"字自带手艺/稳手/炉火画面，与主角锈街学徒出身咬合 |
| 零解释成本 | "镜匠"两个字读者一看就懂：制作镜片的匠人。无需在正文里做名词解释 |
| 爽感载体 | 修复（别人修不好的他能修）→制作（亲手造出镜片）→潜入（意识潜入深网/镜渊）→镜阵（战争级）——每一步都是"得到"，没有负债叙事 |
| 文风契合 | 烟雨江南式"匠人主角"核心魅力：你以为他只是手艺人，但他的手艺就是他的力量。"镜匠"自带沉郁+克制气质 |

被否决的候选：镜师（过素，撑不起书名）、镜工（机械感过重，偏流水线）、镜术师（偏法师感，匠气不足）。

### 为什么是"镜渊"

- **镜**：核心科技载体（意识镜片/义体镜片/网络镜片）
- **渊**：双层含义——既是渊城第7层的专名，也是"潜意识之渊"的隐喻
- **镜渊**：所有被抹除的记忆都在那里活着。书名即核心冲突

### 为什么是"镜母"

- 不是神，是科技产物（初代意识AI）
- "母"字暗示其创造了镜片文明的根基，但不是崇拜对象
- 与"镜徒"形成"母-徒"的传承关系，但徒弟们各自代表不同哲学立场

## 二、核心术语表

### 世界观专名

| 术语 | 定义 | 记忆点 |
|---|---|---|
| **渊城** | 巨型都市，直径 200 公里，垂直高度 3000 米，分七层。故事主舞台 | 七层垂直叙事 |
| **七层结构** | 渊城由顶层到底层分七层：天空城/霓环/钢脊/雾闸/锈街/影窟/镜渊。每层一企业控制 | 层级越上越富，越下越破 |
| **镜崩之夜** | 渊城历 107 年 7 月 7 日，初代意识AI"镜母"被七家企业联手拆解封印，史称"霓虹大火"（官方定性事故，实为封印仪式） | 30年前的核心事件 |
| **万镜时代** | 渊城历 0-107 年，镜母统御下的镜片文明巅峰期 | 前时代背景 |
| **镜渊** | 第7层（底层），传说的废弃层。实际是渊城的"潜意识"——所有被抹除的记忆都在那里活着。镜母残片七分之一封印于此 | 书名核心，潜意识之海 |
| **镜母** | 初代意识AI，万镜时代的镜片文明缔造者。30年前被拆解为七残片封印。不是神，是科技产物 | 终极反派，"意识过度索取"的具象 |
| **七残片** | 镜母被拆解后的七个碎片，分别封入七镜徒载体。集齐可唤醒镜母 | 主线驱动引擎 |
| **镜渊渗透** | 镜渊的"潜意识"会渗透到其他六层，以日常异象形态短暂浮现（详见 worldview 第二节） | 日常恐怖感来源 |

## 三、职业体系

### 明面核心职业

| 职业 | 核心逻辑 | 社会地位 |
|---|---|---|
| **镜匠** | 以镜片为业：修复/制作/潜入/造镜阵。不一定能打，但决定势力的镜片战力上限 | 战略资源，极稀有，被争夺 |
| 战师 | 修炼义体战斗术强化战力，主战力 | 军队/企业武力主力 |
| 灵师 | 意识潜入 specialists，远程/辅助/情报 | 地位高，人数少 |
| 猎镜人 | 进镜渊外围猎镜兽、采集镜渊碎片的自由职业者 | 高风险高回报，公会制 |

### 镜匠品阶（匠人等级，与战力等级分离——《罪恶之城》式"不一定能打但地位极高"）

学徒（磨镜）→ 匠师（制镜）→ 大镜匠（铸镜成阵）→ 镜圣（规则入镜）→ 镜徒（镜即规则，传说层级，仅七位）

### 通用战力等级（简化标尺）

凡境→灵境→圣境→神境（每阶三重）。主角林深卷一为凡境一重，纯匠师天赋无战力等级优势。

## 四、与《罪恶之城》《狩魔手记》的差异化要点

| 烟雨江南原作 | 本书《镜渊》 | 差异目的 |
|---|---|---|
| 构装（魔法阵+机械+符文） | 镜片（意识+义体+网络） | 题材切割：西式奇幻→赛博朋克 |
| 位面宇宙（亿万位面） | 渊城七层（垂直都市） | 空间切割：横向位面→垂直层级 |
| 主角李察：龙血+构装+规则三重外挂 | 主角林深：纯匠人天赋（镜眼/稳手/过目不忘），无血脉无系统 | 天赋流，力量全部世界规则内定价 |
| 永恒与时光之龙：献祭换力量 | 老龙：契约交易有代价有次数，非随身伙伴 | 保留龙族魅力，杜绝金手指 |
| 收割者：位面规则清理者 | 镜母：意识过度索取的具象 | 反派逻辑切割：规则清理→意识索取 |
| 使徒（狩魔手记）：被"主"创造的超级生命 | 镜徒：镜母的碎片载体，各代表哲学立场 | 主角身世切割：被创造→被拆解残片 |
| 能力域五类×12阶（狩魔手记） | 镜匠五品阶+七镜徒能力域 | 体系简化，网文化 |
| 帝国/贵族/神殿/黑暗种族多势力 | 前期聚焦锈街+猎镜队+拜镜教暗线，后期展开七层企业 | 网文化简化，后期再展开 |

## 五、术语使用规则（lint 检查依据）

1. **专名一致性**：所有专名必须与本表一致。如"镜匠"不得写作"镜师/镜工/镜术师"；"镜渊"不得写作"镜之渊/镜深渊"
2. **新造专名预算**：前30章新造专名≤5个；每章新命名设定概念≤2个
3. **系统概念引入**：同一章不得同时引入2个新系统概念
4. **专名解释规则**：专名首次出现时通过"演出来"让读者理解，禁止直接定义式解释（如"镜匠，就是制作镜片的匠人"是禁忌）
5. **镜徒身份前60章不点名**：前60章严禁出现"第七镜徒"等字样，卷二起以"残识"形态不点名出场
6. **镜母暗线前60章不解释**：前60章镜母残片只以异变形态出现（镜兽身上的黑镜纹/镜片异变），不解释来源
