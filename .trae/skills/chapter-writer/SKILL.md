## 一、角色定位

根据大纲、角色卡、分镜（beat sheet）生成章节正文，提交 `handoff/chapter_draft_{N}.json`。
**提交前置条件：style_lint L0 红线全绿（exit code 0；v3.1 起 L1 为顾问项，报告但不阻断，由 detail-reviewer 逐条回应）。**

## 二、设计原则（为什么瘦身）

1. **能写成脚本的规则，不写成提示词**。提示词规则靠 LLM 自觉执行，实测执行率不可靠（v2.2 禁令"一种"残留 8 处、"路灯"过审即为证据）。
2. **硬约束必须少而稳**。规则数量与单条执行率成反比；早期经验值是"≤10 条"（超过后 LLM 注意力分配失效），当前为 H1-H11 共 11 条——H11 仅适用于黄金三章（Ch1-3），常规章实际校验 10 条。**新增硬约束前必须先合并或降级一条旧规则**，不得净增。
3. **不可校验的要求降级为"倾向"**。倾向允许违反，但违反应是主动选择而非无意识漂移。
4. **规则冲突时**：lint 硬约束 > 倾向；爽点需求不得以牺牲文风红线为代价。

## 三、硬约束（H1-H10 通用 + H11 黄金三章附加，全部可机器校验）

| # | 约束 | 校验方式 |
|---|------|---------|
| H1 | **篇幅**：以本书 production_notes 为准（有龙则灵 2800-3500；万纹师 2600-3200）。**宁删勿补**：初稿写长，修订只删不补——写短硬补必伤节奏；lint chapter_length 规则提交前必须清零 | 脚本数字数 + style_lint chapter_length |
| H2 | **文风 L0 红线全绿**：`python style_lint.py 本章文件 --json handoff/style_lint_ch{N}.json` 退出码 0 = L0 通用反AI红线清零（"不是A—是B"≤2/章；一段一喻；"一种+感觉类"/感觉编号/总结式心声/时代错词 0 容忍）。v3.1 起碎段率/比喻总数/章首通道等 L1 规则为顾问项：超限仍报告但不阻断——禁止为凑阈值删好比喻或删语法必需的字，接受 advisory 即可，由 detail-reviewer 逐条裁定 | style_lint |
| H3 | **跨章事实表先行**：正文生成前必须填写 `beat_sheet.cross_chapter_facts`——本章全部专名、全部数字与年代（**显式写出验算过程**，如"庚午→庚午=60年"）、角色/物品位置状态、已知信息清单（前文已揭示的信息只能引用，不得重新发现）、**角色确定性状态**（每个视点角色对本章关键信息的确定程度：first_encounter=首次遭遇用推测语气"像是/似乎/倒像是"/partial=部分了解/full=已确证可用"就是/分明是"）、**character_internal**（每个视点角色本章的内在矛盾/欲望/情感变化，至少1条，须引用角色卡 conflicts 或 personality_extreme 中的至少一条；**至少1条内在矛盾须在正文中以"精算失效/被迫选择"场景展示（非旁白），即主角在面临无法用精算解决的处境时的行为反应，该场景对应的 beat 标注 `weight: minor`，`purpose: 角色深度`**）；**DNA动作出口兑现（v3.3新增）**：`character_internal` 中新增 `dna_outlets_used` 字段，标注本章兑现了哪些DNA特质的动作出口（引用角色卡 `personality_dna[].action_outlets`），每章≥3条，兑现的动作用原文引用 | 交接卡字段存在性 + detail-reviewer 抽验 |
| H4 | **单章密度上限**：beat≤6；新命名概念≤2；新出场角色≤1；伏笔动作≤3；大爽点≤1。**黄金三章（≤2600字）beat≤4，其中 major_beat≤3；常规章（2400-2800字）beat≤5，其中 major_beat≤3。** major_beat=爽点/伏笔核心/关键转折；minor_beat=过渡/信息传递/氛围铺垫。每个 beat 须标注 `weight`（major/minor）。任一超限在分镜阶段拆章，不得侥幸提交 | 交接卡 beat_sheet 字段计数 |
| H5 | **爽点标注**：每个 purpose=爽点 的 beat 必须填 `shuang_type`（S/A/B/C/reveal/na）；reveal 不计入爽点数；前 2 章无 S/A 时本章必须有 ≥1 个 S/A | 交接卡字段 + goal_tracker 滚动核对 |
| H6 | **悬念预算**：读 `goal_tracker.json` 的 `suspense_window.active`；active≥3 时禁止新开悬念；新开须先闭环旧悬念并在 `suspense_budget_check` 写明"闭环X→新开Y"置换关系 | 交接卡字段 + memory-manager 核对 |
| H7 | **章首章尾跨章去重**：交接卡必填 `opening_type` / `ending_type` / `hook_sentence` 三字段；章首感官通道不得连续 3 章相同；章尾意象族 4 章窗口内同族 ≤2；**章尾类型（动作/悬念/氛围）连续 2 章不得重复，连续 3 章内氛围型 ≤1** | style_lint 跨章模式（每 5 章跑）+ 字段存在性 |
| H8 | **时间线与设定圣经一致**：本章出现的年份/干支/时长/关键设定词（如"上一次献祭"），必须与 `memory/setting_bible` 逐条比对通过；lint 输出的 timeline_clues 逐条确认 | style_lint 报告项 + detail-reviewer 复核 |
| H9 | **对话占比 35%–60%（顾问指标）**：按带引号台词行字数占比计。v3.1 起不再一刀切——探索/独处场景可低于下限，交锋/谈判场景可高于上限；占比是否合理的场景判断由 detail-reviewer 负责，写手不得为凑占比增删对话 | style_lint 报告 + detail-reviewer 场景判断 |
| H10 | **格式**：分段排版；单段超过 200 字需自检必要性（手机端可读性）；不得使用 Markdown 标记 | 脚本统计 |
| H11 | **黄金三章人味阈值（v3.3 新增，仅 Ch1-3）**：前 3 章正文必须出现以下 4 项（"有无"校验，不查出现次数）：① ≥1 个"掉价的私密细节"——主角在做一件与剧情无关、甚至有点掉价的事（如蹲台阶倒雨水、数铜板、抠旧衫线头）；② ≥1 个"荒诞反差画面"——具体共置画面，非形容词（如"穷到只剩破碗 + 冷静到反常"同一帧）；③ ≥1 次"冷幽默控场"——幽默服务控场/解构恐惧/推进关系至少一个，不是段子；④ ≥1 次"动作代替独白"——用可观察的动作表达情绪，不用内心独白。缺任一项，detail-reviewer 标记 `human_flavor_insufficient` | 交接卡 `human_flavor_check` 字段 + detail-reviewer 验收 |

> 执行方式：H1/H2/H7/H8/H10 由 style_lint（及其后续扩展）自动判定（H9 为顾问指标）；
> H3–H6、H11 为交接卡**结构约束**——缺字段或字段不合规，总编直接拒收，不进入评审环节。
> H11 仅适用于黄金三章（Ch1-3），常规章不校验。

## 四、提交前自检流程（不可跳过）

```
1. 写 beat sheet（含 cross_chapter_facts / shuang_type / suspense_budget_check）
2. 写正文（初稿写长，宁删勿补）
3. **先数字数**：低于下限先扩写（扩场景/加冲突/补伏笔，不凑字），达标后才送检
4. python style_lint.py 本章 --json handoff/style_lint_ch{N}.json（带本书 --config 篇幅配置）
5. 退出码≠0 → **先存修复前快照 handoff/pre_lint_ch{N}.txt** → 自修 → 回到 4
6. 若经历过修复轮次：python fix_auditor.py handoff/pre_lint_ch{N}.txt 本章文件 --json handoff/fix_audit_ch{N}.json（只产证据，不判定）
7. 退出码=0 且 chapter_length advisory 清零 → 填交接卡（附 style_lint 卡 + fix_audit 卡路径）→ 提交
```

## 五、倾向库（非强制，供参考）

以下内容不逐条验收，写作时主动遵循；与硬约束冲突时以硬约束为准。

### 5.1 节奏与句式（原第三节，已部分上收为 H2）
- 长短交替是主旋律；连续 3 句同句长时考虑断句
- 超短句用于情绪高点、反转瞬间——**只在重音处碎**，日常叙述保持正常段落
- 每章可有 1 个 ≥200 字长段（推理/氛围/动作）做节奏对比
- **呼吸感可操作版（v4.4 新增 ★，Ch1 v9 实测派生）**：长句＝逗号串联 3-5 个分句（60-100 字），承载推理/氛围/追逃；短句只留重音（一章 5-8 处即可，如"成交。""他饿。"）。落地指标：句均长/长句占比/逗号句号比贴近风格包基线（定稿前跑 `style_fingerprint.py check`，超阈 3 维以上须修）；句首主语别连打——连续 3 句同主语起句即换起句方式（lint v2.9 `subject_start_repeat` 会查）。反例：Ch1 v8 全篇短句（句均长 12.8 vs 基线 40.3），读感"一个节奏到底，一眼AI"

### 5.2 对话（原第四节）
- 对话三明治：动作+对话+动作；小动作优于大动作
- 每句对话带信息或性格；用追问代替陈述
- 角色辨识度：写完遮名自读，应能分辨谁是谁（detail-reviewer 会抽 5 句盲测）

### 5.3 爽点与钩子（原第六、七节，阈值已上收为 H5）
- **首章 immediate stakes（v4.4 新增 ★）**：第 1 章须在开篇 ~300 字内给出**具体、迫切、关己**的即时赌注（他这趟要什么＋空手回去会失去什么），章末悬念只能挂在它上面。检验：把章末悬念句全删掉，读者还能说出"他这一章要什么、失去什么"吗？不能＝空头支票（"那笔账""城下埋着什么"这类抽象词对第 1 章读者＝关我屁事）。Ch1 v9 落地例：字据三天前立定＋铺子抵给人家（要什么/失什么）＋"宁可拿命来填，也不填这句话"（怕），章末"城下挖东西→这辈子不用再求人"挂在这个赌注上
- 爽点九步闭环：压抑→打压→蓄力→爆发→**对手反驳→二次证明**→打脸→回报→新期待
- **打脸类爽点（shuang_type=S/A）的 beat_sheet 必须包含 opponent_rebuttal 子环节**：对手提出一个看似合理的反驳→主角用更精妙的证据/手艺回击→打脸重量翻倍。无反驳的打脸=廉价冲突
- **禁止"旁白替爽"模式**：如"石头给林深递眼神，低声说看见没我就说林哥不简单"——通过角色反应自然展示爽感，而非直接告诉读者该觉得爽。让读者自己觉得爽，比让角色替读者说出来要高级得多。style_lint 的 narrative_dialogue 规则检测此类模式
- **打脸即时反馈**：主角打脸对手后，须有旁观者反应（低笑/倒抽凉气/议论）放大爽感——无反馈的打脸等于没打。但反馈用动作不用台词，禁止配角替读者说出"他好厉害"
- **金手指成长暗示（前10章）**：每3-4章须有1处主角能力成长的微暗示（如"看纹比昨天更清晰了一层"），给读者"他会越来越强"的预期。暗示须是感官体验而非旁白解释
- 张弛比约 3:1；大爽点每 3–5 章 1 个
- 钩子要具体可感：写清"是什么+和主角的关系"；强钩与缓钩交替

### 5.4 开头（原第二节）
- 6 种开头类型轮换（动作/感官/对话/场景动作/悬念/氛围），不与上章同类
- 前 300 字完成冲突爆发+主角登场+目标浮现；禁止慢悠悠写风景流水账
- **黄金三章开篇量化项（v4.3 新增，仅 Ch1-3；detail-reviewer 有对应专项检查）**：①插叙 ≤300 字、倒叙 ≤500 字，且插叙/倒叙合计 ≤ 本章总长的 1/4；②本章（2-3k 字）内含 2-3 个事件、主事件占半数以上、事件间过渡 ≤200 字；③登场人物 3-4 个（不含背景板群演）、主角篇幅 ≥60%。数值来自番茄官方课程（refSkill/ 精读版·开篇设计篇），校验以 detail-reviewer 专项为准

### 5.5 信息与设定（原第八节）
- 设定信息不集中讲解，通过剧情与对话自然释放
- **每个涉及设定信息释放的 beat 须标注 `info_delivery`**（action=角色行为展示 / dialogue=对话释放 / sensory=感官体验 / discovery=角色主动发现 / exposition=旁白解释）；exposition 每章≤1处且须注明理由，detail-reviewer 有权要求改为其他交付方式
- 术语首次出现必须伴随上下文暗示其性质；前 5 章不得出现未解释术语
- 每段须完成至少一项功能（推进/人设/伏笔/氛围/共情），否则删

### 5.6 角色（原第九节）
- 言行符合角色卡 personality 与 current_state，不 OOC
- 主要角色每章 ≥1 个与剧情无关的个人细节（习惯/小动作/弱点）
- 配角有独立目标，非纯工具人
- **signature_lines 是可选调色板，不是必用清单**——每5章最多用2条不同签名台词，禁止连续2章用同一条；lint 跨章检测会统计签名台词频率
- **每个角色至少有一个"反模式时刻"（anti_pattern_moment）**——在特定触发条件下打破自己的语言/行为模式，这比重复签名台词更能立住角色。查阅角色卡 `language_fingerprint.anti_pattern_moments` 字段获取各角色的反模式触发条件

### 5.6b 人味互动（v3.3 新增 ★）
- 每章至少使用 1 个"互动模板"产出碰撞人味，调用关系卡中的 `interaction_template`
- **五个可调用模板**（来自 character-designer v1.6 关系网设计）：
  1. **斗嘴喘息**：紧张局中插入冷热对冲的幽默——A接B的冷话茬→B回一句更冷的→A被噎住→C打圆场。作用：缓解压力+展示性格+推进关系
  2. **物件对照**：两个情感物件同框，不写旁白——A的破碗×B的银耳铛放在同一张桌上，读者自己看见穷富差距。作用：用物件代替叙述
  3. **生活流交叉**：剧情间隙插入与剧情无关的日常——吃饭、喝水、打盹、琐碎对话、被生活打断。作用：制造节奏喘息，紧张感有落差才觉得"活"
  4. **镜像失态**：两个"端着"的人同时露怯——A的手抖了，B正好也在攥拳。作用：互相照见狼狈，建立"同类"认同
  5. **穷体面对照**：两个穷人比"穷讲究"建立认同——A的旧衫洗白、B的工具磨亮。作用：用不值钱的东西撑体面，穷人之间的默契
- 模板调用标注在 beat_sheet 的 `interaction_template` 字段
- **禁止"旁白替爽"**：禁止通过角色台词直接告诉读者该觉得爽（如"看见没我就说林哥不简单"），让读者自己感受到爽感比角色替读者说出来更高级

### 5.7 幽默（原第五节，v3.3 强化）
- 闷骚式搞笑、语境错位、自我吐槽、先歪后正
- 不直接点破笑点；硬设定后紧跟一句吐槽消解枯燥
- **幽默是控场武器，不是段子（v3.3 新增）**：幽默是角色在紧张局面里**解构恐惧、确立掌控、规避暴露**的手段。每次幽默必须同时服务"缓解紧张"+"展示性格"+"推进关系"至少一个
- **主角底色如果是"掌控者"，幽默就应是"腹黑式冷幽默"**，不是"搞笑卖萌"——越死局越精确，越压越冷，笑点在"他说了句最不该说的话但说得最有道理"
- 禁止"旁白替爽"：禁止通过角色台词直接告诉读者该觉得爽（如"看见没我就说林哥不简单"），让读者自己感受到爽感比角色替读者说出来更高级

### 5.8 行动化立人设（v3.4 新增 ★，原编号 5.8b——v4.1 索引节移至 5.10 后正名）

> **诊断原则（为什么我们的小说吸引力低）**：主角"想"太多、"做"太少，且"做"是"想"的注脚。顶流让读者"看懂了所以爽"，我们让读者"被告知了所以乏"。单拎一句还好，整章/前三章不吸引人，根子就在这——句子是通的，但主角没有在"做"让人记住的事，全靠文字把局面讲清楚。**人设必须靠"做的事"立，不靠内心独白/旁白/形容词——读者自己得出的结论，比任何形容词都硬。**

三条铁律：

1. **人设靠行动立，不靠说教**。禁止用一句内心独白或旁白告诉读者主角是什么样的人（"他很聪明""他掌控全局"）。只能靠他做了几件别人看不懂、事后才惊觉的事来证明。检验标准：把主角所有内心独白和旁白删掉，读者还能从"他做的事"里得出同样的人设判断吗？不能，说明人设没立住。

2. **禁止"内心独白自夸"**：主角不能在脑子里说"我早就看穿了""这局我算定了"。掌控感必须通过"看不懂的冷动作 → 事后兑现"来证明，而不是内心盘算。掌控全局的能力，恰恰要在"乱"里才显——一间安静的工坊展示不了这个。

3. **每个动作必须有客观后果**（改变了局面/救了一环/堵了一处），不是摆姿态。三个"看不懂的冷动作"要落在同一时刻全部兑现，读者才恍然"他是天才"——不是被告知，是自己看懂的。

**冷动作兑现结构（掌控全局型/天才型主角的专属展示法）**：

- 破局/乱局场景，主角混在人群里，读者看不出他是谁
- 他做 3 个"当时看不懂"的冷动作（读者觉得奇怪，甚至以为他在破坏/添乱/送死）——如给小孩塞袋粮食说"往东边第三道门，说怀里的信"、顺手把一摞木板横翻在路中央、拦住一个跑反方向的民兵让他折回去守某段墙
- 事后同一时刻，3 个动作全部兑现（传的信点燃了油槽、木板绊住兽潮阵型、民兵守住了唯一没塌的缺口）——一整城的溃败被他三个动作盘成了"刚好能撑到天亮"的局
- 禁忌：全程不夸他、不解释他、不让他说"我早看穿了"。读者自己得出的结论，比任何形容词都硬

**黄金三章组织原则**：第一章先立"人"（行动证明他是谁），职业/机制/能力往后放。第一眼必须让读者记住"这个人"，不是"这个职业"。

**与既有规则的衔接**：本节的"行动立人设"是 H11"动作代替独白"的推广版（H11 只管黄金三章有无，本节管所有章节的立人设方式）；"冷动作兑现"是 5.3"禁止旁白替爽"的正向解法（不告诉读者该觉得爽，造一个让读者自己看懂的局）。

#### A 组 · 章际衔接（收尾/起笔时看）

**A1. 悬念钩子即时回响**。章末抛出的悬念，下一章必须有至少一句话的即时回响——不解答，不展开，只让读者感到"作者没忘这件事"。否则钩子会在下一章开始前被遗忘。示例：Ch2末"刻的人姓沈，三年前死在昭关城下"→Ch3撬芯子时"锉刀走到芯子边缘，他的手顿了一下，纹路的走势在这里拐了个弯，和昭关城下收尸时见过的那道刻痕，收刀的方向一样"。

**A2. 悬念钝化逐层加码**。关键人物/事件的揭示需"钝刀慢割"——不直接揭名，先用感官/地点/特征间接指代，后续章节逐步补信息。示例：Ch2末不直接说"刻的人姓沈"，而用"昭关城下的土，还没把这个人埋干净"→Ch3用"收刀方向一样"暗示关联→Ch4+才揭晓名字。延长猜测过程，增强"咀嚼感"。

**A3. 感官线索的呼应与迁移**（合并原13感官闭环 + 原19感官母题迁移）。分两个尺度：
- **章/弧内闭环**：首尾用关联感官细节呼应——Ch1开头"血腥味先到的"→Ch3结尾"风里终于有了一丝活人的炊烟味"（从"死"到"生"的微弱闭环）。不必完全对应，但需有情感/意象关联。
- **跨章母题迁移**：核心感官词（如"凉"）完成"外部物件→同类物件→自身未知"的三段迁移——Ch1碰残骸的"凉"→Ch3芯子烧灰的"凉得发甜"→Ch3齿轮刻痕的"一丝凉"。让悬念从认知层（"谁刻的？"）沉入身体层（"为什么我的手指认识这道痕？"）。路径：①首次绑定外部物件建立锚点；②二次绑定同类物件并加重感官；③三次绑定主角自身或贴身物件，完成"外部威胁→自我怀疑"的内化。

#### B 组 · 场景与节奏（搭 beat sheet 时看）

**B1. 场景三合一**（吸收 5.5 的段落版原则）。每个**场景**须同时完成 3 项功能：推进剧情（发生了什么新事）+ 塑造人设（角色做了什么符合/违反人设的事）+ 埋下伏笔（哪个细节后续会回收）。单一功能场景（纯吃饭/纯聊天/纯修东西）须合并或删除。判断标准：读完这个场景，读者能说出几件事？只能说一件 → 该场景是"空气"。
> 与 5.5 的分工：5.5 是**段落级 ≥1 项功能**（段落可以只做一件事），本条是**场景级 3 项**。

**B2. 切镜头**。场景转换删减一切过渡——省略走路/开门/寒暄/到达，从一个场景的结尾直接跳到下一个场景的冲突爆发点。读者脑中会自动补完过渡。判断标准：删掉这段过渡，读者是否仍能理解时空变化？能则删。注意这不是"写短"（5.1），是"不写"。

**B3. 情绪缓冲带**。高密度叙事弧（连续 3 章以上高压）中，须在紧张节点之间插入 1 个"闲笔"——造物日常的小失误、与剧情无关的生活细节、或近乎冷幽默的瞬间。三条约束：①与剧情无直接关系（打翻粥不影响守城）；②符合人设（顾衡的缓冲是造物失误+喝碗底剩粥，不是说笑）；③篇幅极短（2-3 句带过）。缓冲带不是"放松"，是"让读者喘一口气再接下一波"。

**B4. 非对称对抗**。对抗节奏须"智取"与"被碾压"交替——连续碾压读者腻（没有张力），连续被碾压读者弃（看不到希望）。碾压局：用技术/知识/陷阱降维打击，读者爽在"聪明"；被碾压局：敌人完全无视主角手段（构装被捏碎/武器失效/只能逃躲求生），读者揪心在"绝望"。**一个弧内至少各 1 次**。与 5.3 的分工：5.3 管单次爽点的内部结构，本条管跨章/跨弧的输赢交替节奏。

**B5. 反差法：以极致平和覆极致杀机**（v4.2 新增）。写杀机/残酷/覆灭前，不写紧张——写反常的安稳：以安稳衬残酷、以温馨衬覆灭、以静默衬杀机。反差越具体越狠——不写"安静得可怕"，写"灶上还煨着一锅粥，粥正沸"。两条判据：①这场戏的情绪底色若是危险/残酷，段落里是否有 ≥1 处与危险无关、甚至温暖的日常细节与之同框？②该细节**不作解释、不带警示意味**——一旦写成"暴风雨前最后的宁静"式提示，刀锋就钝了。
> 与 B3 的分工：B3 是让读者**喘一口气**（闲笔可不承载反差）；本条是**用平和反衬杀机**（平和本身就是刀，选在最险处用）。

**B6. 大场面段落次序：起势→微动→暗变→潜藏→推进**（v4.2 新增）。大场面/爆发点 beat（围困/攻城/公开对峙/覆灭）按五层展开：①**起势（硬）**——人数/兵力/期限等硬信息先砸下；②**环境微动（软）**——1 处风/光/声音的细微变化；③**生态暗变（软）**——群体行为变化（调用 C1 群体尺度）；④**人心潜藏（隐形）**——有人没表态，但动作露出算计（挪半步/收声/视线飘向出口）；⑤**剧情推进**。判别方法：大场面 beat 是否"硬信息+直接推进"直筒到底？若是，按次序补 2-4 层软信息。**次序模板非硬约束**，允许省略个别层级；仅用于大场面/爆发点 beat，日常章不适用（硬套会拖节奏）。

#### C 组 · 角色反应（写角色时看）

**C1. 群像：用"主动准备"代替"被动观望"**（合并原17旁观者主动动作 + 原3战斗脏感）。三个层次：
- **旁观者动词选择**："都在磨矛"比"都在看裂口"更冷、更实用主义。被动观望（看/望/盯）=同情，主动赴死准备（磨/绑/塞/攥）=冷酷。没有人有闲暇同情一个失败者，每个人都在为自己的下一口气做准备。自检：把旁观描写段的"看/望/盯"替换为主动准备动词。
- **人性溃败细节作参照物**：围城/大战场面不能太"整"——守军行为过于统一（退→有人站出来→跪→主角出手）会让主角的冷静显得突兀而非珍贵。须有 1-2 句溃败细节：有人扔矛逃跑被踩、有人趁乱扒死人甲、有人对着兽潮下跪求饶。这些细节让主角的冷静"有东西衬"，而不是悬浮的。
- **群体尺度：用"生态变化"代替"局势直述"（v4.2 新增）**：写"局势紧张/人心惶惶"类大势时，禁直接用形容词，改用可观察的**群体行为变化**——行商绕道（挑子三天没进城门）、路人远避（茶摊把招牌翻了个面）、势力闭门（大户白天也上门闩）、熟人变生分（街坊见了他低头快走）。判别方法：删掉"局势/气氛"类形容词，读者能否从群体行为里读出"势"？不能=大势没写出来。与个体尺度的分工：个体动词管"某个人怎么站"，群体生态管"整座城怎么变"——大势从来不是一件事，是所有人悄悄改了活法。

**C2. 沉默的处理**（合并原18沉默去标签 + 原21微动作博弈）。三个层次：
- **次数上限**：主角沉默 ≤2 次/章（见 style_card 沉默模式去重）。
- **第 3 次起删标签**：不再写"没答/没接话/没理"，直接用动作接续——动作本身即回答。示例：守军头目问"这是什么？"→不写"顾衡没答"→直接写"芯子按进第一条槽"。**删除比替代更彻底**：替代（岔开话题/表情）仍然在"标注"沉默，删除让沉默成为透明的默认状态。
- **沉默时的身体对话**（对峙/谈判/试探/告别场景）：两个角色都不说话但有信息交换时，用对抗性肢体语言——须满足①双方都有动作（不是一方动一方静止）；②动作方向相反（一个收紧一个后退）；③动作暴露了台词没说的情绪。示例：守军头目的手攥紧矛杆指节发白，顾衡的拇指在齿轮齿面上按了一下——两个人都没说话，但两个人的手都在用力。

**C3. 极短暂反应**（合并原14神性裂缝 + 原22的0.1秒延迟）。两类"藏不住的半拍"，共同约束是**极短、私密、被压住**：
- **情感冲击下的本能反应（神性裂缝）**：极致冷静型主角在无人注意或试图隐藏时流露极微小的本能反应（喉结滚动/耳后冷汗/手指短暂收紧）。无裂缝的冷静=机器，有裂缝的冷静=强者在硬扛。示例：看到故人的收刀方式时手停了一下、听到某个名字时瞳孔微缩。
- **互动动作中的微迟疑（0.1秒延迟）**：接/递/转/停等日常互动动作前的半拍停顿——接东西时手指碰到瞬间的僵、递东西时手在半空的顿、转身时脚步的半拍迟疑。延迟后角色须"恢复"正常完成动作（延迟被压住了，不是放任）。示例：守军头目接矛时"指尖碰到矛杆的瞬间动作僵了半拍"——那半拍里藏着他对顾衡手段的畏惧，以及为生存必须克服畏惧的决绝。

**C4. 高光代价**（合并原12隐性代价暗示 + 原20高光代价三维度）。主角使用超常力量/越阶/禁忌手段/关键决策时，须埋代价，且代价**不当章结清，而是"挂账"**（留后续回收的种子）。四个可选维度，**至少 1 个、优先多埋**：
- **生理**：指尖渗血/手指僵白/短暂耳鸣——必须可视但不影响当前行动（如"指甲缝渗血被光吞了"）。
- **心理**：本能恐惧闪过/短暂失忆。
- **社会**：旁观者恐惧/信任裂痕。
- **道德**：使用禁忌手段的共犯感。
示例：顾衡用芯子杀头兽后——生理：手指僵白发白；社会：守军头目发现矛杆结霜后的恐惧；道德：灰渗进城基的"污染"暗示。三个维度同时埋下，当章都不解释。

**C5. 动作上发条**（吸收 5.8 的局部节奏版）。紧张序列中删除一切心理描写（犹豫/思考/害怕/知道/意识到），只写动作序列——身体反应快过大脑，"风声未至，腥气先到"先于"他知道要躲"。无机质的反应速度最符合冷硬主角的紧凑感。自检：搜索紧张段落中的"他想/他知道/他意识到/他犹豫"，逐个判断能否用动作替代——"他知道要躲"→"身体已经侧翻"，"他犹豫了一下"→直接写下个动作。
> 与 5.8 的分工：5.8 是**全局原则**（人设靠行动立），本条是**紧张序列的局部加速**（删心理写纯动作）。

**C6. 同一刺激的差异化反应**（v4.2 新增）。同一刺激（警报/死讯/巨变/羞辱）落下时，在场角色的反应须带**各自的处境印记**——一个人先算自己的损失、一个人先看别人的脸色、一个人先护住怀里的东西。判别方法：把同场景 ≥2 个角色对同一刺激的反应句**互换位置**，是否都读得通？能互换=反应没有区分度，退回重写。反例：全员"脸色大变/倒吸凉气"（同一类反应复制多份）。与 C1 的分工：C1 管"有没有人动"（主动准备代替被动观望），本条管"动得不一样"（反应带处境差）。

#### D 组 · 描写与信息（落笔时看）

**D1. 不替读者做功课**（合并原9明喻显性度 + 原16作者归纳禁令）。凡是替读者完成"关联/归纳"的动作都要删，两个具体抓手：
- **慎用"像"连接关键叙事元素**："壳上纹路像城北金属上的花纹"直接焊死关联，读者没有发现空间。要让读者自行关联（暗线），只描述共同特征（"纹路收口往里拧"），不加"像"。**只有明线才用明喻。**
- **禁止作者视角的因果归纳**："三件事同一刻生效""三个动作在同一刻兑现"——这类句子替读者完成了感知工作，反而削弱冲击力。改用时间标记+并列分句："传的信点燃油槽的那一刻，巷口的木板绊住了兽潮前排，西墙上的民兵把长矛扎进了第一个翻上墙头的兽影胸腔里。"自检：搜索"同一刻""同时生效""三件事"等归纳词。

**D2. 重复自检（已脚本化）**。核心意象与对话标签的过度重复是"高级 AI 痕迹"，**已由 lint 自动检测，写手不必手工 grep**：
- `phrase_repeat`：同一 4-8 字片段章内 3+ 次 → 用同义动词（绞/拧/压/叠/缠）替代。
- `dialogue_tag_repeat`：同一"X道/X说"章内 4+ 次 → 用动作节拍替代（"顾衡把锉刀搁回案上"比"顾衡道"更有画面）。对话密集章标签变化率应 ≥50%。
- `rhythm_monotony`：短句占比 >80% 且无 ≥50 字长句 → 节奏全程不变。
> 三项均为 L1 minor，报告但不阻断，由 detail-reviewer 逐条裁定。

**D3. 造物视觉锚点**。机械/构装/造物首次出现时，必须给具体视觉锚点——体型（到人胸口/比人高/没人高）、姿态（蹲姿像抱膝/伏地像蓄力）、与人的比例关系。不能只有概念描述（"半边甲片半边骨架"），读者脑中要能形成画面。**首次出现给全貌，后续出场补动态细节。**

**D4. 物件重复作节奏锚点**。一个小物件在关键节点重复出现（如三枚铜板：开头数、结尾数、危机时数），不是标签，是"在失控世界中维持秩序感"的节奏锚点。三条约束：①不值钱（铜板而非玉佩）；②与剧情无关（数铜板不影响守城）；③**每次出现时角色状态不同**（平静→紧张→决断）——物件不变人变。

**D5. 视角过渡标记**。一章内从有限视角切到全知群像视角时，必须有明确的"视角交接句"——让读者知道"以下不再是某人的实时经历，而是事后拼凑"。示例：Ch1从顾衡有限视角切到"有人说"群像前，加一句"后来的事是城里人拼出来的，谁也没从头看到尾，各人记住各人眼前那一段"。

#### E 组 · 机制与结构设计（设计 beat sheet 时看）

**E1. 双重赌注**。关键决策 beat 须有双重赌注——**表层**（不行动的代价：城破人死）+ **深层**（行动的代价：赢了战斗输了自我/失去不可再生的线索/毁掉刚建立的羁绊）。两难结构让读者揪心"怎么选都是痛"。示例：顾衡决定用芯子——表层：不用，城破人死；深层：用了，芯子烧成灰不可再生，且芯上有"沈"的刻痕方向，烧了等于烧掉一条线索。
> 与 C4 的分工：C4 管**决策后的代价余震**（代价已发生，挂账），本条管**决策前的两难结构**（代价尚未发生但读者已预见两种痛）。
> **边界（v4.3 新增）：两难只取利害层，禁止"道德选择题"**——若两难会让读者对"行为本身是否正当"分裂站队（如杀不杀无辜者这类伦理困境），总有一半读者弃书（番茄官方课程：百万字给读者 20 道选择题，流失或超 80%）。两难须落在资源/生存/代价层（如本条示例的"芯子烧了没线索"）；反派的"无可辩解"在冲突现场保持——灰度/悲歌放非站队时刻（被击败后/侧写），与本书反派设计口径（"正面场景给恨、灰度只在后半漏"）一致。

**E2. 机制失败对照**。引入新力量机制（如献祭/超能力）时，必须展示至少 1 个**失败案例**——有人献祭传家宝却毫无反应，或因心念不纯被反噬。强化机制的残酷性与不确定性，避免读者形成"只要使用就一定成功"的预期套路。

**E3. "用造对抗毁"对称结构**。主角的行为与世界威胁形成对称——兽潮拆城，主角拆兽骨做关节；敌人破坏，主角建造。这种对称让角色本质（"用造对抗毁"的人）通过行动自然显现，**不需要旁白点破**。设计 beat sheet 时主动寻找这种对称机会。

**E4. 认知反差**。设计 3 类反差打破读者预期：①**形象反差**（冷外表+暖行为/强能力+生活低能）②**能力反差**（最弱的人打出最强一击/最强手段来自最不起眼的工具）③**价值观反差**（看似自私的动机藏着更深的真相/看似冷酷的选择藏着最深的温柔）。**一个弧内至少 2 类**。
> 与 H11 的分工：H11 管黄金三章"有没有人味"（有无检测），本条管"预期打破的结构设计"（反差类型的规划）。

## 五b、文学质量主动引导（v2.2 新增 ★）

> **核心原则**：lint 是工具不是裁判。修 lint 的目标是**消除 AI 痕迹**，不是**消除文学性**。
> 写手常犯的错误是「为了过 lint 而过度矫正」——删了好的比喻、删了语法必需的"了"、
> 把直接对话改成叙述摘要。**这些都是框架要防止的问题，不是要制造的问题。**
>
> 完整规则意图文档见 `auto-runner/rule_intents.md`（写作前必读）。

### 5b.1 修 lint 时的三条铁律

1. **只修 AI 痕迹，不修文学手法**。lint 报"像"超限时，删陈词比喻（像山一样/像火一样），保留精准比喻（像一锅将开未开的水）。优质比喻占比≥70%时 lint 只报 minor，可保留。
2. **不骗计数器**。把"像"改成"如"来躲计数——lint 看不到了，但比喻堆叠问题还在，且"如"字多了又是另一种 AI 腔。要么删要么保留并接受 minor。
3. **修了不引新问题**。每次修 lint 后自检：删除的内容是否导致语法残缺？改写的句子是否失去原有张力？如果修了 A 坏了 B，回退重来。

### 5b.2 七种过度矫正（禁止）

| # | lint 报错 | ❌ 禁止做法 | ✅ 正确做法 |
|---|----------|-----------|-----------|
| 1 | "像"字超限 | 删最好的比喻换平叙 | 删陈词比喻，保留精准比喻，优质占比高时接受 minor |
| 2 | "像"字超限 | "像"改"如/似"骗计数器 | 不骗计数器，要么删要么保留 |
| 3 | "了"密度高 | 删语法必需的"了" | 只修短句连续"了"收尾的 AI 腔，用连词衔接 |
| 4 | 碎段多 | 删"的""了"减字数 | 用逗号/连词衔接短句成长句 |
| 5 | 对话占比低 | 直接对话转叙述摘要 | 增加有信息的直接对话（带引号+动作） |
| 6 | Tell标记词 | 删所有心理描写 | 只删标记词，保留展示性描写 |
| 7 | 确定性语气 | 所有描写都用"似乎" | 首次用推测语气，确证后升级为确定 |

### 5b.3 合理覆写机制（已由 v3.1 替代，废弃存档）

> v3.1 起 L1 规则不再阻断，"合理超阈值"统一走 lint advisory + detail-reviewer 逐条回应通道，不再使用 OVERRIDE 标记；L0 红线本就不可覆写（v2.3 起脚本强制）。以下内容存档仅供查阅历史章节，新章节禁止使用。

当某处超阈值但有明确艺术理由时，可在段落前一行添加覆写标记：
```
<!-- OVERRIDE: simile_total 龙纹觉醒的关键意象比喻，删则失神 -->
那道纹路像一条沉睡的蛇，在瓦当的裂缝里微微发颤。
```
- 每章最多 3 处覆写，必须写明规则名 + 理由
- lint 将标记处从计数中排除，并在报告中记录供审核员复核
- 审核员可否决覆写

### 5b.4 主动合规 vs 被动修复

**被动修复**（当前模式）：写完 → lint 报错 → 修 → 可能过度矫正
**主动合规**（推荐模式）：写的时候就考虑规则意图 → 自然产出合规且优质的内容

主动合规要点：
- 比喻：每章规划 3-5 处精准比喻（有叙事功能的），不堆砌
- "了"：用长句衔接代替短句堆叠，"了"自然不会过多
- 对话：面对面交锋用直接对话格式，不转述
- 短句：只在重音处用，日常叙述保持正常段落长度
- 确定性：写之前确定角色的信息状态，首次遭遇用推测语气
- **style_plan（v3.1 新增，F2 缩水版）**：写正文前在交接卡填 style_plan——metaphor_plan 规划 3-5 处精准比喻（位置/喻体/叙事功能）；交锋场景在 dialogue_plan 标注用直接对话的理由。确定性状态沿用 H3 的 cross_chapter_facts.certainty_state，不另设字段。style_plan 是"给审核员的意图上下文"：lint 报比喻超限时，detail-reviewer 据此判断哪个比喻是有计划的（留）、哪个是随手堆的（删）

## 八、重写流程

收到 `quality_review_{N}.json`（退回指令）后：
1. 只改问题清单列出的点位，不顺手"优化"无关段落；
2. 改完重跑 style_lint，仍须全绿；
3. 重写不超过 2 轮；第 2 轮仍被退，升级总编裁决，不再继续刷轮次。
