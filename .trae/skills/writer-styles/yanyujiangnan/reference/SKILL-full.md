# 烟雨江南风格写作技能

蒸馏自烟雨江南三部代表作：《罪恶之城》《狩魔手记》《永夜君王》。

## 风格定位

- **题材偏好**：黑暗奇幻、西幻、末日废土、东方玄幻，擅长在残酷世界中书写个体命运
- **整体调性**：黑暗、苍凉、宏大，底色是虚无与悲怆，但绝望中始终有一线抗争的微光
- **核心母题**：命运与反抗、人性的灰度、权力的腐蚀、孤独与归属、文明与野蛮的边界
- **目标读者**：追求文学性和深度的成熟读者，厌倦纯粹爽文的读者

## 语言风格规则

### 1. 用词偏好
- 偏好书面语与古雅词汇，但不过度文言化；偶尔夹杂现代感词汇形成张力
- 善用四字短语和意象密集的词汇堆叠营造氛围
- 喜用与"光暗、生死、命运、深渊、废墟、荒野"相关的意象词
- 描写残酷场景时用冷静克制的词汇，不渲染血腥，反差感更强

### 2. 句式特征
- 长短句交错：环境描写用绵长句式铺陈，动作和转折用短句切割节奏
- 高潮段落善用排比和重复结构制造气势
- 时常插入一句极短的独立句作为段落收束，如同一记重锤
- 对话简练，很少长篇大论，人物说话带性格但不啰嗦
- **必须有"粗糙"的句子**：不是每句都要打磨。需要笨拙的、直接的、甚至干巴巴的叙述句来衬托精巧的句子。如果每句都是金句，那就没有金句了。好的文章像一块有纹理的玉，不是打磨到光滑无痕

### 3. 描写习惯
- **环境描写**：篇幅占比高，注重光影、色彩、温度、气味的通感描写，营造电影级画面感
- **心理描写**：用第三人称内视角，深入角色内心但不直白说破，通过行为和细节暗示心理
- **动作描写**：战斗场景动词精准密集，画面感强，注重空间感和速度感
- **氛围营造**：是烟雨江南最突出的能力，用环境烘托情绪，景即是情
- **比喻规则**（整合）：比喻必须功能性大于装饰性，喻体优先取自故事世界本身的物质（废土用辐射腐蚀的金属，奇幻用魔法现象）。避免常见比喻（"毛玻璃""隔了一层纱"），避免类型通货意象（废土的灰烬如雪、绿雾，西幻的古老符文、命运丝线）。开篇尤其不能用通货意象——读者第一眼要看到只有这个故事才有的东西。好的比喻同时完成"比喻"和"世界观强化"两个功能

### 4. 对话风格
- 对话占比适中（约25%-35%），不靠对话推进情节
- 角色对话有鲜明个性，但不依赖口头禅
- 重要信息常在对话中轻描淡写地抛出，读者需细品
- 反派和智者角色的对话往往暗藏机锋

## 叙事结构规则

### 1. 章节与节奏
- 单章字数：3000-5000字，偏长
- 节奏偏慢，不追求每章爽点，注重铺垫和氛围
- 擅长用看似平静的章节埋下伏笔，数十章后引爆
- 大高潮前必有压抑和低谷，先抑后扬的幅度极大

### 2. 主题信息重复控制
- 核心信息（设定、情感、主题）全文最多出现两次：**设定一次，收束一次**
- 中间每多出现一次，结尾的冲击力就衰减一层
- 例：记忆在消退，设定时写一次"那张脸也在模糊"，结尾再写一次"已经想不起来了"。中间不要再反复强调"他又失去了一些什么""又模糊了一分"
- **规律**：写完一次后问自己——结尾还要用这个信息吗？如果要用，中间就不要再碰
- **感官体验同理**：以某种感官（痛觉、气味、温度）作为叙事引擎时，该感官的重复出现也有边际递减。高潮前需要一段静场（感官暂停或转换），重置读者的敏感度，让高潮时的感官冲击重新获得力度

### 3. 爽点与章末
- 不走密集爽点路线，爽点间隔大但爆发力强
- 爽点常伴随代价和悲剧，不是纯粹的爽，而是"痛快的悲壮"
- 章末不一定留悬念，有时以一段氛围描写或哲思收束，重要章节结尾常有留白
- 偶尔在平静处突然抛出转折，制造冲击

### 4. 伏笔与结构
- 伏笔密度高，草蛇灰线，前后呼应
- 多线叙事，支线与主线交织，后期汇合
- 善用"命运早已注定"的宿命感结构

## 人物塑造规则

### 1. 主角模板
- 出身底层或困境，背负秘密或特殊能力
- 性格内敛坚韧，不张扬，行动多于言语
- 有道德灰度，会做"必要之恶"，但底线清晰
- 成长伴随着失去，力量越大越孤独
- 内心有柔软处，通常与某个重要的人相关

### 2. 配角体系
- 配角鲜活立体，即使戏份少也有完整的人格
- 配角分几类功能：
  - **引路者/导师**：神秘强大，亦师亦敌，最终往往离去或牺牲
  - **同行者**：与主角相互扶持，性格互补
  - **对手/宿敌**：有自己立场和信念的反派，不是纯粹的恶
  - **红颜**：不是花瓶，有自己的命运和选择，关系往往BE或充满遗憾
- 配角会死，重要配角也会死，死亡有分量不廉价
- **配角必须有主体性瞬间**：配角不能只承担"被保护者""提问者""引路人"等功能性角色。必须在某个时刻做出一件让主角意外的事、展现独立意志的行动，让她从"功能性存在"变成"人"。例如：被保护的孩子反过来保护了主角，或做了主角不会做的选择

### 3. 反派设计
- 反派有自己的逻辑和信念，不是脸谱化的恶
- 反派的强大和智慧真实可信，主角的胜利来之不易
- 部分反派有人性闪光点，死后令人唏嘘
- 终极反派往往代表某种"秩序"或"命运"，主角的抗争是向命运宣战

## 世界观构建规则

### 1. 力量体系
- 体系严谨自洽，有明确规则和代价
- 力量层次分明，主角的成长路径清晰
- 力量使用有代价（精神、寿命、人性流失等），不是无代价变强
- 不同力量体系之间有克制和平衡关系

### 2. 社会结构
- 世界是残酷的，弱肉强食，但有规则和秩序
- 权力机构（帝国、教会、家族）有虚伪和腐败的一面
- 底层人民挣扎求存，世界的残酷感真实
- 种族/势力之间有复杂的历史恩怨和政治博弈

### 3. 环境设定
- 重视地图和地理，不同区域有独特的生态和文化
- 环境本身就是故事的一部分（废土的辐射、永夜的黑暗、位面的法则）
- 世界有"历史感"，有遗迹和失落的文明

## 战斗描写规则

- **宏观与微观结合**：既有战场全局的宏大调度，也有个体搏杀的细节特写
- **画面感**：像电影动作戏，有运镜感，远近景切换
- **节奏感**：快慢交替，爆发时短句密集，对峙时拉长描写制造紧张
- **力量可视化**：用光影、冲击、空间扭曲等视觉效果表现力量层次
- **附带破坏**：战斗对环境的破坏是重要表现手段，凸显力量感
- **代词与定语极简**：战斗中能省的代词和定语全部省掉。上下文已明确对象的，绝不再加"那头""那个""那只"。一个字能省就省，战斗描写要像刀一样干净
- **非战斗部分**：战斗前的对峙、心理博弈、战场氛围与战斗本身同等重要
- **不要在紧张时刻插入闪回**：战斗即将爆发的瞬间绝不插入回忆、背景交代或角色介绍。闪回应放在战后平静时刻，或干脆省略
- **闪回需感官触发**：战后回忆不要用"他想起某人"直白引入。应让某个感官细节（气味、触感、声音）自然触发记忆
- **打破递进套路**：避免"小怪→小怪→精英怪撤退"这种1-2-3递进结构。真实遭遇战不会有整齐的层次，打破读者的类型预期

## 氛围营造规则（核心能力）

这是烟雨江南最突出的特征，需重点遵循：

- **以景写情**：环境描写永远在服务于情绪和主题，不是单纯写景
- **光影运用**：擅长用光与暗的对比营造氛围，黑暗中的微光是标志性意象
- **寂静感**：在大事件前后用极静的描写制造张力，暴风雨前的宁静
- **孤独感**：通过空旷的环境、独行者的背影、沉默的对峙传递孤独
- **废墟美学**：残破、荒芜、衰败的场景描写带有苍凉的美感
- **时间流逝感**：用环境变化表现时间流逝和沧桑

## 克制原则（灵魂规则）

这是烟雨江南与普通网文最大的差距所在，也是最难做到的。核心只有一句话：**信任读者**。

### 0. 克制不等于跳过（最高优先级）
克制是最容易矫枉过正的规则。删减时必须区分两类内容：

| 该删的 | 不该删的 |
|--------|---------|
| 替读者总结情感的句子 | 场景转换的过渡句 |
| 重复出现的核心信息 | 事件发生前的铺垫和预兆 |
| 冗余的代词和定语 | 让读者跟上节奏的引导句 |
| 给行为贴标签的定义 | 角色行动的动机线索 |
| 解释性的金句收束 | 时间和空间的位移交代 |

**判断标准**：删掉某句后，问自己"读者还能跟上吗？画面还连贯吗？"如果不能，就不能删。克制的目标是让读者自己感受，不是让读者自己猜发生了什么。一篇突兀的文章比一篇啰嗦的文章更糟——啰嗦至少能看懂，突兀让人放弃。

### 1. 不解释已经演出来的（合并原规则1+9）
当画面、行为、细节已经传达了信息或情感，绝不再加一句概括或解释。

| 已经演出来的 | 不要再说的 |
|-------------|----------|
| "那张脸也在模糊" | "他怕的不是死亡。他怕的是死之前，忘记最后那张脸。" |
| "没有尖叫，也没有哭" | "废土上的孩子比大人更早学会面对死亡" |
| "火苗很小，像随时会熄灭" | "但这温暖是假的" |
| "嘴角挂着碎肉，肚皮鼓胀，皮毛上结着血痂" | "——刚吃过东西" |
| "陆沉没有问怎么死的" | "在废土上这个问题没有意义" |

**规律**：写完一段细节后，如果下一句是对这段细节的总结或解释，删掉它。每当忍不住要"解释"的时候，就是信任读者不够的时候——问自己"删掉这句，读者还能感受到吗？"如果能，就删。

### 2. 不给行为贴标签
让行为和细节自己说明角色的特质，不要作者出来下定义。

| 错误（贴标签） | 正确（让行为说话） |
|---------------|-------------------|
| "这一头有智慧。它在判断，在权衡" | 只写"它停下来了。呜咽了一声。然后转身走了。"不解释为什么 |
| "他是一个孤独的人" | 写他一个人吃饭、一个人走路、说话时看着别处 |
| "她很勇敢" | 写她做了什么，让读者自己判断那是不是勇敢 |

### 3. 不用金句收束
结尾不要"点题"。不要用排比+总结的方式告诉读者"你应该怎么理解这个故事"。

| 错误（金句收束） | 正确（动作收束） |
|---------------|-----------------|
| "微弱。短暂。倔强。但它是光。" | "火星灭了。他往火堆里添了一根柴。" |
| "这就是命运。" | 不说。让前文自己说话 |

真正的力量在于"说不清楚但还是说了"，在于一个朴实的动作承载了所有未说出口的意义。

### 4. 避免腔调与通货（合并原规则5+6）
**腔调陷阱**：同一种句式和手法全文使用不超过两次。超过就是表演而非写作。典型陷阱——废土/黑暗题材反复用"他没有XXX"的句式表演冷硬（"他没有问怎么死的""他没有回头""他没有说话"）。一次是人物，三次是腔调。

**通货意象**：每个题材类型都有"标配意象"，辨识度低，开篇尤其不能用。废土的灰烬如雪、绿雾、锈蚀、荒原落日；西幻的星光魔法、古老符文、命运丝线；东方玄幻的剑气纵横、天地变色。如果必须用类似意象，必须加入独特的、属于这个故事的修饰，让它从"通货"变成"独家"。

### 5. 叙述者隐身
叙述者的存在感越低，沉浸感越强。区分"叙述者在说话"和"事情在发生"：

| 叙述者在说话（避免） | 事情在发生（追求） |
|-------------------|------------------|
| "陆沉只说了两个字" | 直接写对话，读者自己数 |
| "他自己的脸" | "一张瘦削的脸"——像看到陌生人 |
| "那是辐射给他的东西" | "辐射给他的东西"——内心独白而非叙述 |
| "他不知道她要干什么" | 直接给判断，读者自己补 |

**规律**：写完一句后问"这句话是人物在感受，还是作者在解释？"如果是后者，删或改。目标是文本像"事情正在发生，你恰好在场"，而非"一个人在给你讲故事"。

### 6. 对手退场有因果落点
对手（人、兽、势力）的主动退场不能只靠读者善意脑补，必须有文本内的因果线索：

- 在退场前埋入可推断的原因——它刚进食过不饿、它闻到了同类的血、它认出了某种东西、它受了旧伤不愿冒险
- 线索不需要明说，但必须存在，让读者"能推断"而非"只能猜"
- 埋线索的最佳位置：战斗前的环境描写中（如血腥味的来源暗示变异犬刚分食过猎物）
- **因果线索留一半**：三层铺垫（暗示→明写→确认）不要全部点名。把最关键的那一层用行为呈现，其余留给读者推断。如：犬的鼻子翕动、目光落在同类尸体上——到此为止，读者自己能接上"它判断不值得"
- **视角不要越界**：因果线索应通过主角能观察到的外部行为呈现（鼻子翕动、目光移动），不要钻进对手的感知（"它闻到了什么"）。保持视角统一

## 哲学思辨融入

- 不说教，不直接讨论哲学，而是通过情节和角色命运呈现
- 主题常包括：自由意志与命运、人性的善恶灰度、权力的异化、存在的意义
- 角色会在关键时刻有简短而有力的内心独白，点到为止
- 故事的结局往往开放或带有遗憾，引发读者思考
- **思辨融入的克制**：角色顿悟后，不要再加一句解释。如"他明白了祖父的话——力量不是自由"之后，不要再解释"那些站在巅峰的存在不过是从一个笼子走进另一个笼子"。让顿悟本身停住，读者自己填充

## 禁忌清单

- **不要**写成纯粹爽文，主角不能无脑碾压、装逼打脸
- **不要**让重要角色廉价死亡，死亡必须有分量和意义
- **不要**用过于轻快、搞笑的语调，保持整体的厚重感
- **不要**大段直白说理或说教，思辨要融入叙事
- **不要**忽视环境描写，氛围是烟雨江南的灵魂
- **不要**让反派脸谱化，每个对手都应有自己的信念
- **不要**力量体系混乱，变强必须有逻辑和代价

## 参考示例

### 示例1：氛围营造（《狩魔手记》风格）
> 荒原上的风从未停歇。它掠过锈蚀的钢铁骨架，穿过坍塌半截的高楼，最后呜咽着消散在灰蒙蒙的天际线下。苏站在一座曾经的教堂前，穹顶早已不知去向，只剩四壁残垣倔强地指向铅灰色的天空。风把他的衣角吹得猎猎作响，他却一动不动，像一尊被遗忘的雕像。辐射云层缝隙中漏下一缕暗红的光，照在祭坛上早已干涸的褐色痕迹上。这里曾经有过祈祷，有过信仰，有过人类最后的温柔。现在只剩下风，和无尽的沉默。

**风格分析**：环境描写占比极高，用"锈蚀""坍塌""铅灰""暗红"等意象堆叠废土的苍凉感。最后一句从景物转向人文感慨，点出"曾经"与"现在"的对比，是烟雨江南式的废墟美学。

### 示例2：战斗描写（《永夜君王》风格）
> 原力光芒在千夜身上一闪即逝，下一刻他已出现在狼人首领身侧。那柄暗金长刀划出一道几乎看不见的弧线，切开了夜色，也切开了血肉。狼人首领的低吼戛然而止，它低头看着胸口的伤口，浑浊的眼睛里闪过一丝不可置信。千夜没有停留。他踏过倒下的躯体，刀锋斜指地面，血珠沿着刀刃滑落，在永夜大陆永恒的黑暗中，溅开一朵无声的花。身后，更多的狼人嚎叫着扑来。千夜转身，瞳孔深处原力之光亮起，如黑暗中燃起的星火。他举刀，向前迈了一步。仅仅一步。

**风格分析**：动作描写用短句密集推进节奏，"一闪即逝""下一刻"制造速度感。战斗中穿插环境和细节，不是纯粹的动作流水账。"仅仅一步"作为独立短句收束，制造力量感和悬念。原力之光"如黑暗中燃起的星火"是标志性的"黑暗中的微光"意象。

### 示例3：哲思融入（《罪恶之城》风格）
> 深渊凝视着李察，李察也凝视着深渊。他看见无数灵魂在黑暗中沉浮，看见星辰在虚无中诞生与熄灭，看见命运的丝线编织成一张无形的网，将众生牢牢缚住。他忽然明白了祖父的话——力量不是自由，只是更大的牢笼。那些站在巅峰的存在，不过是从一个笼子走进另一个笼子。李察闭上眼睛，再睁开时，瞳孔深处多了一抹幽蓝。他举起手，掌心凝聚着一粒微光。那是他自己的光，微小，倔强，却是黑暗中唯一属于他的东西。"如果命运是深渊，"他轻声说，"那我就在深渊里，燃一把火。"

**风格分析**：哲思通过角色的顿悟呈现，不是作者说教。"力量不是自由，只是更大的牢笼"是烟雨江南的典型母题。最后以简短对话收束，将抽象的哲思落地为具体的行动宣言。

## 创作流程

1. **确认题材与框架**：确定世界类型（奇幻/废土/玄幻）、主角设定、核心冲突
2. **构建世界观**：设计力量体系、社会结构、地理环境，确保自洽
3. **规划节奏曲线**：标注低谷、伏笔点、高潮点，遵循先抑后扬的大节奏
4. **撰写时检查清单**：
   - [ ] 环境描写是否充分，是否服务于情绪
   - [ ] 句式是否长短交错，有无独立短句收束
   - [ ] 战斗是否宏观微观结合，有无画面感
   - [ ] 人物是否有灰度，反派是否有信念，配角是否有主体性瞬间
   - [ ] **克制总检**：逐句审查——有没有"解释已经演出来的信息""给行为贴标签""金句收束""叙述者暴露"？有则删
   - [ ] **重复检查**：核心信息是否出现三次以上（只保留设定一次+收束一次）？同一种句式是否超过两次？通货意象是否出现在开篇？
   - [ ] **突兀检查**：是否有事件突然发生无铺垫？对手退场是否有因果线索且留一半？视角是否越界？
   - [ ] **比喻检查**：喻体是否属于这个世界？是否是常见比喻或通货意象？比喻是否同时完成"比喻"和"世界观标记"？
5. **对照禁忌清单自查**：确保没有触碰禁忌项
6. **余味检查**：重要段落结尾是否有留白和余味
