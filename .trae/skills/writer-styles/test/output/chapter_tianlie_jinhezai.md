# 《天裂》第1章（今何在版）· 风格技巧说明与约束自检

> 配套正文：`chapter_tianlie_jinhezai.txt`（约2010字，未超4000字上限）
> 风格依据：`.trae/skills/writer-styles/jinhezai/style_card.md` + `fingerprint.json`（《悟空传》6.1万字基线）

## 一、本章使用的核心风格技巧（5条）

1. **短句碎片为骨，长句爆破为锋**
   全章以 ≤8 字短句碎切推进（"天裂了。""半声。""是白。"），段落均长极短；仅在情绪决堤处放出全章唯一的长句爆破——"也许……我只是想知道，天上那个东西，凭什么让我们怕成这样。"这正是今何在"诗人的呼吸"：碎句铺路，一句长句泄洪。

2. **破折号/省略号双签名（量化校准）**
   实测：破折号 4.5/千字（基线 4.802）、省略号 8.5/千字（基线 8.368）——两个签名手法密度几乎贴着《悟空传》基线落点。破折号用于语气急转与插入（"然后——""第三步的时候——"），省略号承载静默与未尽之意，并保留今何在标志性的独立成段静默（"……"单独一行）。

3. **"我"与"你"的呼告对话感（独白体底色）**
   采用第一人称叙述，"我"密度 28.9/千字、"你"密度 10.4/千字，叙事不断滑入对读者的直接诘问（"你听过狗只叫半声吗？""你问我为什么不跑？"），让世界对"你"说话，这是独白体小说区别于长句叙事体的根本质感。

4. **对话即叙事，短兵相接 + 动作节拍**
   关键信息全部靠对话交代而非叙述概括：老周的儿子（处境）、提鸟笼老头的"七十年前听过一次"（世界观钩子）、"你怕吗？/……怕。/怕，就对了"（主题点题）。多轮无引导语短兵相接（"地震？""不像。"），并按风格卡要求穿插 2-3 处动作节拍（拽袖子、塞鸟笼、回头）打断纯对话流。粗粝与诗意并置："放你个头，炮能把天崩了？"的粗口紧邻"好像全世界的水，都想回家"的抒情。

5. **不解释，让画面自己悲伤（留白式克制）**
   全章无一句情绪标签或总结式心声。悲伤交给物象：停在 12:00 的手机屏上那条发给"妈"、只有一个"忙"字的未发出微信；睁着眼睛"看死"的画眉；末日里念叨"瓜还没收钱"的老王——"人抓住的东西，往往就是人能站住的全部理由"点到即止，不展开论述。

## 二、与 testTopic 约束的对应关系自检

| 约束 | 落实情况 |
|---|---|
| ① 建立主角（≤500字） | 开篇约300字内完成：理发匠"阿末"，三代守一间理发铺，爷爷与父亲皆亡，守着父亲"涨价要慢"的规矩；性格——嘴硬寡言、不拆穿别人的谎（悲悯的底色），由日常对话建立而非自述 |
| ② 钟响瞬间（写人的反应而非声音本身） | "那一声，不是从耳朵进来的。是从骨头里出去的。"+ 后颈皮肉绷紧、镜中脸白、推子落地、狗只叫"半声"——全部写体感与反应，未直接描写声音 |
| ③ 天裂（群体性恐惧场面） | 满街人定格（西瓜刀/外卖刹车）→ 同时抬头 → 跪、拍、笑、喊、报警的众生相；"恐惧是有形状的。它是一条街的人，仰着同一张脸。" |
| ④ 第一个异变（30分钟内、可视化） | **雨往上落**：地面杂物先飘起，随后雨水从地面升起、滴入天缝——具体、可见、违反常识 |
| ⑤ 主角的第一个选择 | 章末放弃逃跑，把鸟笼放在门槛上，朝裂缝走去（"留/进"而非"跑"）；动机落在"看够了人低着头"的叛逆上，暗示主角性 |
| ⑥ 钩子 | 末句："这一次，全世界只有我一个人听见。"——第二声钟只响给主角，制造第二章悬念 |
| 手机元素 | 信号格空、时间停 12:00、屏幕上一条发给"妈"未发出的"忙"字微信 |
| 陌生人元素 | 提鸟笼的老头：死画眉目击证人 + "七岁那年听过一次"的信息源 + "你怕吗"点题对话 |
| "不对"认知转折 | 明写两处："不对。/风没有起来。"（异变前兆）与"不对——这不是地震，不是演习，也不是我疯了。是天上的什么东西，醒了。"（原文级转折句） |
| 非视觉感官细节 | 触觉："老周的后颈在我刀下绷紧了"（皮肉触感）；体感："那一声是从骨头里出去的"（骨感）；听觉：狗叫"半声" |
| 无游戏化UI/无重生穿越/无明示金手指 | 均无。"雨躲开我"+独闻第二声钟为暗示级，未给任何明确能力解释 |
| 无"我叫XX今年XX岁"式自我介绍 | 身份全部由对话与铺子沿革侧写 |
| ≤4000字 | 约2010字 ✓ |
