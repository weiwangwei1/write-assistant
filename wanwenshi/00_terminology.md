# 术语体系设计 —— 《万纹师》（暂定书名）

> 版本：v1.0（2026-07-26）
> 背景：《献祭纪元：赊刀人》已归档（archive/newbook_献祭纪元_放弃_20260726）。
> 本项目为全新选题：**天赋流匠人职业 + 无系统金手指 + 热血正剧**，
> 参考《罪恶之城》结构骨架（多位面/规则之力/职业体系/龙族/位面战争），全面换皮。

---

## 一、命名决策：为什么是"铸纹师"

| 维度 | 分析 |
|---|---|
| 差异化 | 与《罪恶之城》"构装师"切割：构装=魔法阵+机械+符文的装置（西式奇幻）；铸纹=把"规则碎片（纹）"锻刻入器物（东方锻造质感）。"铸"字自带铁匠/炉火画面，与主角铁匠铺出身咬合 |
| 零解释成本 | "铸纹师"三个字读者一看就懂：铸造纹路的师傅。无需像"赊刀人"那样在正文里标读音、做名词解释 |
| 爽感载体 | 修复（别人修不好的他能修）→制作（亲手造出武装）→图纸（复原/改良上古图纸）→纹阵（战争级）——每一步都是"得到"，没有负债叙事 |
| 文化浓度 | "纹"承东方器物纹样/图腾传统（青铜纹、云雷纹、龙纹），民俗底色自然 |

被否决的候选：符械师（机械感过重，偏西式）、灵纹师（偏法师感，匠气不足）、纹匠（过素，撑不起书名）。

## 二、核心术语表

| 术语 | 定义 | 记忆点 |
|---|---|---|
| **纹** | 规则碎片在世间的固化形态。草木枯荣有纹、凶兽骨骼有纹、古战场上古战场遗留的"上古纹"最珍贵 | 万物皆有纹，看得见摸得着 |
| **铸纹** | 把游离的纹引入器物刻痕（引纹），或把规则碎片锻成新纹（铸纹）的技术 | 手艺活，不是法术 |
| **纹器** | 铸入纹的器物：武器/防具/傀儡/阵盘 | 装备即战力，可展示 |
| **纹阵** | 多纹联动的阵列：护城阵/军阵/领域阵 | 战争级力量，军团戏舞台 |
| **本命纹** | 铸纹师把自身规则领悟铸成的独一无二的纹 | 后期主角路线标志 |
| **蚀纹** | 纹的"癌变"：会吞噬其他纹的异变纹，源于上古"纹崩之夜" | 主线威胁，与暗线一体 |
| **蚀纹者** | 被蚀纹侵蚀的人/兽/位面，周期性入侵苍澜 | 对立阵营 |
| **衔纹龙族** | 远古龙族，龙鳞上的天然纹是"纹"的起源。万纹时代教人族铸纹，纹崩之夜集体沉睡 | 老龙的种族，暗线核心 |
| **荒纹绝地** | 纹崩后形成的破碎遗迹带，危险与上古纹资源并存 | 副本舞台 |
| **上古图纸** | 万纹时代遗留的铸纹图样，复原一张=轰动一方 | 图纸争夺=势力博弈载体 |

## 三、职业体系（明面三大主职 + 铸纹师为核心）

| 职业 | 核心逻辑 | 社会地位 |
|---|---|---|
| **铸纹师** | 以纹为业：引纹、铸纹、修纹、造纹器纹阵。不一定能打，但决定势力的战力上限 | 战略资源，极稀有，被争夺 |
| 战师 | 修炼战气强化肉体武技，主战力 | 军队主力 |
| 灵师 | 感悟天地灵气施术，远程/辅助 | 地位高，人数少 |
| 猎纹人 | 进荒纹绝地采纹、猎纹兽的自由职业者 | 高风险高回报，公会制 |

**铸纹师品阶**（匠人等级，与战力等级分离——《罪恶之城》式"不一定能打但地位极高"）：
学徒（磨纹）→ 铸纹师（引纹）→ 大铸纹师（铸纹成阵）→ 纹圣（规则入纹）→ 纹传（纹即规则，传说层级，万纹时代后无人达到）。

**通用战力等级**（简化标尺）：凡境→灵境→圣境→神境（每阶三重）。

## 四、与《罪恶之城》的差异化要点

| 罪恶之城 | 本书 | 差异目的 |
|---|---|---|
| 构装（魔法阵+机械+符文） | 纹（规则碎片的东方纹样形态） | 文化质感切割 |
| 主角千夜：龙血+构装+规则三重外挂 | 主角沈拓：纯匠师天赋（稳手/过目不忘/空间逻辑），无血脉无系统 | 天赋流，力量全部世界规则内定价 |
| 老龙：远古NPC，你求它 | 老龙：遗迹交易方，契约交易有代价有次数，非随身伙伴 | 保留龙族魅力，杜绝金手指 |
| 献祭=向强大存在换力量（信息不对称） | 献祭保留为世界机制，人人可用，主角无特权 | 机制公平，外挂零容忍 |
| 帝国/贵族/神殿/黑暗种族多势力 | 前期聚焦3势力（百炼阁/猎纹公会/大胤纹备院）+暗线拜纹教 | 网文化简化，后期再展开 |
