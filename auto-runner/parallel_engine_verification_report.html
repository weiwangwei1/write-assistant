6关键技术决策

流水线依赖修正

在初版生成器中，Ch(N+1) Write 错误地依赖 Ch(N) Memory Commit，导致流水线并行被破坏（必须等记忆入库才能写下一章）。修正后 Ch(N+1) Write 依赖 Ch(N) Merge（正文已打磨但不必等审稿和入库），实现真正并行。

// 修正前（错误）：Ch15 Write 依赖 Ch14 Memory Commit
depends_on: [5]  // Ch14 Memory Commit — 并行被破坏！

// 修正后（正确）：Ch15 Write 依赖 Ch14 Merge
depends_on: [3]  // Ch14 Merge — 正文已打磨，可与Ch14审稿并行

统一审核模式集成

使用 -ReviewMode unified 参数，将传统2步（quality-reviewer 8维 + final-reviewer 4维）合并为1步 unified_review（12维一次评完），每章减少1步骤+1文件。已在Ch12验证等价性：unified_score(9.51) == final_score(9.51)。

开头/结尾风格自动轮换

生成器根据章节号自动分配开头/结尾风格，确保无连续重复：

章节开头结尾
Ch14sensory（感官）action_unfinished（动作未完成）
Ch15dialogue（对话）info_reveal（信息揭示）
Ch16scene_action（场景动作）dialogue_ending（对话结尾）
Ch17suspense（悬念）scene_description（场景描写）
